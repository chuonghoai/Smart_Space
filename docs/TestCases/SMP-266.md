# SMP-266: Báo lỗi khi gửi email thông tin đăng nhập admin thất bại

1. **Mã số test case:** SMP-266
2. **Tên test case:** Báo lỗi khi gửi email thông tin đăng nhập admin thất bại
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản quản trị viên
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AdminAccountServiceImpl.createAdmin(...) bắt MailException từ mailService.sendAdminCredentialsEmail và ném BadRequestException("mail.admin.credentials.send_failed").
7. **Mục đích kiểm thử:** Xác minh dịch vụ chuyển lỗi gửi mail thành BadRequestException để kích hoạt rollback transaction ở tầng Spring.
8. **Điều kiện tiên quyết:** Stub existsByEmailAndRole=false, passwordEncoder.encode="hashed", saveAndFlush trả về entity, và doThrow(new MailSendException("smtp down")) trên mailService.sendAdminCredentialsEmail(...).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.createAdmin(request, "admin-me") khi gửi mail ném MailSendException | CreateAdminRequest(" New Admin ", " new@example.com ", ""), currentAdminId="admin-me" | Ném BadRequestException với message "mail.admin.credentials.send_failed" |

10. **Input từng bước:**
   - Bước 1: CreateAdminRequest(" New Admin ", " new@example.com ", ""), currentAdminId="admin-me"
11. **Kỳ vọng từng bước:**
   - Bước 1: Ném BadRequestException với message "mail.admin.credentials.send_failed"
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/admin/AdminAccountServiceImplTest.java`
13. **Ghi chú:** Tên test method: Create.mailFailure_isReported. Lưu ý: unit test sử dụng Mockito nên chỉ xác minh ngoại lệ BadRequestException được ném ra; hành vi rollback DB thực tế phụ thuộc vào annotation @Transactional khi chạy trong Spring container.
