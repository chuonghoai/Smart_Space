# SMP-290: Render template mail/account-locked tiếng Việt kèm lý do và email hỗ trợ

1. **Mã số test case:** SMP-290
2. **Tên test case:** Render template mail/account-locked tiếng Việt kèm lý do và email hỗ trợ
3. **Project:** Spring Boot Backend
4. **Chức năng:** Template Email thông báo (Thymeleaf Mail Templates)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra render template mail/account-locked với locale tiếng Việt ("vi"), tên "Lê Văn C", lý do "Đăng nhiều phản ánh sai sự thật." và supportEmail="support@smartspace.vn": HTML chứa đầy đủ lời chào, lý do, chữ ký "Hội đồng quản trị", liên kết mailto, bản quyền "© 2026 SmartSpace", không có chuỗi "??" (key i18n bị thiếu), và ghi file preview ra target/mail-preview/account-locked_vi.html.
7. **Mục đích kiểm thử:** Xác minh template email khóa tài khoản hiển thị đúng nội dung tiếng Việt, đầy đủ bản dịch i18n và phần hỗ trợ khi có cấu hình email hỗ trợ.
8. **Điều kiện tiên quyết:** @BeforeAll khởi tạo SpringTemplateEngine với ClassLoaderTemplateResolver (prefix="templates/", suffix=".html", HTML, UTF-8) và ResourceBundleMessageSource thật (basenames="i18n/messages", UTF-8, fallbackToSystemLocale=false).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi engine.process("mail/account-locked", ctx) với locale "vi" | locale=vi, lang="vi", fullName="Lê Văn C", reason="Đăng nhiều phản ánh sai sự thật.", logoUrl=null, supportEmail="support@smartspace.vn", year="2026" | Trả về chuỗi HTML đã render |
| 2 | Kiểm tra các nội dung tiếng Việt, liên kết hỗ trợ và key i18n trong HTML | html kết quả | Chứa "Xin chào Lê Văn C,", "Đăng nhiều phản ánh sai sự thật.", "Hội đồng quản trị", "mailto:support@smartspace.vn", "© 2026 SmartSpace" và không chứa "??" |
| 3 | Xuất file HTML preview | target/mail-preview/account-locked_vi.html | Ghi thành công nội dung HTML bằng UTF-8 |

10. **Input từng bước:**
   - Bước 1: locale=vi, lang="vi", fullName="Lê Văn C", reason="Đăng nhiều phản ánh sai sự thật.", logoUrl=null, supportEmail="support@smartspace.vn", year="2026"
   - Bước 2: html kết quả
   - Bước 3: target/mail-preview/account-locked_vi.html
11. **Kỳ vọng từng bước:**
   - Bước 1: Trả về chuỗi HTML đã render
   - Bước 2: Chứa "Xin chào Lê Văn C,", "Đăng nhiều phản ánh sai sự thật.", "Hội đồng quản trị", "mailto:support@smartspace.vn", "© 2026 SmartSpace" và không chứa "??"
   - Bước 3: Ghi thành công nội dung HTML bằng UTF-8
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/mail/AccountLockedMailTemplateTest.java`
13. **Ghi chú:** Test thực thi không cần Spring context, dùng ResourceBundleMessageSource thật và có side effect ghi preview vào target/mail-preview/.
