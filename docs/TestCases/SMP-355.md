# SMP-355: Luồng E2E đăng nhập Staff Web thành công vào trang chủ /home

1. **Mã số test case:** SMP-355
2. **Tên test case:** Luồng E2E đăng nhập Staff Web thành công vào trang chủ /home
3. **Project:** Flutter Staff
4. **Chức năng:** Đăng nhập E2E Staff Web
5. **Loại kiểm thử:** E2E Web Automation Test (Playwright)
6. **Mô tả test case:** Nhập tài khoản Staff từ PW_STAFF_EMAIL / PW_STAFF_PASSWORD vào màn hình đăng nhập Staff Web, nhấn Đăng nhập và xác minh chuyển hướng sang /#/home.
7. **Mục đích kiểm thử:** Xác minh luồng đăng nhập đầu-cuối cho Staff từ giao diện Web tới Backend và vào trang chủ.
8. **Điều kiện tiên quyết:** Backend và Staff Web server đang chạy; có PW_STAFF_EMAIL và PW_STAFF_PASSWORD (nếu thiếu sẽ SKIPPED).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Boot Staff Web tới /#/login và điền thông tin đăng nhập từ env | PW_STAFF_EMAIL, PW_STAFF_PASSWORD | Textbox nhận đủ thông tin |
| 2 | Nhấn nút 'Đăng nhập' và chờ URL chứa /home | Click 'Đăng nhập' | URL chuyển sang /#/home |

10. **Input từng bước:**
   - Bước 1: PW_STAFF_EMAIL, PW_STAFF_PASSWORD
   - Bước 2: Click 'Đăng nhập'
11. **Kỳ vọng từng bước:**
   - Bước 1: Textbox nhận đủ thông tin
   - Bước 2: URL chuyển sang /#/home
12. **File test tương ứng:** `playwright/staff/staff-web.spec.ts`
13. **Ghi chú:** Không hardcode thông tin đăng nhập; tự SKIPPED khi thiếu biến môi trường.
