# SMP-175: Danh sách Hội đồng quản trị chỉ gồm admin, có summary và currentUser

1. **Mã số test case:** SMP-175
2. **Tên test case:** Danh sách Hội đồng quản trị chỉ gồm admin, có summary và currentUser
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản Hội đồng quản trị (/admin/admins)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gọi GET /admin/admins?page=1&size=50 nhận HTTP 200, body có trường summary, có email admin@gmail.com, đánh dấu "currentUser":true cho chính admin đang gọi và không trả về tài khoản staff/client.
7. **Mục đích kiểm thử:** Đảm bảo API danh sách Hội đồng quản trị lọc đúng vai trò admin, trả về thống kê summary và đánh dấu tài khoản hiện tại.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); CSDL có seed_data.sql (u1=admin@gmail.com, u5=staff1@gmail.com, u2=user@gmail.com); JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /admin/admins?page=1&size=50 với admin token u1 | Token admin@gmail.com (u1, ROLE_admin) | HTTP 200; body chứa "summary", "admin@gmail.com", "currentUser":true và không chứa "staff1@gmail.com" hay "user@gmail.com". |

10. **Input từng bước:**
   - Bước 1: Token admin@gmail.com (u1, ROLE_admin)
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; body chứa "summary", "admin@gmail.com", "currentUser":true và không chứa "staff1@gmail.com" hay "user@gmail.com".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminAccountManagementTest.java`
13. **Ghi chú:** Không gây side-effect. Class này chưa đăng ký trong testapi.ps1.
