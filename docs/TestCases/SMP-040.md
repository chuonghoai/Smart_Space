# SMP-040: ReportDateRange bỏ giờ, đảo đầu-cuối nếu ngược và định dạng yyyy-MM-dd

1. **Mã số test case:** SMP-040
2. **Tên test case:** ReportDateRange bỏ giờ, đảo đầu-cuối nếu ngược và định dạng yyyy-MM-dd
3. **Project:** Flutter Client
4. **Chức năng:** Bộ lọc danh sách phản ánh (Report List Filters)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra ReportDateRange(start: 2026-03-15 18:30, end: 2026-03-01 07:00) tự chuẩn hóa bỏ phần giờ, đảo ngược lại thành từ 01/03 đến 15/03, xuất fromQuery='2026-03-01', toQuery='2026-03-15' và isSingleDay=false.
7. **Mục đích kiểm thử:** Đảm bảo khoảng ngày gửi lên API luôn đúng thứ tự từ nhỏ đến lớn và đúng định dạng yyyy-MM-dd.
8. **Điều kiện tiên quyết:** Khởi tạo ReportDateRange với start > end và có giờ phút khác 0.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tạo ReportDateRange(start: DateTime(2026, 3, 15, 18, 30), end: DateTime(2026, 3, 1, 7)) | start=2026-03-15 18:30, end=2026-03-01 07:00 | fromQuery=='2026-03-01', toQuery=='2026-03-15', isSingleDay==false |

10. **Input từng bước:**
   - Bước 1: start=2026-03-15 18:30, end=2026-03-01 07:00
11. **Kỳ vọng từng bước:**
   - Bước 1: fromQuery=='2026-03-01', toQuery=='2026-03-15', isSingleDay==false
12. **File test tương ứng:** `smartspace_client/test/features/reports/report_list_filters_test.dart`
13. **Ghi chú:** Không có.
