# SMP-223: Tham số limit được tôn trọng trên API bản đồ nhiệm vụ Staff

1. **Mã số test case:** SMP-223
2. **Tên test case:** Tham số limit được tôn trọng trên API bản đồ nhiệm vụ Staff
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ nhiệm vụ Staff
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Staff u5 gọi GET /reports/staff/assigned?status=processing&limit=1 để kiểm tra số phần tử trả về không vượt quá 1.
7. **Mục đích kiểm thử:** Xác minh tham số limit giới hạn đúng số lượng nhiệm vụ trả về cho Staff.
8. **Điều kiện tiên quyết:** Backend đang chạy tại BASE_URL (mặc định http://localhost:8989); JWT staff u5 hợp lệ.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /reports/staff/assigned?status=processing&limit=1 với JWT staff u5. | JWT u5 (ROLE_staff); status=processing&limit=1 | HTTP 200 và data.size() <= 1. |

10. **Input từng bước:**
   - Bước 1: JWT u5 (ROLE_staff); status=processing&limit=1
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200 và data.size() <= 1.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/staff/StaffAssignedMapTest.java`
13. **Ghi chú:** Không có.
