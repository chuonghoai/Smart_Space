# SMP-281: Xác minh restoreUserAccess gỡ bỏ cờ chặn khỏi Redis

1. **Mã số test case:** SMP-281
2. **Tên test case:** Xác minh restoreUserAccess gỡ bỏ cờ chặn khỏi Redis
3. **Project:** Spring Boot Backend
4. **Chức năng:** Xác thực & Bảo mật tài khoản (AuthenticationService)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra restoreUserAccess("user-1") gọi stringRedisTemplate.delete("blocked_user:user-1") để gỡ bỏ cờ chặn truy cập của user.
7. **Mục đích kiểm thử:** Xác minh cơ chế mở khóa truy cập xóa đúng khóa cờ chặn trong Redis.
8. **Điều kiện tiên quyết:** Unit test dùng Mockito trên AuthenticationService với mock StringRedisTemplate.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi authenticationService.restoreUserAccess("user-1") | userId = "user-1" | Phương thức thực thi hoàn tất |
| 2 | Xác minh stringRedisTemplate.delete được gọi với khóa blocked_user | verify(stringRedisTemplate).delete("blocked_user:user-1") | Redis xóa đúng khóa "blocked_user:user-1" |

10. **Input từng bước:**
   - Bước 1: userId = "user-1"
   - Bước 2: verify(stringRedisTemplate).delete("blocked_user:user-1")
11. **Kỳ vọng từng bước:**
   - Bước 1: Phương thức thực thi hoàn tất
   - Bước 2: Redis xóa đúng khóa "blocked_user:user-1"
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/auth/AuthenticationServiceSecurityTest.java`
13. **Ghi chú:** Thuộc nhóm @Nested BlockedAccount.
