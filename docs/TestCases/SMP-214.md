# SMP-214: Bảng tin sắp xếp theo khoảng cách gần nhất xuyên suốt phân trang

1. **Mã số test case:** SMP-214
2. **Tên test case:** Bảng tin sắp xếp theo khoảng cách gần nhất xuyên suốt phân trang
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bảng tin phản ánh (Report Feed)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Gọi GET /reports/feed với sort=nearby trên page=1 và page=2 (size=5) tại tọa độ TP.HCM, kiểm tra mọi item đều có distance_in_meters và thứ tự khoảng cách không giảm.
7. **Mục đích kiểm thử:** Xác minh tính năng sắp xếp gần tôi (nearby) hoạt động nhất quán cả khi chuyển trang.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; JWT client u2 hợp lệ.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /reports/feed?sort=nearby&user_lat=10.7769&user_long=106.7009&size=5&page=1 và page=2. | JWT client u2; tọa độ (10.7769, 106.7009), size=5, page=1..2 | Cả 2 request trả HTTP 200; mọi item trong content đều có distance_in_meters khác null. |
| 2 | Kiểm tra dãy giá trị distance_in_meters thu thập từ trang 1 nối tiếp sang trang 2. | Danh sách distances qua page 1 và page 2 | Mọi phần tử liên tiếp thỏa distances[i] + 1.0 >= distances[i - 1] (cho phép sai số xấp xỉ <= 1.0m). |

10. **Input từng bước:**
   - Bước 1: JWT client u2; tọa độ (10.7769, 106.7009), size=5, page=1..2
   - Bước 2: Danh sách distances qua page 1 và page 2
11. **Kỳ vọng từng bước:**
   - Bước 1: Cả 2 request trả HTTP 200; mọi item trong content đều có distance_in_meters khác null.
   - Bước 2: Mọi phần tử liên tiếp thỏa distances[i] + 1.0 >= distances[i - 1] (cho phép sai số xấp xỉ <= 1.0m).
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/ReportFeedTest.java`
13. **Ghi chú:** Nếu DB có ít hơn 2 report không bị rejected, kiểm tra thứ tự xuyên trang có thể không đầy đủ.
