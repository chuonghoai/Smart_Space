# SMP-195: Mặc định GET /notifications/my không truyền unread trả về tổng >= số chưa đọc

1. **Mã số test case:** SMP-195
2. **Tên test case:** Mặc định GET /notifications/my không truyền unread trả về tổng >= số chưa đọc
3. **Project:** Spring Boot Backend
4. **Chức năng:** Danh sách thông báo (/notifications/my)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Client u2 gọi GET /notifications/my?page=0&size=1 (không truyền unread) trả về totalElements lớn hơn hoặc bằng totalElements khi truyền unread=true, đảm bảo tương thích ngược.
7. **Mục đích kiểm thử:** Đảm bảo khi không truyền tham số unread, API vẫn trả về cả thông báo đã đọc và chưa đọc (tương thích ngược cho Staff/Admin).
8. **Điều kiện tiên quyết:** Backend đang chạy cố định tại http://localhost:8989 (@BeforeAll fail nếu không kết nối được socket); JWT client u2 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /notifications/my?page=0&size=1 (không có tham số unread) và lấy totalElements | Token client u2, page=0, size=1 | HTTP 200; đọc được giá trị tổng số thông báo (all). |
| 2 | Gửi GET /notifications/my?page=0&size=1&unread=true và so sánh tổng số | Token client u2, page=0, size=1, unread=true | HTTP 200; kiểm tra khẳng định all >= unread. |

10. **Input từng bước:**
   - Bước 1: Token client u2, page=0, size=1
   - Bước 2: Token client u2, page=0, size=1, unread=true
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; đọc được giá trị tổng số thông báo (all).
   - Bước 2: HTTP 200; kiểm tra khẳng định all >= unread.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/notification/NotificationFilterTest.java`
13. **Ghi chú:** Chỉ đọc dữ liệu, không gây side-effect. Class này chưa đăng ký trong testapi.ps1.
