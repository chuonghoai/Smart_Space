# SMP-144: Parse DelegationPage dạng camelCase và xử lý JSON null

1. **Mã số test case:** SMP-144
2. **Tên test case:** Parse DelegationPage dạng camelCase và xử lý JSON null
3. **Project:** Flutter Staff
4. **Chức năng:** Nhờ đồng nghiệp làm giùm (Delegation)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra DelegationPage.fromJson đọc cấu trúc PageResponse dạng camelCase (currentPage, totalPages, content), tính đúng cờ hasMore khi currentPage + 1 < totalPages, và trả về danh sách items rỗng khi JSON là null.
7. **Mục đích kiểm thử:** Đảm bảo model phân trang xử lý đúng định dạng phản hồi từ backend và an toàn với dữ liệu null.
8. **Điều kiện tiên quyết:** Dữ liệu JSON trang 0/2 có 1 phần tử từ _delegationJson('1') và hàm itemFromJson là DelegationModel.fromJson.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi DelegationPage.fromJson với JSON {'currentPage': 0, 'totalPages': 2, 'content': [_delegationJson('1')]}. | currentPage=0, totalPages=2, 1 item id='1' | page.items.single.id = '1' và page.hasMore = true. |
| 2 | Gọi DelegationPage.fromJson(null, DelegationModel.fromJson). | json = null | Trả về DelegationPage có items rỗng. |

10. **Input từng bước:**
   - Bước 1: currentPage=0, totalPages=2, 1 item id='1'
   - Bước 2: json = null
11. **Kỳ vọng từng bước:**
   - Bước 1: page.items.single.id = '1' và page.hasMore = true.
   - Bước 2: Trả về DelegationPage có items rỗng.
12. **File test tương ứng:** `smartspace_staff/test/features/delegation/delegation_test.dart`
13. **Ghi chú:** Không có.
