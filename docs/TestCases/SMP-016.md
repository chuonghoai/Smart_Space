# SMP-016: Bỏ qua response của request bản đồ cũ về sau request mới

1. **Mã số test case:** SMP-016
2. **Tên test case:** Bỏ qua response của request bản đồ cũ về sau request mới
3. **Project:** Flutter Client
4. **Chức năng:** Bản đồ phản ánh (Map Reports Provider)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra khi gửi 2 request liên tiếp (first cho viewport, second cho insideViewport với force=true), nếu request thứ 2 hoàn tất với ['new'] trước rồi request đầu mới hoàn tất với ['stale'], state.reports chỉ giữ ['new'].
7. **Mục đích kiểm thử:** Đảm bảo phản hồi mạng đến muộn của thao tác bản đồ cũ không ghi đè dữ liệu mới nhất.
8. **Điều kiện tiên quyết:** _FakeReportRepo lưu 2 Completer đang chờ cho 2 request liên tiếp.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi loadForViewport(viewport) (first) và loadForViewport(insideViewport, force: true) (second) | 2 pending requests | repo.pending có 2 request |
| 2 | Complete pending[1] với ['new'] trước, rồi complete pending[0] với ['stale'] | pending[1]=['new']; pending[0]=['stale'] | notifier.state.reports chỉ chứa ID ['new'] |

10. **Input từng bước:**
   - Bước 1: 2 pending requests
   - Bước 2: pending[1]=['new']; pending[0]=['stale']
11. **Kỳ vọng từng bước:**
   - Bước 1: repo.pending có 2 request
   - Bước 2: notifier.state.reports chỉ chứa ID ['new']
12. **File test tương ứng:** `smartspace_client/test/features/reports/map_reports_provider_test.dart`
13. **Ghi chú:** Không có.
