# SMP-076: Parse danh sách phản ánh bản đồ và cờ truncated từ JSON

1. **Mã số test case:** SMP-076
2. **Tên test case:** Parse danh sách phản ánh bản đồ và cờ truncated từ JSON
3. **Project:** Flutter Admin
4. **Chức năng:** Bản đồ Admin (AdminMapReportsResult)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AdminMapReportsResult.fromJson giải mã chính xác mảng reports (bao gồm chuyển đổi trạng thái 'PENDING' sang isPending) và cờ truncated=true.
7. **Mục đích kiểm thử:** Xác minh AdminMapReportsResult đọc đúng danh sách điểm phản ánh và trạng thái bị cắt giới hạn (truncated) từ API bản đồ.
8. **Điều kiện tiên quyết:** TestWidgetsFlutterBinding.ensureInitialized() đã gọi; setUp gán SharedPreferences.setMockInitialValues({}).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi AdminMapReportsResult.fromJson với JSON chứa 1 report PENDING và truncated=true. | {'reports': [{'id': 'a', 'title': 'A', 'status': 'PENDING', 'latitude': 1, 'longitude': 2}], 'truncated': true} | result.reports.single.id là 'a', result.reports.single.isPending là true và result.truncated là true. |

10. **Input từng bước:**
   - Bước 1: {'reports': [{'id': 'a', 'title': 'A', 'status': 'PENDING', 'latitude': 1, 'longitude': 2}], 'truncated': true}
11. **Kỳ vọng từng bước:**
   - Bước 1: result.reports.single.id là 'a', result.reports.single.isPending là true và result.truncated là true.
12. **File test tương ứng:** `smartspace_admin/test/features/map/admin_map_test.dart`
13. **Ghi chú:** Không có.
