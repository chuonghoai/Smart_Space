# SMP-177: Chặn 403 đối với Staff và Client ở API Hội đồng quản trị

1. **Mã số test case:** SMP-177
2. **Tên test case:** Chặn 403 đối với Staff và Client ở API Hội đồng quản trị
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản Hội đồng quản trị (/admin/admins)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Staff bị chặn 403 khi gọi GET /admin/admins và Client bị chặn 403 khi gọi GET /admin/admins hoặc PUT /admin/admins/u1/status.
7. **Mục đích kiểm thử:** Đảm bảo phân quyền chỉ cho phép admin xem và cập nhật trạng thái tài khoản Hội đồng quản trị.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); CSDL có seed_data.sql (u1=admin, u5=staff, u2=client); JWT ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /admin/admins bằng token Staff (u5, ROLE_staff) | Token staff1@gmail.com (u5, ROLE_staff) | HTTP 403 Forbidden. |
| 2 | Gửi GET /admin/admins bằng token Client (u2, ROLE_client) | Token user@gmail.com (u2, ROLE_client) | HTTP 403 Forbidden. |
| 3 | Gửi PUT /admin/admins/u1/status với body {"status":"blocked"} bằng token Client (u2) | Token user@gmail.com (u2, ROLE_client), body {"status":"blocked"} | HTTP 403 Forbidden. |

10. **Input từng bước:**
   - Bước 1: Token staff1@gmail.com (u5, ROLE_staff)
   - Bước 2: Token user@gmail.com (u2, ROLE_client)
   - Bước 3: Token user@gmail.com (u2, ROLE_client), body {"status":"blocked"}
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 403 Forbidden.
   - Bước 2: HTTP 403 Forbidden.
   - Bước 3: HTTP 403 Forbidden.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminAccountManagementTest.java`
13. **Ghi chú:** Không gây side-effect. Class này chưa đăng ký trong testapi.ps1.
