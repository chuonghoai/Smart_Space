# SMP-179: Trả về 404 khi cập nhật trạng thái cho tài khoản staff qua API /admin/admins

1. **Mã số test case:** SMP-179
2. **Tên test case:** Trả về 404 khi cập nhật trạng thái cho tài khoản staff qua API /admin/admins
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản Hội đồng quản trị (/admin/admins/{id}/status)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gửi PUT /admin/admins/u5/status với status "blocked" (trong đó u5 là staff theo seed_data.sql) bị từ chối với HTTP 404.
7. **Mục đích kiểm thử:** Đảm bảo endpoint /admin/admins/{id}/status chỉ thao tác trên các tài khoản thuộc vai trò admin, không tác động nhầm tới staff.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); CSDL có u5 là tài khoản ROLE_staff; JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin u1 gửi PUT /admin/admins/u5/status với status "blocked" | Target id = "u5", body {"status":"blocked"} | HTTP 404 Not Found. |

10. **Input từng bước:**
   - Bước 1: Target id = "u5", body {"status":"blocked"}
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 404 Not Found.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminAccountManagementTest.java`
13. **Ghi chú:** Không gây side-effect. Class này chưa đăng ký trong testapi.ps1.
