# SMP-206: Bản đồ Client trả về 400 khi bounds không hợp lệ

1. **Mã số test case:** SMP-206
2. **Tên test case:** Bản đồ Client trả về 400 khi bounds không hợp lệ
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Client
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra GET /reports/map trả về HTTP 400 khi truyền min_lat > max_lat, latitude ngoài [-90, 90] hoặc longitude ngoài [-180, 180].
7. **Mục đích kiểm thử:** Đảm bảo API bản đồ Client validate tọa độ địa lý trước khi truy vấn.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; JWT client u2 hợp lệ.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /reports/map với min_lat=10.9 và max_lat=10.7. | JWT client u2; min_lat=10.9, max_lat=10.7, min_lng=106.6, max_lng=106.8 | HTTP 400. |
| 2 | Gửi GET /reports/map với min_lat=-95. | JWT client u2; min_lat=-95, max_lat=10.7, min_lng=106.6, max_lng=106.8 | HTTP 400. |
| 3 | Gửi GET /reports/map với max_lng=190. | JWT client u2; min_lat=10.7, max_lat=10.9, min_lng=106.6, max_lng=190 | HTTP 400. |

10. **Input từng bước:**
   - Bước 1: JWT client u2; min_lat=10.9, max_lat=10.7, min_lng=106.6, max_lng=106.8
   - Bước 2: JWT client u2; min_lat=-95, max_lat=10.7, min_lng=106.6, max_lng=106.8
   - Bước 3: JWT client u2; min_lat=10.7, max_lat=10.9, min_lng=106.6, max_lng=190
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 400.
   - Bước 2: HTTP 400.
   - Bước 3: HTTP 400.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/MapReportsTest.java`
13. **Ghi chú:** Không có.
