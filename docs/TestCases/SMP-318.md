# SMP-318: Xử lý query thiếu tham số, focus trống hoặc toạ độ sai định dạng

1. **Mã số test case:** SMP-318
2. **Tên test case:** Xử lý query thiếu tham số, focus trống hoặc toạ độ sai định dạng
3. **Project:** Flutter Shared (mobile_shared)
4. **Chức năng:** Bản đồ dùng chung (MapFocusTarget)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra MapFocusTarget.fromQueryParameters trả về null cho 3 trường hợp lỗi dữ liệu: thiếu lng, focus chỉ gồm khoảng trắng ' ', và lat không parse được sang số ('abc').
7. **Mục đích kiểm thử:** Đảm bảo deep link hoặc query param bị thiếu/hỏng không gây lỗi parse và trả về null an toàn.
8. **Điều kiện tiên quyết:** Tồn tại phương thức MapFocusTarget.fromQueryParameters.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi fromQueryParameters với 3 Map: {'focus': 'r-1', 'lat': '10.8'}, {'focus': ' ', 'lat': '10.8', 'lng': '106.6'}, và {'focus': 'r-1', 'lat': 'abc', 'lng': '106.6'}. | 3 bộ query thiếu lng / focus khoảng trắng / lat='abc' | Cả 3 lần gọi đều trả về null. |

10. **Input từng bước:**
   - Bước 1: 3 bộ query thiếu lng / focus khoảng trắng / lat='abc'
11. **Kỳ vọng từng bước:**
   - Bước 1: Cả 3 lần gọi đều trả về null.
12. **File test tương ứng:** `mobile_shared/test/features/map/map_focus_target_test.dart`
13. **Ghi chú:** Không có.
