# SMP-196: Admin phát thông báo thử nghiệm đa ngôn ngữ (VI/EN) tới toàn bộ người dùng

1. **Mã số test case:** SMP-196
2. **Tên test case:** Admin phát thông báo thử nghiệm đa ngôn ngữ (VI/EN) tới toàn bộ người dùng
3. **Project:** Spring Boot Backend
4. **Chức năng:** Phát thông báo thử nghiệm đa ngôn ngữ (POST /notifications/broadcast-test)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin u1 gửi POST /notifications/broadcast-test với body rỗng nhận HTTP 200, success=true, message thành công, data khác null với totalSent > 0 và totalSent == viCount + enCount.
7. **Mục đích kiểm thử:** Xác minh API gửi thông báo thử nghiệm đa ngôn ngữ (VI/EN theo cấu hình người dùng trong DB) hoạt động thành công và thống kê khớp số lượng đã gửi.
8. **Điều kiện tiên quyết:** Backend đang chạy cố định tại http://localhost:8989 (@BeforeAll fail nếu không kết nối được socket); CSDL có ít nhất 1 người dùng; JWT admin u1 (admin@gmail.com, ROLE_admin) ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tạo Admin JWT (u1, admin@gmail.com, ROLE_admin) và gửi POST /notifications/broadcast-test không kèm body | Token admin u1, body rỗng (noBody) | HTTP 200 OK. |
| 2 | Phân tích JSON phản hồi và kiểm tra các trường success, message, data.totalSent, viCount, enCount | Response body JSON | success=true; message chứa "notification.test.success", "thông báo test" hoặc "test notification"; data khác null; totalSent > 0 và totalSent == viCount + enCount. |

10. **Input từng bước:**
   - Bước 1: Token admin u1, body rỗng (noBody)
   - Bước 2: Response body JSON
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200 OK.
   - Bước 2: success=true; message chứa "notification.test.success", "thông báo test" hoặc "test notification"; data khác null; totalSent > 0 và totalSent == viCount + enCount.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/notification/SendTestNotificationTest.java`
13. **Ghi chú:** Có side-effect thực tế trên CSDL/FCM (tạo và gửi thông báo thử nghiệm tới toàn bộ người dùng). Class đã đăng ký trong testapi.ps1 dưới lệnh SendTestNotification.
