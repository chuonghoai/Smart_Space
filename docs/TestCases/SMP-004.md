# SMP-004: Tải thêm và làm mới giữ nguyên bộ lọc thông báo

1. **Mã số test case:** SMP-004
2. **Tên test case:** Tải thêm và làm mới giữ nguyên bộ lọc thông báo
3. **Project:** Flutter Client
4. **Chức năng:** Thông báo (Notifications)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra khi đang bật unreadOnly=true, tải trang 0 với 20 mục ('n0'..'n19'), gọi fetchNotifications(loadMore: true) gửi page=1 kèm unreadOnly=true, nhận 1 mục 'n20' khiến hasMore=false; sau đó gọi fetchNotifications() gửi page=0 vẫn giữ unreadOnly=true.
7. **Mục đích kiểm thử:** Đảm bảo cả tải thêm trang (loadMore) và kéo làm mới (refresh) đều giữ nguyên bộ lọc unreadOnly đang chọn.
8. **Điều kiện tiên quyết:** NotificationNotifier dùng _FakeNotificationRepo; trang 0 trả về đủ 20 mục để cho phép loadMore.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Bật setUnreadOnly(true) và hoàn tất trang 0 với 20 thông báo 'n0'..'n19' | setUnreadOnly(true); 20 items | Tải thành công trang 0 |
| 2 | Gọi fetchNotifications(loadMore: true) và hoàn tất với [_notif('n20')] | loadMore=true; response=[_notif('n20')] | repo.calls.last == (page: 1, unreadOnly: true) và state.hasMore == false |
| 3 | Gọi lại fetchNotifications() để làm mới | fetchNotifications() | repo.calls.last == (page: 0, unreadOnly: true) |

10. **Input từng bước:**
   - Bước 1: setUnreadOnly(true); 20 items
   - Bước 2: loadMore=true; response=[_notif('n20')]
   - Bước 3: fetchNotifications()
11. **Kỳ vọng từng bước:**
   - Bước 1: Tải thành công trang 0
   - Bước 2: repo.calls.last == (page: 1, unreadOnly: true) và state.hasMore == false
   - Bước 3: repo.calls.last == (page: 0, unreadOnly: true)
12. **File test tương ứng:** `smartspace_client/test/features/notifications/notification_filter_test.dart`
13. **Ghi chú:** Không có.
