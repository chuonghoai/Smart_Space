# SMP-342: Kiểm tra GET /news công khai trả về HTTP 200 và danh sách mảng

1. **Mã số test case:** SMP-342
2. **Tên test case:** Kiểm tra GET /news công khai trả về HTTP 200 và danh sách mảng
3. **Project:** Spring Boot Backend
4. **Chức năng:** Tin tức (NewsController)
5. **Loại kiểm thử:** API Automation Test (Playwright)
6. **Mô tả test case:** Gửi GET /news không kèm token xác thực và kiểm tra HTTP 200 cùng dữ liệu trả về là danh sách dạng mảng.
7. **Mục đích kiểm thử:** Xác minh endpoint công khai GET /news hoạt động bình thường đúng với SecurityConfig.
8. **Điều kiện tiên quyết:** Backend đang chạy tại PW_BACKEND_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /news không kèm token | GET /news | HTTP 200 OK, success=true, Array.isArray(data)=true |

10. **Input từng bước:**
   - Bước 1: GET /news
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200 OK, success=true, Array.isArray(data)=true
12. **File test tương ứng:** `playwright/backend/public-and-protected-api.spec.ts`
13. **Ghi chú:** Không làm thay đổi dữ liệu tin tức trong DB.
