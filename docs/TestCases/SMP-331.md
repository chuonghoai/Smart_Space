# SMP-331: ViewportLoadGate.invalidate buộc tải lại khung đã tải

1. **Mã số test case:** SMP-331
2. **Tên test case:** ViewportLoadGate.invalidate buộc tải lại khung đã tải
3. **Project:** Flutter Shared (mobile_shared)
4. **Chức năng:** Khung nhìn & Cluster bản đồ (MapViewport)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra sau khi đã gate.succeed(gate.begin(viewport)!, truncated: false), nếu gọi gate.invalidate() thì lời gọi gate.begin(inside) tiếp theo trả về request khác null.
7. **Mục đích kiểm thử:** Đảm bảo khi người dùng thay đổi bộ lọc bản đồ, gate reset cache để tải dữ liệu mới theo bộ lọc.
8. **Điều kiện tiên quyết:** gate đã hoàn tất succeed(viewport, truncated: false).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi gate.succeed(gate.begin(viewport)!, truncated: false), gọi gate.invalidate(), rồi gọi gate.begin(inside). | succeed(viewport) -> invalidate() -> begin(inside) | gate.begin(inside) trả về khác null. |

10. **Input từng bước:**
   - Bước 1: succeed(viewport) -> invalidate() -> begin(inside)
11. **Kỳ vọng từng bước:**
   - Bước 1: gate.begin(inside) trả về khác null.
12. **File test tương ứng:** `mobile_shared/test/features/map/map_viewport_test.dart`
13. **Ghi chú:** Không có.
