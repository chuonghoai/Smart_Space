# SMP-314: Kiểm tra định dạng khóa Redis theo từng khung thời gian mật độ

1. **Mã số test case:** SMP-314
2. **Tên test case:** Kiểm tra định dạng khóa Redis theo từng khung thời gian mật độ
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ mật độ báo cáo H3 (ReportDensityServiceImpl)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra các phương thức getKeyCells, getKeyGeo và getKeyMeta trên ReportDensityServiceImpl sinh đúng tên khóa Redis cho EDensityTimeframe.ALL ("map:density:cells", "map:density:geo", "map:density:meta"), MONTH_1 ("map:density:1m:cells", "map:density:1m:geo", "map:density:1m:meta") và getKeyCells(MONTH_12) ("map:density:12m:cells").
7. **Mục đích kiểm thử:** Xác minh quy ước đặt tên khóa cache mật độ trên Redis tách biệt theo từng khung thời gian.
8. **Điều kiện tiên quyết:** @BeforeEach khởi tạo ReportDensityServiceImpl.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Kiểm tra key cho EDensityTimeframe.ALL | EDensityTimeframe.ALL | getKeyCells="map:density:cells", getKeyGeo="map:density:geo", getKeyMeta="map:density:meta" |
| 2 | Kiểm tra key cho EDensityTimeframe.MONTH_1 và MONTH_12 | EDensityTimeframe.MONTH_1, EDensityTimeframe.MONTH_12 | MONTH_1 -> "map:density:1m:cells", "map:density:1m:geo", "map:density:1m:meta"; getKeyCells(MONTH_12) -> "map:density:12m:cells" |

10. **Input từng bước:**
   - Bước 1: EDensityTimeframe.ALL
   - Bước 2: EDensityTimeframe.MONTH_1, EDensityTimeframe.MONTH_12
11. **Kỳ vọng từng bước:**
   - Bước 1: getKeyCells="map:density:cells", getKeyGeo="map:density:geo", getKeyMeta="map:density:meta"
   - Bước 2: MONTH_1 -> "map:density:1m:cells", "map:density:1m:geo", "map:density:1m:meta"; getKeyCells(MONTH_12) -> "map:density:12m:cells"
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/report/ReportDensityServiceTest.java`
13. **Ghi chú:** Không có.
