# SMP-218: Quy trình E2E xử lý lại phản ánh và ghi đè đánh giá mới

1. **Mã số test case:** SMP-218
2. **Tên test case:** Quy trình E2E xử lý lại phản ánh và ghi đè đánh giá mới
3. **Project:** Spring Boot Backend
4. **Chức năng:** Đánh giá và xử lý lại phản ánh
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Mô phỏng đầy đủ 8 bước: Client tạo report -> Admin giao Staff u5 -> Staff hoàn tất lần 1 -> Client đánh giá Unresolved -> Admin reopen về processing -> Staff hoàn tất lần 2 -> kiểm tra reset review cũ về null -> Client đánh giá mới 5 sao.
7. **Mục đích kiểm thử:** Đảm bảo luồng mở lại xử lý phản ánh reset đúng dữ liệu đánh giá cũ và cho phép Client gửi đánh giá mới ghi đè.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; các user seed u1 (admin), u2 (client), u5 (staff) tồn tại trong DB.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Client u2 tạo report mới qua POST /reports và Admin u1 gán cho Staff u5 (severity=low). | JWT u2 tạo report "Bồn rửa tay sảnh B bị rò rỉ nước"; JWT u1 assign u5 | Cả 2 API trả HTTP 200; lấy được reportId. |
| 2 | Staff u5 hoàn tất lần 1 qua POST /reports/{id}/complete, sau đó Client u2 gửi POST /reports/{id}/review với is_resolved=false. | JWT u5 complete lần 1; JWT u2 review Unresolved kèm reason và 1 image_url | Cả 2 API trả HTTP 200. |
| 3 | Admin u1 gọi PATCH /admin/reports/{id}/status với {"status": "processing"}, sau đó Staff u5 hoàn tất lần 2 qua POST /reports/{id}/complete. | JWT u1 reopen về processing; JWT u5 complete lần 2 | Cả 2 API trả HTTP 200. |
| 4 | Client u2 gọi GET /reports/{id} để kiểm tra trạng thái reset review. | JWT u2; GET /reports/{reportId} | HTTP 200; status="processed"; is_review_resolved, reviewed_at và review_note đều là null. |
| 5 | Client u2 gửi đánh giá mới với is_resolved=true, rating=5 qua POST /reports/{id}/review. | JWT u2; Body: {"is_resolved": true, "rating": 5, "reason": "Lần xử lý này rất tốt..."} | HTTP 200; is_review_resolved=true, rating=5, reviewed_at khác null và review_note khớp nội dung mới. |

10. **Input từng bước:**
   - Bước 1: JWT u2 tạo report "Bồn rửa tay sảnh B bị rò rỉ nước"; JWT u1 assign u5
   - Bước 2: JWT u5 complete lần 1; JWT u2 review Unresolved kèm reason và 1 image_url
   - Bước 3: JWT u1 reopen về processing; JWT u5 complete lần 2
   - Bước 4: JWT u2; GET /reports/{reportId}
   - Bước 5: JWT u2; Body: {"is_resolved": true, "rating": 5, "reason": "Lần xử lý này rất tốt..."}
11. **Kỳ vọng từng bước:**
   - Bước 1: Cả 2 API trả HTTP 200; lấy được reportId.
   - Bước 2: Cả 2 API trả HTTP 200.
   - Bước 3: Cả 2 API trả HTTP 200.
   - Bước 4: HTTP 200; status="processed"; is_review_resolved, reviewed_at và review_note đều là null.
   - Bước 5: HTTP 200; is_review_resolved=true, rating=5, reviewed_at khác null và review_note khớp nội dung mới.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/ReviewReportRehandledTest.java`
13. **Ghi chú:** Tạo và cập nhật 1 bản ghi report thật qua 8 lời gọi API trong DB.
