# SMP-334: Chuyển đổi ClusterMarker sang GeoJSON FeatureCollection đầy đủ thuộc tính

1. **Mã số test case:** SMP-334
2. **Tên test case:** Chuyển đổi ClusterMarker sang GeoJSON FeatureCollection đầy đủ thuộc tính
3. **Project:** Flutter Shared (mobile_shared)
4. **Chức năng:** Khung nhìn & Cluster bản đồ (MapViewport)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra ClusterMapLayer.toFeatureCollection chuyển ClusterMarker(id: 'a', latitude: 10.5, longitude: 106.5, isAlert: true, isEmphasized: false, styleKey: 'pending') thành chuỗi GeoJSON có geometry Point với coordinates [106.5, 10.5] ([lng, lat]) và đầy đủ properties: id, isAlert, isEmphasized, imageKey, fallbackKey.
7. **Mục đích kiểm thử:** Đảm bảo dữ liệu GeoJSON cấp cho Mapbox tuân thủ đúng chuẩn [longitude, latitude] và đủ thuộc tính render expression.
8. **Điều kiện tiên quyết:** Khởi tạo marker = ClusterMarker(id: 'a', latitude: 10.5, longitude: 106.5, imageUrl: '', isAlert: true, isEmphasized: false, styleKey: 'pending').
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi ClusterMapLayer.toFeatureCollection([marker], (m) => 'img-${m.id}', (m) => 'fallback-${m.styleKey}') và parse JSON kết quả. | 1 ClusterMarker hợp lệ | feature['geometry'] là {'type': 'Point', 'coordinates': [106.5, 10.5]} và feature['properties'] gồm {'id': 'a', 'isAlert': true, 'isEmphasized': false, 'imageKey': 'img-a', 'fallbackKey': 'fallback-pending'}. |

10. **Input từng bước:**
   - Bước 1: 1 ClusterMarker hợp lệ
11. **Kỳ vọng từng bước:**
   - Bước 1: feature['geometry'] là {'type': 'Point', 'coordinates': [106.5, 10.5]} và feature['properties'] gồm {'id': 'a', 'isAlert': true, 'isEmphasized': false, 'imageKey': 'img-a', 'fallbackKey': 'fallback-pending'}.
12. **File test tương ứng:** `mobile_shared/test/features/map/map_viewport_test.dart`
13. **Ghi chú:** Không có.
