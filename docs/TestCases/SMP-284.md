# SMP-284: Tự động tạo tài khoản client mới khi đăng nhập lần đầu qua loginGoogle

1. **Mã số test case:** SMP-284
2. **Tên test case:** Tự động tạo tài khoản client mới khi đăng nhập lần đầu qua loginGoogle
3. **Project:** Spring Boot Backend
4. **Chức năng:** Cấp tài khoản khi đăng nhập Google (AuthenticationService)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra loginGoogle với role ERole.client khi email chưa có trong DB sẽ tự động lưu User mới với role == ERole.client, status == EUserStatus.active và trả về kết quả đăng nhập khác null.
7. **Mục đích kiểm thử:** Xác minh chính sách tự động cấp tài khoản qua Google login áp dụng đúng cho vai trò client.
8. **Điều kiện tiên quyết:** Dùng spy AuthenticationService stub verifyGoogleIdToken trả về Payload(email="someone@example.com", name="Someone"). Mock userRepository.findByEmailAndRole("someone@example.com", ERole.client) = Optional.empty(); mock userRepository.save(any(User.class)) gán id="user-1"; stub jwtService sinh access/refresh token.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.loginGoogle(googleRequest(ERole.client)) khi user client chưa tồn tại | GoogleLoginRequest(idToken="google-id-token", deviceId="device-1", role=ERole.client) | Trả về response khác null |
| 2 | Bắt đối tượng User được lưu bằng ArgumentCaptor và kiểm tra thuộc tính | verify(userRepository).save(captor.capture()) | User được lưu có role == ERole.client và status == EUserStatus.active |

10. **Input từng bước:**
   - Bước 1: GoogleLoginRequest(idToken="google-id-token", deviceId="device-1", role=ERole.client)
   - Bước 2: verify(userRepository).save(captor.capture())
11. **Kỳ vọng từng bước:**
   - Bước 1: Trả về response khác null
   - Bước 2: User được lưu có role == ERole.client và status == EUserStatus.active
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/auth/AuthenticationServiceSecurityTest.java`
13. **Ghi chú:** Thuộc nhóm @Nested GoogleProvisioning.
