# SMP-347: Màn hình đăng nhập Flutter Admin Web responsive trên Mobile (390x844)

1. **Mã số test case:** SMP-347
2. **Tên test case:** Màn hình đăng nhập Flutter Admin Web responsive trên Mobile (390x844)
3. **Project:** Flutter Admin
4. **Chức năng:** Giao diện Responsive Đăng nhập Admin
5. **Loại kiểm thử:** Web UI Automation Test (Playwright)
6. **Mô tả test case:** Mở Flutter Admin Web với viewport 390x844 (Mobile breakpoint < 850px), xác minh render sạch không pageerror và có đủ nút Đăng nhập cùng tối thiểu 2 textbox.
7. **Mục đích kiểm thử:** Xác minh AdminLoginScreen chuyển sang bố cục Mobile trên trình duyệt thật không lỗi runtime.
8. **Điều kiện tiên quyết:** Flutter Admin Web server đang chạy tại PW_ADMIN_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Đặt viewport 390x844 và mở Flutter Admin Web | viewport=390x844 | Chuyển sang /login không có pageerror |
| 2 | Kiểm tra nút Đăng nhập và số lượng ô textbox | Semantics tree | Nút 'Đăng nhập' hiển thị; số lượng textbox >= 2 |

10. **Input từng bước:**
   - Bước 1: viewport=390x844
   - Bước 2: Semantics tree
11. **Kỳ vọng từng bước:**
   - Bước 1: Chuyển sang /login không có pageerror
   - Bước 2: Nút 'Đăng nhập' hiển thị; số lượng textbox >= 2
12. **File test tương ứng:** `playwright/admin/admin-web.spec.ts`
13. **Ghi chú:** Không có.
