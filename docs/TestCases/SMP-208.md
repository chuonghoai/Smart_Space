# SMP-208: Bản đồ Client cắt danh sách đúng limit và đặt truncated = true

1. **Mã số test case:** SMP-208
2. **Tên test case:** Bản đồ Client cắt danh sách đúng limit và đặt truncated = true
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Client
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Tạo 2 report nằm trong cùng một khung nhìn nhỏ quanh tọa độ ngẫu nhiên và gọi GET /reports/map với limit=1.
7. **Mục đích kiểm thử:** Đảm bảo tham số limit giới hạn đúng số report trả về và gắn cờ truncated=true khi bị cắt.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; user seed u2 (client) tồn tại trong DB.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Client u2 tạo 2 report tại point và (point[0]+0.0001, point[1]+0.0001) qua POST /reports. | JWT client u2; 2 payload POST /reports | Cả 2 request trả về HTTP 200. |
| 2 | Client u2 gọi GET /reports/map với bounds point ± 0.0005 và limit=1. | JWT client u2; limit=1 | HTTP 200; data.reports.size() == 1 và data.truncated == true. |

10. **Input từng bước:**
   - Bước 1: JWT client u2; 2 payload POST /reports
   - Bước 2: JWT client u2; limit=1
11. **Kỳ vọng từng bước:**
   - Bước 1: Cả 2 request trả về HTTP 200.
   - Bước 2: HTTP 200; data.reports.size() == 1 và data.truncated == true.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/MapReportsTest.java`
13. **Ghi chú:** Test tạo 2 report mới vào DB khi chạy.
