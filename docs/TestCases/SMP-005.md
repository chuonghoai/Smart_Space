# SMP-005: Kiểm tra logic quá hạn ReportDeadlineHelper qua vòng đời xử lý

1. **Mã số test case:** SMP-005
2. **Tên test case:** Kiểm tra logic quá hạn ReportDeadlineHelper qua vòng đời xử lý
3. **Project:** Flutter Client
4. **Chức năng:** Hạn xử lý phản ánh (Report Deadline)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra hàm ReportDeadlineHelper.isOverdue qua 4 mốc: đang processing quá pastDeadline (true), đã processed sau pastDeadline (true), mở lại processing với futureReopenDeadline dù còn resolvedAt cũ (false), và sau khi vượt futureReopenDeadline (true).
7. **Mục đích kiểm thử:** Xác minh logic tính quá hạn phản ánh hoạt động đúng trong cả trường hợp hoàn thành trễ và mở lại xử lý với hạn mới.
8. **Điều kiện tiên quyết:** Dùng các mốc DateTime cố định: now=2026-11-16 12:00, pastDeadline=2026-11-10 12:00, resolvedAt=2026-11-12 09:00, futureReopenDeadline=2026-11-21 12:00.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Kiểm tra isOverdue khi status='processing', deadline=pastDeadline, now=2026-11-16 | status='processing', deadline=2026-11-10, now=2026-11-16 | Trả về true |
| 2 | Kiểm tra isOverdue khi status='processed', resolvedAt=2026-11-12 > pastDeadline | status='processed', deadline=2026-11-10, resolvedAt=2026-11-12 | Trả về true (giữ trạng thái quá hạn) |
| 3 | Kiểm tra isOverdue khi mở lại status='processing' với futureReopenDeadline=2026-11-21 và vẫn có resolvedAt cũ | status='processing', deadline=2026-11-21, resolvedAt=2026-11-12, now=2026-11-16 | Trả về false (xóa quá hạn cũ) |
| 4 | Kiểm tra isOverdue khi now=2026-11-22 vượt quá futureReopenDeadline | status='processing', deadline=2026-11-21, now=2026-11-22 | Trả về true (quá hạn trở lại) |

10. **Input từng bước:**
   - Bước 1: status='processing', deadline=2026-11-10, now=2026-11-16
   - Bước 2: status='processed', deadline=2026-11-10, resolvedAt=2026-11-12
   - Bước 3: status='processing', deadline=2026-11-21, resolvedAt=2026-11-12, now=2026-11-16
   - Bước 4: status='processing', deadline=2026-11-21, now=2026-11-22
11. **Kỳ vọng từng bước:**
   - Bước 1: Trả về true
   - Bước 2: Trả về true (giữ trạng thái quá hạn)
   - Bước 3: Trả về false (xóa quá hạn cũ)
   - Bước 4: Trả về true (quá hạn trở lại)
12. **File test tương ứng:** `smartspace_client/test/features/reports/deadline_ui_test.dart`
13. **Ghi chú:** Không có.
