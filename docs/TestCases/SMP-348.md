# SMP-348: Validate form đăng nhập Admin Web khi bỏ trống Email và Mật khẩu

1. **Mã số test case:** SMP-348
2. **Tên test case:** Validate form đăng nhập Admin Web khi bỏ trống Email và Mật khẩu
3. **Project:** Flutter Admin
4. **Chức năng:** Validation Đăng nhập Admin (LoginController)
5. **Loại kiểm thử:** Web UI Automation Test (Playwright)
6. **Mô tả test case:** Mở Admin Web tại /login, nhấn ngay nút 'Đăng nhập' khi chưa nhập Email/Mật khẩu và kiểm tra hiển thị thông báo 'Vui lòng nhập email và mật khẩu'.
7. **Mục đích kiểm thử:** Xác minh logic kiểm tra đầu vào phía client trước khi gửi request API đăng nhập.
8. **Điều kiện tiên quyết:** Flutter Admin Web server đang chạy tại PW_ADMIN_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Boot Flutter Admin Web tới /login | Không nhập email và password | Hiển thị màn hình đăng nhập |
| 2 | Nhấn nút 'Đăng nhập' | Click button 'Đăng nhập' | Semantics hiển thị 'Vui lòng nhập email và mật khẩu' và URL giữ nguyên ở /login |

10. **Input từng bước:**
   - Bước 1: Không nhập email và password
   - Bước 2: Click button 'Đăng nhập'
11. **Kỳ vọng từng bước:**
   - Bước 1: Hiển thị màn hình đăng nhập
   - Bước 2: Semantics hiển thị 'Vui lòng nhập email và mật khẩu' và URL giữ nguyên ở /login
12. **File test tương ứng:** `playwright/admin/admin-web.spec.ts`
13. **Ghi chú:** Thông báo lấy từ l10n.pleaseEnterEmailAndPassword trong app_vi.arb.
