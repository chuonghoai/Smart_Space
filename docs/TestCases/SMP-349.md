# SMP-349: Điều hướng từ Đăng nhập sang Quên mật khẩu trên Admin Web

1. **Mã số test case:** SMP-349
2. **Tên test case:** Điều hướng từ Đăng nhập sang Quên mật khẩu trên Admin Web
3. **Project:** Flutter Admin
4. **Chức năng:** Điều hướng Quên mật khẩu (GoRouter Admin)
5. **Loại kiểm thử:** Web UI Automation Test (Playwright)
6. **Mô tả test case:** Trên màn hình đăng nhập Admin Web, nhấn nút 'Quên mật khẩu?' và kiểm tra GoRouter mở màn hình AdminForgotPasswordScreen.
7. **Mục đích kiểm thử:** Xác minh liên kết điều hướng sang luồng quên mật khẩu trên Admin Web hoạt động đúng.
8. **Điều kiện tiên quyết:** Flutter Admin Web server đang chạy tại PW_ADMIN_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Boot Flutter Admin Web tới /login | URL /login | Nút 'Quên mật khẩu?' hiển thị |
| 2 | Nhấn nút 'Quên mật khẩu?' | Click button 'Quên mật khẩu?' | Màn hình Quên mật khẩu hiển thị 'Nhập email của bạn để nhận mã OTP' và nút 'Quay lại đăng nhập' |

10. **Input từng bước:**
   - Bước 1: URL /login
   - Bước 2: Click button 'Quên mật khẩu?'
11. **Kỳ vọng từng bước:**
   - Bước 1: Nút 'Quên mật khẩu?' hiển thị
   - Bước 2: Màn hình Quên mật khẩu hiển thị 'Nhập email của bạn để nhận mã OTP' và nút 'Quay lại đăng nhập'
12. **File test tương ứng:** `playwright/admin/admin-web.spec.ts`
13. **Ghi chú:** AdminLoginScreen điều hướng bằng context.push(RouterPath.forgotPassword) nên theo mặc định GoRouter trên Web URL thanh địa chỉ vẫn giữ /login trong khi màn hình đích đã được đẩy vào Navigator stack.
