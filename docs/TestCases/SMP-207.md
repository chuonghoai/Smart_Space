# SMP-207: Bản đồ Client lọc đúng bounds, có trường severity và ẩn report rejected

1. **Mã số test case:** SMP-207
2. **Tên test case:** Bản đồ Client lọc đúng bounds, có trường severity và ẩn report rejected
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Client
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Tạo report mới, kiểm tra GET /reports/map chỉ trả về report trong khung bounds kèm trường severity và truncated, đồng thời ẩn report sau khi Admin chuyển trạng thái thành rejected.
7. **Mục đích kiểm thử:** Xác minh lọc địa lý, cấu trúc dữ liệu trả về và quy tắc ẩn report bị từ chối trên bản đồ Client.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; user seed u2 (client) và u1 (admin) tồn tại trong DB.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Client u2 tạo report tại tọa độ ngẫu nhiên point qua POST /reports. | JWT client u2; Payload tại point (10.70..10.90, 106.60..106.80) | HTTP 200; lấy được reportId. |
| 2 | Client u2 gọi GET /reports/map với khung inside (point ± 0.0005) và khung outside (+0.01..+0.02). | JWT client u2; Query bounds inside và outside | Khung inside trả HTTP 200, có trường truncated, chứa reportId và phần tử đầu tiên có trường severity; khung outside không chứa reportId. |
| 3 | Admin u1 gọi PATCH /admin/reports/{reportId}/status với status="rejected", sau đó Client u2 gọi lại khung inside. | JWT admin u1 với {"status": "rejected"}, rồi JWT client u2 gọi bounds inside | PATCH trả HTTP 200; GET bản đồ Client sau khi reject không còn chứa reportId. |

10. **Input từng bước:**
   - Bước 1: JWT client u2; Payload tại point (10.70..10.90, 106.60..106.80)
   - Bước 2: JWT client u2; Query bounds inside và outside
   - Bước 3: JWT admin u1 với {"status": "rejected"}, rồi JWT client u2 gọi bounds inside
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; lấy được reportId.
   - Bước 2: Khung inside trả HTTP 200, có trường truncated, chứa reportId và phần tử đầu tiên có trường severity; khung outside không chứa reportId.
   - Bước 3: PATCH trả HTTP 200; GET bản đồ Client sau khi reject không còn chứa reportId.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/MapReportsTest.java`
13. **Ghi chú:** Test tạo report mới vào DB và cập nhật sang rejected.
