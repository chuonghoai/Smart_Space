# SMP-236: Từ chối tạo đề xuất khóa khi URL ảnh không phải HTTPS

1. **Mã số test case:** SMP-236
2. **Tên test case:** Từ chối tạo đề xuất khóa khi URL ảnh không phải HTTPS
3. **Project:** Spring Boot Backend
4. **Chức năng:** Đề xuất khóa tài khoản người dùng
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AccountLockRequestServiceImpl.create(...) từ chối URL ảnh bằng chứng bắt đầu bằng "http://" thay vì "https://".
7. **Mục đích kiểm thử:** Đảm bảo hệ thống chỉ chấp nhận đường dẫn ảnh bằng chứng sử dụng giao thức HTTPS.
8. **Điều kiện tiên quyết:** Mock dependency bằng Mockito; lý do hợp lệ VALID_REASON.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.create(...) với URL ảnh dùng giao thức HTTP | CreateAccountLockRequest(targetUserId="user-1", reason=VALID_REASON, evidenceImageUrls=["http://x/a.jpg"], reportIds=null), adminId="admin-a" | Ném BadRequestException với message "lock_request.evidence.image_invalid" |

10. **Input từng bước:**
   - Bước 1: CreateAccountLockRequest(targetUserId="user-1", reason=VALID_REASON, evidenceImageUrls=["http://x/a.jpg"], reportIds=null), adminId="admin-a"
11. **Kỳ vọng từng bước:**
   - Bước 1: Ném BadRequestException với message "lock_request.evidence.image_invalid"
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/admin/AccountLockRequestServiceImplTest.java`
13. **Ghi chú:** Tên test method: Create.nonHttpsImage_isRejected.
