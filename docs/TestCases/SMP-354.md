# SMP-354: Mở drawer cài đặt ngôn ngữ và giao diện trên Staff Web

1. **Mã số test case:** SMP-354
2. **Tên test case:** Mở drawer cài đặt ngôn ngữ và giao diện trên Staff Web
3. **Project:** Flutter Staff
4. **Chức năng:** Cài đặt Ngôn ngữ & Giao diện (LoginSetting Drawer)
5. **Loại kiểm thử:** Web UI Automation Test (Playwright)
6. **Mô tả test case:** Trên màn hình đăng nhập Staff Web, nhấn nút cài đặt ở góc trên bên phải để mở endDrawer LoginSetting và kiểm tra hiển thị nhãn 'Cài đặt'.
7. **Mục đích kiểm thử:** Xác minh drawer cài đặt ngôn ngữ/theme hoạt động đúng trên trình duyệt web của Staff.
8. **Điều kiện tiên quyết:** Flutter Staff Web server đang chạy tại PW_STAFF_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Boot Staff Web tới /#/login | URL /#/login | Màn hình đăng nhập hiển thị |
| 2 | Nhấn button đầu tiên (IconButton Icons.settings) | Click button.first() | Drawer mở ra và semantics chứa 'Cài đặt' |

10. **Input từng bước:**
   - Bước 1: URL /#/login
   - Bước 2: Click button.first()
11. **Kỳ vọng từng bước:**
   - Bước 1: Màn hình đăng nhập hiển thị
   - Bước 2: Drawer mở ra và semantics chứa 'Cài đặt'
12. **File test tương ứng:** `playwright/staff/staff-web.spec.ts`
13. **Ghi chú:** IconButton(Icons.settings) trong MobileLoginScreen chưa gắn tooltip nên test xác định qua button đầu tiên trên màn hình.
