# SMP-008: Parse severity và thuộc tính isDangerous trong ReportModel

1. **Mã số test case:** SMP-008
2. **Tên test case:** Parse severity và thuộc tính isDangerous trong ReportModel
3. **Project:** Flutter Client
4. **Chức năng:** Bản đồ phản ánh (Map Models)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra ReportModel.fromJson ánh xạ chuỗi severity ('critical', 'high', 'medium', 'low') sang EReportSeverity và giá trị isDangerous (true cho critical/high, false cho medium).
7. **Mục đích kiểm thử:** Đảm bảo mapping mức độ nghiêm trọng từ JSON và phân loại phản ánh nguy hiểm chính xác.
8. **Điều kiện tiên quyết:** Helper json(severity) tạo Map chứa id='r1', title='t', status='pending', latitude=10.8, longitude=106.7.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Parse JSON với severity lần lượt là 'critical', 'high', 'medium', 'low' | severity = 'critical' \| 'high' \| 'medium' \| 'low' | isDangerous là true cho critical/high, false cho medium; 'low' parse thành EReportSeverity.low |

10. **Input từng bước:**
   - Bước 1: severity = 'critical' | 'high' | 'medium' | 'low'
11. **Kỳ vọng từng bước:**
   - Bước 1: isDangerous là true cho critical/high, false cho medium; 'low' parse thành EReportSeverity.low
12. **File test tương ứng:** `smartspace_client/test/features/reports/map_models_test.dart`
13. **Ghi chú:** Không có.
