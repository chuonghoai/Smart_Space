# SMP-188: Lấy thống kê KPI người dùng và top người đóng góp

1. **Mã số test case:** SMP-188
2. **Tên test case:** Lấy thống kê KPI người dùng và top người đóng góp
3. **Project:** Spring Boot Backend
4. **Chức năng:** Thống kê người dùng Admin (GET /admin/users/statistics)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gọi GET /admin/users/statistics nhận HTTP 200 và body JSON chứa đủ 7 trường KPI: totalUsers, newUsers, newUsersPrevious, activeReporters, reports, reportsPrevious, topReporters.
7. **Mục đích kiểm thử:** Đảm bảo endpoint thống kê người dùng trả về đầy đủ bộ chỉ số tổng hợp cho màn hình quản trị.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin u1 gửi GET /admin/users/statistics | Token admin u1 | HTTP 200; body chứa đủ các khóa "totalUsers", "newUsers", "newUsersPrevious", "activeReporters", "reports", "reportsPrevious", "topReporters". |

10. **Input từng bước:**
   - Bước 1: Token admin u1
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; body chứa đủ các khóa "totalUsers", "newUsers", "newUsersPrevious", "activeReporters", "reports", "reportsPrevious", "topReporters".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminUserManagementTest.java`
13. **Ghi chú:** Class này đã đăng ký trong testapi.ps1 dưới lệnh AdminUsers.
