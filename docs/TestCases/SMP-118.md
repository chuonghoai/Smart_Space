# SMP-118: Phân biệt màu trạng thái Processing (Info) và Processed (Success) ở cả Light và Dark Mode

1. **Mã số test case:** SMP-118
2. **Tên test case:** Phân biệt màu trạng thái Processing (Info) và Processed (Success) ở cả Light và Dark Mode
3. **Project:** Flutter Admin
4. **Chức năng:** Hệ thống màu trạng thái phản ánh (ReportStatusStyle)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra hàm reportStatusColor(context, status) trả về đúng token màu info cho 'processing' và token màu success cho 'processed', đồng thời hai màu khác nhau ở cả AppTheme.lightTheme và AppTheme.darkTheme.
7. **Mục đích kiểm thử:** Đảm bảo hai trạng thái 'processing' và 'processed' dùng đúng semantic token và phân biệt rõ ràng ở cả hai chế độ sáng/tối.
8. **Điều kiện tiên quyết:** MaterialApp cấu hình AppLocalizations, locale 'vi', lần lượt dùng AppTheme.lightTheme và AppTheme.darkTheme (kèm Theme(data: AppTheme.darkTheme)).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Render Builder trong MaterialApp dùng AppTheme.lightTheme và gọi reportStatusColor(context, 'processing') cùng reportStatusColor(context, 'processed'). | Theme: AppTheme.lightTheme; status: 'processing', 'processed'. | processingColorLight == AppSemanticColors.light.info, processedColorLight == AppSemanticColors.light.success và processingColorLight != processedColorLight. |
| 2 | Render Builder trong MaterialApp và Theme(data: AppTheme.darkTheme), gọi lại reportStatusColor cho 'processing' và 'processed'. | Theme: AppTheme.darkTheme; status: 'processing', 'processed'. | processingColorDark == AppSemanticColors.dark.info, processedColorDark == AppSemanticColors.dark.success và processingColorDark != processedColorDark. |

10. **Input từng bước:**
   - Bước 1: Theme: AppTheme.lightTheme; status: 'processing', 'processed'.
   - Bước 2: Theme: AppTheme.darkTheme; status: 'processing', 'processed'.
11. **Kỳ vọng từng bước:**
   - Bước 1: processingColorLight == AppSemanticColors.light.info, processedColorLight == AppSemanticColors.light.success và processingColorLight != processedColorLight.
   - Bước 2: processingColorDark == AppSemanticColors.dark.info, processedColorDark == AppSemanticColors.dark.success và processingColorDark != processedColorDark.
12. **File test tương ứng:** `smartspace_admin/test/ui/screen/home/admin_home_card_uniformity_test.dart`
13. **Ghi chú:** Không có.
