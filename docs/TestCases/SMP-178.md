# SMP-178: Admin không thể tự khóa chính tài khoản của mình

1. **Mã số test case:** SMP-178
2. **Tên test case:** Admin không thể tự khóa chính tài khoản của mình
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản Hội đồng quản trị (/admin/admins/{id}/status)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin u1 gửi PUT /admin/admins/u1/status với trạng thái "blocked" để tự khóa chính mình bị từ chối với HTTP 400.
7. **Mục đích kiểm thử:** Ngăn chặn quản trị viên tự vô hiệu hóa tài khoản đang sử dụng.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); token gọi API thuộc về chính userId u1.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin u1 gửi PUT /admin/admins/u1/status với status "blocked" | Token admin u1, body {"status":"blocked"} | HTTP 400 Bad Request. |

10. **Input từng bước:**
   - Bước 1: Token admin u1, body {"status":"blocked"}
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 400 Bad Request.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminAccountManagementTest.java`
13. **Ghi chú:** Không gây side-effect khóa tài khoản. Class này chưa đăng ký trong testapi.ps1.
