# SMP-187: Chặn 403 đối với Client khi gọi GET /admin/users

1. **Mã số test case:** SMP-187
2. **Tên test case:** Chặn 403 đối với Client khi gọi GET /admin/users
3. **Project:** Spring Boot Backend
4. **Chức năng:** Admin quản lý người dùng (GET /admin/users)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra tài khoản Client (u2, ROLE_client) gửi GET /admin/users bị từ chối với HTTP 403 Forbidden.
7. **Mục đích kiểm thử:** Đảm bảo client thông thường không thể truy cập danh sách người dùng dành cho admin.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); JWT client u2 (ROLE_client) ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Client u2 gửi GET /admin/users | Token user@gmail.com (u2, ROLE_client) | HTTP 403 Forbidden. |

10. **Input từng bước:**
   - Bước 1: Token user@gmail.com (u2, ROLE_client)
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 403 Forbidden.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminUserManagementTest.java`
13. **Ghi chú:** Class này đã đăng ký trong testapi.ps1 dưới lệnh AdminUsers.
