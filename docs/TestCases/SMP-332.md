# SMP-332: ClusterLayerColors.fromTheme mặc định dùng màu error/onError của theme

1. **Mã số test case:** SMP-332
2. **Tên test case:** ClusterLayerColors.fromTheme mặc định dùng màu error/onError của theme
3. **Project:** Flutter Shared (mobile_shared)
4. **Chức năng:** Khung nhìn & Cluster bản đồ (MapViewport)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra ClusterLayerColors.fromTheme(ThemeData.light()) khi không truyền tham số alert sẽ gán colors.alert bằng theme.colorScheme.error và colors.onAlert bằng theme.colorScheme.onError.
7. **Mục đích kiểm thử:** Đảm bảo lớp cluster tuân thủ hệ thống màu Theme mặc định cho trạng thái cảnh báo.
8. **Điều kiện tiên quyết:** Tạo theme = ThemeData.light().
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi ClusterLayerColors.fromTheme(theme) và kiểm tra alert, onAlert. | ThemeData.light(), alert = null | colors.alert == theme.colorScheme.error và colors.onAlert == theme.colorScheme.onError. |

10. **Input từng bước:**
   - Bước 1: ThemeData.light(), alert = null
11. **Kỳ vọng từng bước:**
   - Bước 1: colors.alert == theme.colorScheme.error và colors.onAlert == theme.colorScheme.onError.
12. **File test tương ứng:** `mobile_shared/test/features/map/map_viewport_test.dart`
13. **Ghi chú:** Không có.
