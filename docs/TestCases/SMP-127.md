# SMP-127: AdminHomeScreen hiển thị bố cục desktop bento và AdminQuickAccessBar chế độ panel khi width >= 1024

1. **Mã số test case:** SMP-127
2. **Tên test case:** AdminHomeScreen hiển thị bố cục desktop bento và AdminQuickAccessBar chế độ panel khi width >= 1024
3. **Project:** Flutter Admin
4. **Chức năng:** Trang chủ Admin (AdminHomeScreen Responsive)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra AdminHomeScreen trên kích thước desktop 1400x1000 (>= 1024px) hiển thị header desktop (Icons.shield_outlined, Icons.refresh), số liệu KPI (userCount '120', staffCount '15') và AdminQuickAccessBar có isPanelMode == true.
7. **Mục đích kiểm thử:** Xác minh breakpoint desktop (>= 1024px) của AdminHomeScreen hiển thị đúng header quản trị, các chỉ số tổng quan và thanh truy cập nhanh dạng panel.
8. **Điều kiện tiên quyết:** Surface size Size(1400, 1000); _buildTestApp override notificationProvider, adminOverviewProvider (userCount: 120, staffCount: 15, ...), recentReportProvider, recentActivityProvider và latestNewsProvider.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Đặt kích thước bề mặt 1400x1000, render AdminHomeScreen() qua _buildTestApp và gọi pumpAndSettle(). | AdminHomeScreen(); Size(1400, 1000); mock overview (userCount: 120, staffCount: 15). | Tìm thấy Icons.shield_outlined, Icons.refresh, text '120', text '15' và 1 AdminQuickAccessBar thỏa điều kiện isPanelMode == true. |

10. **Input từng bước:**
   - Bước 1: AdminHomeScreen(); Size(1400, 1000); mock overview (userCount: 120, staffCount: 15).
11. **Kỳ vọng từng bước:**
   - Bước 1: Tìm thấy Icons.shield_outlined, Icons.refresh, text '120', text '15' và 1 AdminQuickAccessBar thỏa điều kiện isPanelMode == true.
12. **File test tương ứng:** `smartspace_admin/test/ui/screen/home/home_responsive_test.dart`
13. **Ghi chú:** Không có.
