# SMP-275: Không tiết lộ trạng thái khóa khi tài khoản admin bị khóa nhập sai mật khẩu

1. **Mã số test case:** SMP-275
2. **Tên test case:** Không tiết lộ trạng thái khóa khi tài khoản admin bị khóa nhập sai mật khẩu
3. **Project:** Spring Boot Backend
4. **Chức năng:** Xác thực & Bảo mật tài khoản (AuthenticationService)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra loginBasic đối với tài khoản admin ở trạng thái EUserStatus.blocked nhưng nhập sai mật khẩu chỉ trả về BadRequestException("auth.invalid_credentials") thay vì thông báo tài khoản bị khóa.
7. **Mục đích kiểm thử:** Đảm bảo luồng đăng nhập không làm lộ thông tin trạng thái khóa tài khoản khi người dùng chưa xác thực đúng mật khẩu.
8. **Điều kiện tiên quyết:** Unit test dùng Mockito trên AuthenticationService. Mock userRepository.findByEmailAndRole("someone@example.com", ERole.admin) trả về User(role=ERole.admin, status=EUserStatus.blocked, password="hashed") và passwordEncoder.matches("secret", "hashed") trả về false.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Cấu hình mock User admin bị khóa và mật khẩu không khớp | User(id="user-1", role=ERole.admin, status=EUserStatus.blocked); passwordEncoder.matches("secret", "hashed") = false | Mock trả về User bị khóa và kết quả so sánh mật khẩu là false |
| 2 | Gọi authenticationService.loginBasic(request) | LoginRequest(email="someone@example.com", password="secret", role=ERole.admin, deviceId="device-1") | Ném BadRequestException với message "auth.invalid_credentials" |

10. **Input từng bước:**
   - Bước 1: User(id="user-1", role=ERole.admin, status=EUserStatus.blocked); passwordEncoder.matches("secret", "hashed") = false
   - Bước 2: LoginRequest(email="someone@example.com", password="secret", role=ERole.admin, deviceId="device-1")
11. **Kỳ vọng từng bước:**
   - Bước 1: Mock trả về User bị khóa và kết quả so sánh mật khẩu là false
   - Bước 2: Ném BadRequestException với message "auth.invalid_credentials"
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/auth/AuthenticationServiceSecurityTest.java`
13. **Ghi chú:** Thuộc nhóm @Nested BlockedAccount.
