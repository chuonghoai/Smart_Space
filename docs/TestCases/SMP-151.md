# SMP-151: Lọc report trên bản đồ theo nhóm Nguy hiểm và Thông thường

1. **Mã số test case:** SMP-151
2. **Tên test case:** Lọc report trên bản đồ theo nhóm Nguy hiểm và Thông thường
3. **Project:** Flutter Staff
4. **Chức năng:** Bản đồ nhân viên (Staff Map)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra MapState.getFilteredReports trên danh sách gồm 3 report (high, medium, unknown) khi bật cả hai cờ mặc định, khi tắt showNormal và khi tắt showDangerous.
7. **Mục đích kiểm thử:** Đảm bảo hai bộ lọc Nguy hiểm và Thông thường phân chia tập report không chồng lấn và bao gồm report unknown vào nhóm Thông thường.
8. **Điều kiện tiên quyết:** Danh sách 3 report: 'danger' (high), 'normal' (medium), 'unrated' (unknown).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi getFilteredReports với MapState() mặc định (showDangerous=true, showNormal=true). | MapState() mặc định và 3 report | Trả về đầy đủ ['danger', 'normal', 'unrated']. |
| 2 | Gọi getFilteredReports với MapState(showNormal: false). | showNormal: false | Chỉ trả về ['danger']. |
| 3 | Gọi getFilteredReports với MapState(showDangerous: false). | showDangerous: false | Trả về ['normal', 'unrated']. |

10. **Input từng bước:**
   - Bước 1: MapState() mặc định và 3 report
   - Bước 2: showNormal: false
   - Bước 3: showDangerous: false
11. **Kỳ vọng từng bước:**
   - Bước 1: Trả về đầy đủ ['danger', 'normal', 'unrated'].
   - Bước 2: Chỉ trả về ['danger'].
   - Bước 3: Trả về ['normal', 'unrated'].
12. **File test tương ứng:** `smartspace_staff/test/features/map/staff_map_test.dart`
13. **Ghi chú:** Không có.
