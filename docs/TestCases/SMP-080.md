# SMP-080: Thay đổi mapFilterProvider kích hoạt MapReportsNotifier tải lại dữ liệu

1. **Mã số test case:** SMP-080
2. **Tên test case:** Thay đổi mapFilterProvider kích hoạt MapReportsNotifier tải lại dữ liệu
3. **Project:** Flutter Admin
4. **Chức năng:** Bản đồ Admin (MapReportsNotifier)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra khi mapFilterProvider thay đổi trạng thái filter (từ mặc định sang ReportFilter(status: 'pending')), MapReportsNotifier tự động kích hoạt gọi lại _FakeMapService với tham số status='pending' và cập nhật danh sách reports mới.
7. **Mục đích kiểm thử:** Xác minh phản ứng reactive giữa bộ lọc bản đồ (mapFilterProvider) và dữ liệu phản ánh hiển thị (mapReportsProvider).
8. **Điều kiện tiên quyết:** ProviderContainer override mapReportsProvider bằng _FakeMapService; đã tải thành công lần đầu cho viewport với kết quả ['r1'].
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Khởi tạo listener bằng container.read(mapReportsProvider), gọi loadForViewport(viewport) và complete trả về ['r1']. | viewport (10.7..10.9, 106.6..106.8), response 1 = ['r1']. | Tải lần đầu hoàn tất. |
| 2 | Cập nhật mapFilterProvider.notifier.state = ReportFilter(status: 'pending'). | ReportFilter(status: 'pending') | service.calls tăng lên 2 và lời gọi cuối có status='pending'. |
| 3 | Complete response thứ 2 với ['r2'] và gọi await pumpEventQueue(). | _ok(['r2']) | container.read(mapReportsProvider).reports chỉ còn id ['r2']. |

10. **Input từng bước:**
   - Bước 1: viewport (10.7..10.9, 106.6..106.8), response 1 = ['r1'].
   - Bước 2: ReportFilter(status: 'pending')
   - Bước 3: _ok(['r2'])
11. **Kỳ vọng từng bước:**
   - Bước 1: Tải lần đầu hoàn tất.
   - Bước 2: service.calls tăng lên 2 và lời gọi cuối có status='pending'.
   - Bước 3: container.read(mapReportsProvider).reports chỉ còn id ['r2'].
12. **File test tương ứng:** `smartspace_admin/test/features/map/admin_map_test.dart`
13. **Ghi chú:** Không có.
