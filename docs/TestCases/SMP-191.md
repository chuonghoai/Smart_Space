# SMP-191: Chi tiết người dùng trả về 404 khi tra cứu staff hoặc admin

1. **Mã số test case:** SMP-191
2. **Tên test case:** Chi tiết người dùng trả về 404 khi tra cứu staff hoặc admin
3. **Project:** Spring Boot Backend
4. **Chức năng:** Chi tiết người dùng Admin (GET /admin/users/{id})
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gọi GET /admin/users/u5 (staff) và GET /admin/users/u1 (admin) đều nhận được HTTP 404 Not Found.
7. **Mục đích kiểm thử:** Đảm bảo endpoint chi tiết /admin/users/{id} chỉ phục vụ tra cứu tài khoản client, không trả về thông tin của staff hay admin.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); theo seed_data.sql, u5 là staff và u1 là admin; JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin u1 gửi GET /admin/users/u5 và GET /admin/users/u1 | Path id = "u5" và id = "u1" | Cả 2 yêu cầu đều trả về HTTP 404 Not Found. |

10. **Input từng bước:**
   - Bước 1: Path id = "u5" và id = "u1"
11. **Kỳ vọng từng bước:**
   - Bước 1: Cả 2 yêu cầu đều trả về HTTP 404 Not Found.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminUserManagementTest.java`
13. **Ghi chú:** Class này đã đăng ký trong testapi.ps1 dưới lệnh AdminUsers.
