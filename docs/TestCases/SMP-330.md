# SMP-330: Cho phép thử lại cùng khung nhìn sau khi request thất bại

1. **Mã số test case:** SMP-330
2. **Tên test case:** Cho phép thử lại cùng khung nhìn sau khi request thất bại
3. **Project:** Flutter Shared (mobile_shared)
4. **Chức năng:** Khung nhìn & Cluster bản đồ (MapViewport)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra sau khi lấy request = gate.begin(viewport)! và gọi gate.fail(request), lời gọi gate.begin(viewport) tiếp theo vẫn trả về request khác null thay vì bị chặn bởi cơ chế chống lặp cùng khung.
7. **Mục đích kiểm thử:** Đảm bảo khi tải khung nhìn bị lỗi mạng, người dùng hoặc app có thể thử tải lại ngay trên chính khung nhìn đó.
8. **Điều kiện tiên quyết:** gate đã tạo request cho viewport.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi request = gate.begin(viewport)!, gọi gate.fail(request), rồi gọi lại gate.begin(viewport). | begin(viewport) -> fail(request) -> begin(viewport) | Lần gọi gate.begin(viewport) thứ hai trả về khác null. |

10. **Input từng bước:**
   - Bước 1: begin(viewport) -> fail(request) -> begin(viewport)
11. **Kỳ vọng từng bước:**
   - Bước 1: Lần gọi gate.begin(viewport) thứ hai trả về khác null.
12. **File test tương ứng:** `mobile_shared/test/features/map/map_viewport_test.dart`
13. **Ghi chú:** Không có.
