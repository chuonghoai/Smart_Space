# SMP-242: Tạo đề xuất khóa thành công với hạn 72h và mời admin active

1. **Mã số test case:** SMP-242
2. **Tên test case:** Tạo đề xuất khóa thành công với hạn 72h và mời admin active
3. **Project:** Spring Boot Backend
4. **Chức năng:** Đề xuất khóa tài khoản người dùng
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra luồng tạo đề xuất khóa thành công: lưu đề xuất trạng thái pending có hạn ~72 giờ, khử trùng URL ảnh trùng lặp, lưu cả bằng chứng ảnh và phản ánh, ghi ActivityHistory, chỉ gửi thông báo tới các admin active và trả về DTO phản ánh đúng quyền người đề xuất.
7. **Mục đích kiểm thử:** Xác minh đầy đủ nghiệp vụ tạo mới đề xuất khóa tài khoản và các tác vụ phụ đi kèm.
8. **Điều kiện tiên quyết:** Stub target active client, proposer "admin-a" active admin, countByRoleAndStatus=3L, reportRepository.findAllById trả về report("r1", target, null), requestRepository.save gán id="req-1", và userRepository.findByRole(ERole.admin) trả về 3 user gồm proposer, admin-b (active) và admin-blocked (blocked).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.create(...) với 2 URL ảnh giống nhau và 1 reportId | CreateAccountLockRequest(targetUserId="user-1", reason=VALID_REASON, evidenceImageUrls=["https://x/a.jpg", "https://x/a.jpg"], reportIds=["r1"]), adminId="admin-a" | Lưu AccountLockRequest trạng thái pending với expiresAt cách hiện tại 71-72 giờ |
| 2 | Kiểm tra danh sách bằng chứng được lưu qua evidenceRepository.saveAll | ArgumentCaptor<List<AccountLockEvidence>> | Lưu đúng 2 phần tử do ảnh trùng bị gộp: phần tử 0 type=image, phần tử 1 type=report |
| 3 | Kiểm tra log hoạt động, danh sách admin được thông báo và response trả về | activityHistoryRepository, notifier.notifyNewRequest, AccountLockRequestResponse | Ghi ActivityHistory; notifier nhận danh sách toàn bộ là admin active; response có id="req-1", mine=true, canVote=false, voteBlockedReason="proposer", canCancel=true |

10. **Input từng bước:**
   - Bước 1: CreateAccountLockRequest(targetUserId="user-1", reason=VALID_REASON, evidenceImageUrls=["https://x/a.jpg", "https://x/a.jpg"], reportIds=["r1"]), adminId="admin-a"
   - Bước 2: ArgumentCaptor<List<AccountLockEvidence>>
   - Bước 3: activityHistoryRepository, notifier.notifyNewRequest, AccountLockRequestResponse
11. **Kỳ vọng từng bước:**
   - Bước 1: Lưu AccountLockRequest trạng thái pending với expiresAt cách hiện tại 71-72 giờ
   - Bước 2: Lưu đúng 2 phần tử do ảnh trùng bị gộp: phần tử 0 type=image, phần tử 1 type=report
   - Bước 3: Ghi ActivityHistory; notifier nhận danh sách toàn bộ là admin active; response có id="req-1", mine=true, canVote=false, voteBlockedReason="proposer", canCancel=true
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/admin/AccountLockRequestServiceImplTest.java`
13. **Ghi chú:** Tên test method: Create.success_createsPendingRequest.
