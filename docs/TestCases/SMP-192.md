# SMP-192: Staff lấy danh sách hội thoại theo bộ lọc role (all, client, admin) và unread-count

1. **Mã số test case:** SMP-192
2. **Tên test case:** Staff lấy danh sách hội thoại theo bộ lọc role (all, client, admin) và unread-count
3. **Project:** Spring Boot Backend
4. **Chức năng:** Hội thoại Chat cho Staff (/conversations/my-conversation, /conversations/unread-count)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Staff (u3, staff@gmail.com, scope="staff") gọi tuần tự 4 API GET: danh sách hội thoại của tôi với role=all (khẳng định HTTP 200 và "success":true), đếm tin nhắn chưa đọc /conversations/unread-count (HTTP 200), và danh sách hội thoại lọc theo role=client, role=admin (đều HTTP 200).
7. **Mục đích kiểm thử:** Xác minh Staff có thể lấy danh sách hội thoại theo các bộ lọc role và truy vấn số lượng hội thoại/tin nhắn chưa đọc.
8. **Điều kiện tiên quyết:** Backend đang chạy cố định tại http://localhost:8989 (@BeforeAll fail nếu không kết nối được socket); JWT HS512 giả lập cho userId="u3", email="staff@gmail.com", claim scope="staff" ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /conversations/my-conversation?page=1&size=10&role=all kèm token Staff u3 | Token u3 (staff@gmail.com, scope="staff"), page=1, size=10, role=all | HTTP 200 và body chứa "success":true. |
| 2 | Gửi GET /conversations/unread-count kèm token Staff u3 | Token u3 | HTTP 200. |
| 3 | Gửi GET /conversations/my-conversation?page=1&size=10&role=client và role=admin | role=client và role=admin | Cả 2 yêu cầu đều trả về HTTP 200. |

10. **Input từng bước:**
   - Bước 1: Token u3 (staff@gmail.com, scope="staff"), page=1, size=10, role=all
   - Bước 2: Token u3
   - Bước 3: role=client và role=admin
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200 và body chứa "success":true.
   - Bước 2: HTTP 200.
   - Bước 3: Cả 2 yêu cầu đều trả về HTTP 200.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/chat/StaffChatIntegrationTest.java`
13. **Ghi chú:** Lưu ý trung thực theo code: Mặc dù @DisplayName ghi "Kiểm tra toàn diện API hội thoại, tin nhắn, phân quyền và presence cho Staff", thân test thực tế chỉ thực hiện 4 request GET (3 lượt my-conversation và 1 lượt unread-count), chưa có assertion cho gửi tin nhắn, phân quyền 403 hay presence API; ngoài ra claim scope dùng "staff" (không có tiền tố ROLE_). Class đã đăng ký trong testapi.ps1 dưới lệnh StaffChat.
