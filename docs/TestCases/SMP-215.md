# SMP-215: Bảng tin lọc phản ánh theo mức độ nghiêm trọng (severity=high)

1. **Mã số test case:** SMP-215
2. **Tên test case:** Bảng tin lọc phản ánh theo mức độ nghiêm trọng (severity=high)
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bảng tin phản ánh (Report Feed)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Gửi GET /reports/feed?severity=high&size=20&page=1 và kiểm tra tất cả phần tử trả về đều có trường severity bằng "high".
7. **Mục đích kiểm thử:** Xác minh bộ lọc severity trên API Bảng tin hoạt động chính xác.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; JWT client u2 hợp lệ.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /reports/feed?severity=high&size=20&page=1 bằng token client u2. | JWT client u2; Query: severity=high&size=20&page=1 | HTTP 200; mọi phần tử trong data.content đều có severity == "high". |

10. **Input từng bước:**
   - Bước 1: JWT client u2; Query: severity=high&size=20&page=1
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; mọi phần tử trong data.content đều có severity == "high".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/ReportFeedTest.java`
13. **Ghi chú:** Phụ thuộc dữ liệu trong DB; nếu DB hiện không có report severity=high, vòng lặp kiểm tra 0 phần tử vẫn pass.
