# SMP-163: Smoke test template counter mặc định trên SmartSpaceStaffApp

1. **Mã số test case:** SMP-163
2. **Tên test case:** Smoke test template counter mặc định trên SmartSpaceStaffApp
3. **Project:** Flutter Staff
4. **Chức năng:** Khởi tạo ứng dụng (Template mặc định Flutter)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Test mặc định được tạo từ template counter của Flutter: dựng widget const SmartSpaceStaffApp(), tìm text '0' (findsOneWidget) và '1' (findsNothing), chạm Icons.add, pump lại frame rồi kỳ vọng '0' biến mất và '1' xuất hiện.
7. **Mục đích kiểm thử:** Theo mã nguồn hiện tại là smoke test template counter mặc định của Flutter chứ chưa phản ánh nghiệp vụ thực tế của SmartSpaceStaffApp.
8. **Điều kiện tiên quyết:** File test sử dụng const SmartSpaceStaffApp() mà không bọc ProviderScope hoặc mock các dịch vụ/khởi tạo phụ thuộc trong main.dart.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi tester.pumpWidget(const SmartSpaceStaffApp()) và kiểm tra text '0' (1 widget), '1' (0 widget). | const SmartSpaceStaffApp() | Theo assertion trong file test: tìm thấy 1 text '0' và 0 text '1' (thực tế không khớp vì SmartSpaceStaffApp là MaterialApp.router, không phải màn hình counter). |
| 2 | Gọi tester.tap(find.byIcon(Icons.add)), gọi tester.pump(), sau đó kiểm tra text '0' (0 widget) và '1' (1 widget). | Tap vào Icons.add | Theo assertion trong file test: '0' biến mất và hiển thị 1 text '1' (thực tế không thể xác minh thành công do app thực tế không có counter và thiếu ProviderScope/khởi tạo môi trường). |

10. **Input từng bước:**
   - Bước 1: const SmartSpaceStaffApp()
   - Bước 2: Tap vào Icons.add
11. **Kỳ vọng từng bước:**
   - Bước 1: Theo assertion trong file test: tìm thấy 1 text '0' và 0 text '1' (thực tế không khớp vì SmartSpaceStaffApp là MaterialApp.router, không phải màn hình counter).
   - Bước 2: Theo assertion trong file test: '0' biến mất và hiển thị 1 text '1' (thực tế không thể xác minh thành công do app thực tế không có counter và thiếu ProviderScope/khởi tạo môi trường).
12. **File test tương ứng:** `smartspace_staff/test/widget_test.dart`
13. **Ghi chú:** Đây là file template counter mặc định của Flutter được giữ nguyên code không sửa: test kiểm tra màn hình counter mặc định '0'/'1' với nút Icons.add trên SmartSpaceStaffApp() và sẽ fail khi chạy thực tế vì SmartSpaceStaffApp sử dụng AppServicesInitializer + MaterialApp.router (không có giao diện counter và cũng thiếu ProviderScope bao ngoài). Không có logic nghiệp vụ Staff nào được kiểm chứng từ test này.
