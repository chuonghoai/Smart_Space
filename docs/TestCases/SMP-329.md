# SMP-329: Loại bỏ request cũ (stale) khi có request viewport mới hơn

1. **Mã số test case:** SMP-329
2. **Tên test case:** Loại bỏ request cũ (stale) khi có request viewport mới hơn
3. **Project:** Flutter Shared (mobile_shared)
4. **Chức năng:** Khung nhìn & Cluster bản đồ (MapViewport)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra tạo request first = begin(viewport) rồi second = begin(inside, force: true): isCurrent(first) là false, isCurrent(second) là true; sau đó nếu succeed(first) trước rồi succeed(second), gate vẫn dựa vào vùng đã tải của second và bỏ qua begin(inside).
7. **Mục đích kiểm thử:** Ngăn race condition khi phản hồi mạng của khung nhìn cũ về sau ghi đè vùng dữ liệu của khung nhìn mới nhất.
8. **Điều kiện tiên quyết:** Khởi tạo ViewportLoadGate mới.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi first = gate.begin(viewport)! và second = gate.begin(inside, force: true)!, rồi kiểm tra gate.isCurrent. | first(viewport), second(inside, force: true) | gate.isCurrent(first) = false và gate.isCurrent(second) = true. |
| 2 | Gọi gate.succeed(first, truncated: false), tiếp theo gate.succeed(second, truncated: false), rồi gọi gate.begin(inside). | succeed(first) -> succeed(second) -> begin(inside) | gate.begin(inside) trả về null vì kết quả của second được ghi nhận đúng. |

10. **Input từng bước:**
   - Bước 1: first(viewport), second(inside, force: true)
   - Bước 2: succeed(first) -> succeed(second) -> begin(inside)
11. **Kỳ vọng từng bước:**
   - Bước 1: gate.isCurrent(first) = false và gate.isCurrent(second) = true.
   - Bước 2: gate.begin(inside) trả về null vì kết quả của second được ghi nhận đúng.
12. **File test tương ứng:** `mobile_shared/test/features/map/map_viewport_test.dart`
13. **Ghi chú:** Không có.
