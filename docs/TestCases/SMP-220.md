# SMP-220: Client đánh giá phản ánh là Chưa được xử lý (Unresolved) kèm ảnh bằng chứng

1. **Mã số test case:** SMP-220
2. **Tên test case:** Client đánh giá phản ánh là Chưa được xử lý (Unresolved) kèm ảnh bằng chứng
3. **Project:** Spring Boot Backend
4. **Chức năng:** Đánh giá phản ánh
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Mô phỏng Client u2 tạo report -> Admin u1 gán Staff u5 -> Staff u5 hoàn tất -> Client u2 gửi POST /reports/{id}/review với is_resolved=false kèm lý do và 1 URL ảnh bằng chứng.
7. **Mục đích kiểm thử:** Xác minh Client có thể phản hồi phản ánh chưa được giải quyết triệt để cùng lý do và hình ảnh minh chứng.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; các user seed u1 (admin), u2 (client), u5 (staff) tồn tại trong DB.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Client u2 tạo report "Rác thải sinh hoạt ứ đọng lối thoát hiểm tầng 2", Admin u1 giao cho Staff u5 (severity=medium), Staff u5 gọi complete. | JWT u2, u1, u5 cho các bước POST /reports, /assign và /complete | Cả 3 bước trả HTTP 200; report chuyển trạng thái processed. |
| 2 | Client u2 gửi POST /reports/{reportId}/review với is_resolved=false, reason và 1 URL trong image_urls. | JWT u2; Body có is_resolved=false, reason và mảng 1 image_url | HTTP 200; success=true; data.is_review_resolved=false; data.review_note khớp reason; data.review_image_urls là mảng 1 phần tử; data.reviewed_at không rỗng. |

10. **Input từng bước:**
   - Bước 1: JWT u2, u1, u5 cho các bước POST /reports, /assign và /complete
   - Bước 2: JWT u2; Body có is_resolved=false, reason và mảng 1 image_url
11. **Kỳ vọng từng bước:**
   - Bước 1: Cả 3 bước trả HTTP 200; report chuyển trạng thái processed.
   - Bước 2: HTTP 200; success=true; data.is_review_resolved=false; data.review_note khớp reason; data.review_image_urls là mảng 1 phần tử; data.reviewed_at không rỗng.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/ReviewReportUnresolvedTest.java`
13. **Ghi chú:** Không có.
