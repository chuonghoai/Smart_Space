# SMP-001: Lọc thông báo "Chưa đọc" tải lại trang 0 với unreadOnly

1. **Mã số test case:** SMP-001
2. **Tên test case:** Lọc thông báo "Chưa đọc" tải lại trang 0 với unreadOnly
3. **Project:** Flutter Client
4. **Chức năng:** Thông báo (Notifications)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra khi NotificationNotifier đã tải danh sách ban đầu (gồm thông báo 'a' chưa đọc và 'b' đã đọc), sau đó gọi setUnreadOnly(true), notifier xóa danh sách thông báo hiện tại, bật isLoadingNotifications=true và gọi API trang 0 với unreadOnly=true.
7. **Mục đích kiểm thử:** Đảm bảo chuyển sang tab/bộ lọc "Chưa đọc" xóa dữ liệu cũ tránh hiển thị lẫn lộn và tải lại từ trang 0 với cờ unreadOnly=true.
8. **Điều kiện tiên quyết:** Khởi tạo NotificationNotifier với NotificationService dùng _FakeNotificationRepo điều khiển response qua Completer.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi notifier.fetchNotifications() và hoàn tất request bằng danh sách 2 thông báo ('a' isRead=false, 'b' isRead=true) | fetchNotifications(); response=[_notif('a'), _notif('b', isRead: true)] | Danh sách thông báo ban đầu được tải thành công |
| 2 | Chuyển bộ lọc sang chưa đọc bằng notifier.setUnreadOnly(true) và flush microtask | unreadOnly = true | repo.calls.last ghi nhận (page: 0, unreadOnly: true); notifier.state.notifications rỗng; notifier.state.isLoadingNotifications == true |

10. **Input từng bước:**
   - Bước 1: fetchNotifications(); response=[_notif('a'), _notif('b', isRead: true)]
   - Bước 2: unreadOnly = true
11. **Kỳ vọng từng bước:**
   - Bước 1: Danh sách thông báo ban đầu được tải thành công
   - Bước 2: repo.calls.last ghi nhận (page: 0, unreadOnly: true); notifier.state.notifications rỗng; notifier.state.isLoadingNotifications == true
12. **File test tương ứng:** `smartspace_client/test/features/notifications/notification_filter_test.dart`
13. **Ghi chú:** Không có.
