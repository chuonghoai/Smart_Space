# SMP-205: Bản đồ Client trả về 401 khi không có token

1. **Mã số test case:** SMP-205
2. **Tên test case:** Bản đồ Client trả về 401 khi không có token
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Client
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Gửi request GET /reports/map kèm tọa độ khung nhìn hợp lệ nhưng không có Bearer token để kiểm tra chặn truy cập chưa xác thực.
7. **Mục đích kiểm thử:** Đảm bảo API bản đồ Client yêu cầu xác thực JWT.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /reports/map?min_lat=10.700000&max_lat=10.900000&min_lng=106.600000&max_lng=106.800000 không kèm header Authorization. | Token: null; Bounds hợp lệ quanh TP.HCM | Server trả về HTTP 401. |

10. **Input từng bước:**
   - Bước 1: Token: null; Bounds hợp lệ quanh TP.HCM
11. **Kỳ vọng từng bước:**
   - Bước 1: Server trả về HTTP 401.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/MapReportsTest.java`
13. **Ghi chú:** Không có.
