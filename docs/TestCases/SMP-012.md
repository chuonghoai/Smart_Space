# SMP-012: Tải phản ánh bản đồ mở rộng viewport theo prefetchFactor

1. **Mã số test case:** SMP-012
2. **Tên test case:** Tải phản ánh bản đồ mở rộng viewport theo prefetchFactor
3. **Project:** Flutter Client
4. **Chức năng:** Bản đồ phản ánh (Map Reports Provider)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra gọi notifier.loadForViewport(viewport) bật isLoading=true, gửi bounds mở rộng theo MapReportsNotifier.prefetchFactor lên repo, và khi hoàn tất với ['a', 'b'] thì tắt isLoading và cập nhật state.reports.
7. **Mục đích kiểm thử:** Đảm bảo bản đồ tải trước vùng đệm rộng hơn khung nhìn hiện tại và cập nhật đúng trạng thái tải.
8. **Điều kiện tiên quyết:** Khởi tạo SharedPreferences mock, _FakeReportRepo và MapReportsNotifier với đồng hồ giả DateTime(2026, 1, 1, 12).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi notifier.loadForViewport(viewport) | viewport = MapBounds(10.7..10.9, 106.6..106.8) | state.isLoading == true; repo.requestedBounds.single == viewport.expandBy(MapReportsNotifier.prefetchFactor) |
| 2 | Hoàn tất Completer với danh sách report ['a', 'b'] | ApiResponse(success: true, reports: ['a', 'b']) | state.isLoading == false; state.reports có ID ['a', 'b'] |

10. **Input từng bước:**
   - Bước 1: viewport = MapBounds(10.7..10.9, 106.6..106.8)
   - Bước 2: ApiResponse(success: true, reports: ['a', 'b'])
11. **Kỳ vọng từng bước:**
   - Bước 1: state.isLoading == true; repo.requestedBounds.single == viewport.expandBy(MapReportsNotifier.prefetchFactor)
   - Bước 2: state.isLoading == false; state.reports có ID ['a', 'b']
12. **File test tương ứng:** `smartspace_client/test/features/reports/map_reports_provider_test.dart`
13. **Ghi chú:** Không có.
