# SMP-358: Điều hướng từ Đăng nhập sang màn hình Đăng ký Email trên Client Web

1. **Mã số test case:** SMP-358
2. **Tên test case:** Điều hướng từ Đăng nhập sang màn hình Đăng ký Email trên Client Web
3. **Project:** Flutter Client
4. **Chức năng:** Điều hướng Đăng ký (GoRouter Client)
5. **Loại kiểm thử:** Web UI Automation Test (Playwright)
6. **Mô tả test case:** Trên màn hình đăng nhập Client Web, nhấn nút 'Đăng ký' và kiểm tra GoRouter mở màn hình MobileRegisterEmailScreen.
7. **Mục đích kiểm thử:** Xác minh luồng chuyển sang màn hình đăng ký tài khoản Client trên Web.
8. **Điều kiện tiên quyết:** Flutter Client Web server đang chạy tại PW_CLIENT_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Boot Client Web tới /login | URL /login | Nút 'Đăng ký' hiển thị |
| 2 | Nhấn nút 'Đăng ký' | Click button 'Đăng ký' | Màn hình đăng ký hiển thị 'Địa chỉ email của bạn là gì?' và nút 'Tiếp tục' |

10. **Input từng bước:**
   - Bước 1: URL /login
   - Bước 2: Click button 'Đăng ký'
11. **Kỳ vọng từng bước:**
   - Bước 1: Nút 'Đăng ký' hiển thị
   - Bước 2: Màn hình đăng ký hiển thị 'Địa chỉ email của bạn là gì?' và nút 'Tiếp tục'
12. **File test tương ứng:** `playwright/client/client-web.spec.ts`
13. **Ghi chú:** MobileLoginScreen dùng context.push(RouterPath.registerEmail) nên theo mặc định GoRouter trên Web URL thanh địa chỉ không đổi trong khi màn hình Đăng ký Email đã được render.
