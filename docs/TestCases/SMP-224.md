# SMP-224: Dashboard Admin thống kê nhân viên trả về đủ KPI, workload và ẩn password

1. **Mã số test case:** SMP-224
2. **Tên test case:** Dashboard Admin thống kê nhân viên trả về đủ KPI, workload và ẩn password
3. **Project:** Spring Boot Backend
4. **Chức năng:** Dashboard quản lý nhân viên
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Admin u1 gọi GET /admin/staffs/statistics để kiểm tra response chứa đầy đủ 9 trường thống kê KPI/workload và không làm lộ trường password.
7. **Mục đích kiểm thử:** Xác minh contract dữ liệu và tính bảo mật thông tin nhân viên của API thống kê Dashboard.
8. **Điều kiện tiên quyết:** Backend đang chạy tại BASE_URL (mặc định http://localhost:8989); JWT admin u1 hợp lệ.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /admin/staffs/statistics với token Admin u1 (ROLE_admin). | JWT u1 (admin@gmail.com, scope=ROLE_admin) | HTTP 200; body chứa đủ các khóa totalStaff, activeStaff, blockedStaff, processingReports, resolved, resolvedPrevious, avgResolutionMinutes, avgResolutionMinutesPrevious, workload và không chứa "password". |

10. **Input từng bước:**
   - Bước 1: JWT u1 (admin@gmail.com, scope=ROLE_admin)
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; body chứa đủ các khóa totalStaff, activeStaff, blockedStaff, processingReports, resolved, resolvedPrevious, avgResolutionMinutes, avgResolutionMinutesPrevious, workload và không chứa "password".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/staff/StaffDashboardTest.java`
13. **Ghi chú:** Không có.
