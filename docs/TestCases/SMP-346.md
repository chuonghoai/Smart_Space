# SMP-346: Boot Flutter Admin Web (Desktop 1280x800) và hiển thị màn hình đăng nhập

1. **Mã số test case:** SMP-346
2. **Tên test case:** Boot Flutter Admin Web (Desktop 1280x800) và hiển thị màn hình đăng nhập
3. **Project:** Flutter Admin
4. **Chức năng:** Khởi tạo & Đăng nhập Web (SplashScreen -> AdminLoginScreen)
5. **Loại kiểm thử:** Web UI Automation Test (Playwright)
6. **Mô tả test case:** Mở Flutter Admin Web ở độ phân giải Desktop 1280x800, chờ redirect sang /login, bật semantics tree, xác minh không có pageerror, tiêu đề SmartSpace Admin và hiển thị nội dung đăng nhập.
7. **Mục đích kiểm thử:** Xác minh bản build Flutter Web của smartspace_admin chạy ổn định trên Chromium và render đúng màn hình đăng nhập Desktop.
8. **Điều kiện tiên quyết:** Static SPA server đang phục vụ build/web của smartspace_admin tại PW_ADMIN_URL (mặc định http://localhost:9101).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Đặt viewport 1280x800, mở / và đợi redirect sang /login | viewport=1280x800, url=/ | URL chứa /login; không có pageerror |
| 2 | Kích hoạt Flutter semantics và kiểm tra tiêu đề + UI đăng nhập | flt-semantics-placeholder | Title chứa SmartSpace Admin; có text 'Chào mừng trở lại' và nút 'Đăng nhập' |

10. **Input từng bước:**
   - Bước 1: viewport=1280x800, url=/
   - Bước 2: flt-semantics-placeholder
11. **Kỳ vọng từng bước:**
   - Bước 1: URL chứa /login; không có pageerror
   - Bước 2: Title chứa SmartSpace Admin; có text 'Chào mừng trở lại' và nút 'Đăng nhập'
12. **File test tương ứng:** `playwright/admin/admin-web.spec.ts`
13. **Ghi chú:** smartspace_admin sử dụng usePathUrlStrategy() nên static server phải có SPA fallback.
