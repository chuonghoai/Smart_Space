# SMP-230: Phân quyền, validate yêu cầu nhờ làm giùm và danh sách đồng nghiệp

1. **Mã số test case:** SMP-230
2. **Tên test case:** Phân quyền, validate yêu cầu nhờ làm giùm và danh sách đồng nghiệp
3. **Project:** Spring Boot Backend
4. **Chức năng:** Nhờ làm giùm giữa Staff (Staff Delegation)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra các điều kiện lỗi khi gọi API delegation (người không được giao gửi yêu cầu -> 403, tự nhờ chính mình -> 400, thiếu helper_id -> 400) và phân quyền/bảo mật của GET /staff/colleagues.
7. **Mục đích kiểm thử:** Đảm bảo validation nghiệp vụ, phân quyền API Staff và không rò rỉ email đồng nghiệp.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; dữ liệu seed có u1 (admin), u2 (client), u5 (requester), u6 (helper).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tạo report giao cho u5 (severity=low), sau đó dùng token u6 gọi POST /staff/delegations. | JWT u6; {"report_id": reportId, "helper_id": "u5"} | HTTP 403 (không phải người được giao). |
| 2 | u5 gọi POST /staff/delegations với helper_id="u5" (tự nhờ chính mình) và gọi payload thiếu helper_id. | JWT u5; 2 payload không hợp lệ | Cả 2 request đều trả về HTTP 400. |
| 3 | Client u2 gọi GET /staff/colleagues và Staff u5 gọi GET /staff/colleagues. | JWT client u2 và JWT staff u5 | u2 nhận HTTP 403; u5 nhận HTTP 200, danh sách content không chứa id "u5" và không item nào có trường "email". |

10. **Input từng bước:**
   - Bước 1: JWT u6; {"report_id": reportId, "helper_id": "u5"}
   - Bước 2: JWT u5; 2 payload không hợp lệ
   - Bước 3: JWT client u2 và JWT staff u5
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 403 (không phải người được giao).
   - Bước 2: Cả 2 request đều trả về HTTP 400.
   - Bước 3: u2 nhận HTTP 403; u5 nhận HTTP 200, danh sách content không chứa id "u5" và không item nào có trường "email".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/staff/StaffDelegationTest.java`
13. **Ghi chú:** Tạo 1 report mới trong DB khi chạy.
