# SMP-211: Report đã xử lý (processed) trên bản đồ Client chỉ hiện cho chính chủ

1. **Mã số test case:** SMP-211
2. **Tên test case:** Report đã xử lý (processed) trên bản đồ Client chỉ hiện cho chính chủ
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Client
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Tạo một report, phân công và hoàn tất để chuyển sang trạng thái processed, sau đó kiểm tra chỉ chủ report (u2) mới thấy ở các filter null, all, mine, processed, còn người xem khác không thấy.
7. **Mục đích kiểm thử:** Đảm bảo quyền riêng tư/quy tắc hiển thị report đã hoàn tất xử lý trên bản đồ Client.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; user seed u2 (client), u1 (admin), u5 (staff) tồn tại trong DB.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Owner u2 tạo report -> Admin u1 gán cho Staff u5 -> Staff u5 gọi POST /reports/{id}/complete. | JWT u2, u1, u5; tạo, assign severity=low và complete report | Cả 3 bước trả về HTTP 200; report đạt trạng thái processed. |
| 2 | Owner u2 gọi GET /reports/map quanh point lần lượt với filter=null, all, mine, processed. | ownerToken (u2); 4 giá trị filter | Cả 4 lần gọi đều trả về HTTP 200 và chứa reportId. |
| 3 | Người dùng khác (otherToken) gọi GET /reports/map quanh point lần lượt với filter=null, all, processed, processing. | otherToken (map-test-<uuid>); 4 giá trị filter | Cả 4 lần gọi đều trả về HTTP 200 và không chứa reportId. |

10. **Input từng bước:**
   - Bước 1: JWT u2, u1, u5; tạo, assign severity=low và complete report
   - Bước 2: ownerToken (u2); 4 giá trị filter
   - Bước 3: otherToken (map-test-<uuid>); 4 giá trị filter
11. **Kỳ vọng từng bước:**
   - Bước 1: Cả 3 bước trả về HTTP 200; report đạt trạng thái processed.
   - Bước 2: Cả 4 lần gọi đều trả về HTTP 200 và chứa reportId.
   - Bước 3: Cả 4 lần gọi đều trả về HTTP 200 và không chứa reportId.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/MapReportsTest.java`
13. **Ghi chú:** Test tạo và hoàn tất 1 bản ghi report thật trong DB.
