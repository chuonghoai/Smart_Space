# SMP-360: Luồng E2E đăng nhập Client Web thành công vào trang chủ /home

1. **Mã số test case:** SMP-360
2. **Tên test case:** Luồng E2E đăng nhập Client Web thành công vào trang chủ /home
3. **Project:** Flutter Client
4. **Chức năng:** Đăng nhập E2E Client Web
5. **Loại kiểm thử:** E2E Web Automation Test (Playwright)
6. **Mô tả test case:** Nhập tài khoản Client từ PW_CLIENT_EMAIL / PW_CLIENT_PASSWORD vào màn hình đăng nhập Client Web, nhấn Đăng nhập và kiểm tra chuyển sang /home.
7. **Mục đích kiểm thử:** Xác minh luồng E2E đăng nhập Client Web kết nối Backend và điều hướng trang chủ.
8. **Điều kiện tiên quyết:** Backend và Client Web server đang chạy; có PW_CLIENT_EMAIL và PW_CLIENT_PASSWORD (nếu thiếu sẽ SKIPPED).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Boot Client Web tới /login và điền email, password từ env | PW_CLIENT_EMAIL, PW_CLIENT_PASSWORD | Hai textbox nhận đủ dữ liệu |
| 2 | Nhấn nút 'Đăng nhập' và chờ URL chứa /home | Click 'Đăng nhập' (exact) | URL chuyển sang /home |

10. **Input từng bước:**
   - Bước 1: PW_CLIENT_EMAIL, PW_CLIENT_PASSWORD
   - Bước 2: Click 'Đăng nhập' (exact)
11. **Kỳ vọng từng bước:**
   - Bước 1: Hai textbox nhận đủ dữ liệu
   - Bước 2: URL chuyển sang /home
12. **File test tương ứng:** `playwright/client/client-web.spec.ts`
13. **Ghi chú:** Không hardcode thông tin đăng nhập; tự SKIPPED khi thiếu biến môi trường.
