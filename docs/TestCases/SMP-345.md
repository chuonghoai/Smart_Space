# SMP-345: Kiểm tra RBAC: Client gọi GET /admin/home/overview bị chặn quyền 403

1. **Mã số test case:** SMP-345
2. **Tên test case:** Kiểm tra RBAC: Client gọi GET /admin/home/overview bị chặn quyền 403
3. **Project:** Spring Boot Backend
4. **Chức năng:** Phân quyền RBAC (AdminHomeController)
5. **Loại kiểm thử:** API Automation Test (Playwright)
6. **Mô tả test case:** Đăng nhập tài khoản Client từ PW_CLIENT_EMAIL / PW_CLIENT_PASSWORD, dùng accessToken gọi GET /admin/home/overview để kiểm tra bị chặn 403 Forbidden và logout sau test.
7. **Mục đích kiểm thử:** Xác minh cơ chế @PreAuthorize("hasRole('admin')") chặn tài khoản role client truy cập API Admin.
8. **Điều kiện tiên quyết:** Backend đang chạy; biến môi trường PW_CLIENT_EMAIL và PW_CLIENT_PASSWORD được cấu hình (nếu thiếu sẽ SKIPPED).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Đăng nhập role client bằng PW_CLIENT_EMAIL / PW_CLIENT_PASSWORD | role=client, deviceId ngẫu nhiên | Nhận accessToken hợp lệ của Client |
| 2 | Gọi GET /admin/home/overview kèm Bearer token của Client | Authorization: Bearer <clientAccessToken> | HTTP 403 Forbidden |
| 3 | Gọi POST /auth/logout trong finally | Authorization: Bearer <clientAccessToken> | Thu hồi phiên đăng nhập test |

10. **Input từng bước:**
   - Bước 1: role=client, deviceId ngẫu nhiên
   - Bước 2: Authorization: Bearer <clientAccessToken>
   - Bước 3: Authorization: Bearer <clientAccessToken>
11. **Kỳ vọng từng bước:**
   - Bước 1: Nhận accessToken hợp lệ của Client
   - Bước 2: HTTP 403 Forbidden
   - Bước 3: Thu hồi phiên đăng nhập test
12. **File test tương ứng:** `playwright/backend/public-and-protected-api.spec.ts`
13. **Ghi chú:** Không hardcode thông tin đăng nhập; tự SKIPPED khi thiếu biến môi trường.
