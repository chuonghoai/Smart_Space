# SMP-117: Màn hình quên mật khẩu Admin hỗ trợ tiếng Việt và Dark Theme

1. **Mã số test case:** SMP-117
2. **Tên test case:** Màn hình quên mật khẩu Admin hỗ trợ tiếng Việt và Dark Theme
3. **Project:** Flutter Admin
4. **Chức năng:** Xác thực - Quên mật khẩu Admin (Localization & Theme)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra AdminForgotPasswordScreen khi dùng locale 'vi' và AppTheme.darkTheme ở kích thước 1200x800 hiển thị AuthBrandingPanel và các text tiếng Việt 'Quay lại đăng nhập', 'Quên mật khẩu'.
7. **Mục đích kiểm thử:** Xác minh màn hình quên mật khẩu Admin hỗ trợ tiếng Việt và Dark Theme chính xác.
8. **Điều kiện tiên quyết:** Surface size đặt thành Size(1200, 800); MaterialApp dùng AppTheme.darkTheme và locale 'vi'.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Đặt kích thước bề mặt 1200x800, render AdminForgotPasswordScreen với locale 'vi' và theme AppTheme.darkTheme, gọi pump(). | AdminForgotPasswordScreen(); Size(1200, 800); locale 'vi'; AppTheme.darkTheme. | Tìm thấy 1 AuthBrandingPanel, text 'Quay lại đăng nhập' và text 'Quên mật khẩu'. |

10. **Input từng bước:**
   - Bước 1: AdminForgotPasswordScreen(); Size(1200, 800); locale 'vi'; AppTheme.darkTheme.
11. **Kỳ vọng từng bước:**
   - Bước 1: Tìm thấy 1 AuthBrandingPanel, text 'Quay lại đăng nhập' và text 'Quên mật khẩu'.
12. **File test tương ứng:** `smartspace_admin/test/ui/screen/auth/auth_responsive_test.dart`
13. **Ghi chú:** Test xác nhận render thành công với AppTheme.darkTheme và các chuỗi tiếng Việt; không assert trực tiếp giá trị màu theme.
