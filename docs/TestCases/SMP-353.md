# SMP-353: Đăng nhập Staff Web với tài khoản không tồn tại hiển thị lỗi từ Backend

1. **Mã số test case:** SMP-353
2. **Tên test case:** Đăng nhập Staff Web với tài khoản không tồn tại hiển thị lỗi từ Backend
3. **Project:** Flutter Staff
4. **Chức năng:** Tích hợp API Đăng nhập Staff Web -> Backend
5. **Loại kiểm thử:** E2E Web Automation Test (Playwright)
6. **Mô tả test case:** Nhập tài khoản không tồn tại (nonexistent-staff@smartspace.invalid) vào form đăng nhập Staff Web, nhấn Đăng nhập, lắng nghe POST /auth/login tới Backend và xác nhận HTTP 400/401 cùng giữ nguyên trang login.
7. **Mục đích kiểm thử:** Xác minh Flutter Staff Web gửi đúng request POST /auth/login tới Backend URL cấu hình qua --dart-define=API_URL và xử lý phản hồi lỗi an toàn.
8. **Điều kiện tiên quyết:** Backend và Staff Web server đang chạy; bản build Web trỏ API_URL tới Backend.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Boot Staff Web tới /#/login và điền email nonexistent-staff@smartspace.invalid cùng mật khẩu giả | email=nonexistent-staff@smartspace.invalid | Form nhận đủ giá trị |
| 2 | Nhấn 'Đăng nhập' và chờ response POST /auth/login | Click 'Đăng nhập' | Backend trả HTTP 400 hoặc 401; URL vẫn ở /login |

10. **Input từng bước:**
   - Bước 1: email=nonexistent-staff@smartspace.invalid
   - Bước 2: Click 'Đăng nhập'
11. **Kỳ vọng từng bước:**
   - Bước 1: Form nhận đủ giá trị
   - Bước 2: Backend trả HTTP 400 hoặc 401; URL vẫn ở /login
12. **File test tương ứng:** `playwright/staff/staff-web.spec.ts`
13. **Ghi chú:** Test thực tế xác nhận kết nối giữa Flutter Staff Web và Backend mà không cần tài khoản thật.
