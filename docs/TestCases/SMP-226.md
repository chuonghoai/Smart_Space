# SMP-226: Client bị chặn 403 khi truy cập API thống kê nhân viên Admin

1. **Mã số test case:** SMP-226
2. **Tên test case:** Client bị chặn 403 khi truy cập API thống kê nhân viên Admin
3. **Project:** Spring Boot Backend
4. **Chức năng:** Dashboard quản lý nhân viên
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Dùng JWT role client u2 gọi GET /admin/staffs/statistics và GET /admin/staffs/trend để xác minh server trả về HTTP 403.
7. **Mục đích kiểm thử:** Đảm bảo Client không thể truy cập dữ liệu thống kê nội bộ của Admin.
8. **Điều kiện tiên quyết:** Backend đang chạy tại BASE_URL (mặc định http://localhost:8989); JWT client u2 hợp lệ.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /admin/staffs/statistics và GET /admin/staffs/trend bằng JWT client u2 (ROLE_client). | JWT u2 (user@gmail.com, scope=ROLE_client) | Cả 2 request đều trả về HTTP 403. |

10. **Input từng bước:**
   - Bước 1: JWT u2 (user@gmail.com, scope=ROLE_client)
11. **Kỳ vọng từng bước:**
   - Bước 1: Cả 2 request đều trả về HTTP 403.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/staff/StaffDashboardTest.java`
13. **Ghi chú:** Không có.
