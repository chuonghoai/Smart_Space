# SMP-221: API danh sách nhiệm vụ bản đồ Staff trả về 401 khi thiếu token

1. **Mã số test case:** SMP-221
2. **Tên test case:** API danh sách nhiệm vụ bản đồ Staff trả về 401 khi thiếu token
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ nhiệm vụ Staff
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Gửi GET /reports/staff/assigned?status=processing&limit=100 không kèm Bearer token và kiểm tra mã lỗi HTTP 401.
7. **Mục đích kiểm thử:** Đảm bảo endpoint lấy nhiệm vụ bản đồ của Staff được bảo vệ xác thực.
8. **Điều kiện tiên quyết:** Backend đang chạy tại BASE_URL (mặc định http://localhost:8989, có thể ghi đè qua -Dsmartspace.baseUrl).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /reports/staff/assigned?status=processing&limit=100 không có header Authorization. | Token: null; Path: /reports/staff/assigned?status=processing&limit=100 | Server trả về HTTP 401. |

10. **Input từng bước:**
   - Bước 1: Token: null; Path: /reports/staff/assigned?status=processing&limit=100
11. **Kỳ vọng từng bước:**
   - Bước 1: Server trả về HTTP 401.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/staff/StaffAssignedMapTest.java`
13. **Ghi chú:** Không có.
