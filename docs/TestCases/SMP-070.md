# SMP-070: Cho phép khóa admin khác khi vẫn còn nhiều admin hoạt động

1. **Mã số test case:** SMP-070
2. **Tên test case:** Cho phép khóa admin khác khi vẫn còn nhiều admin hoạt động
3. **Project:** Flutter Admin
4. **Chức năng:** Quản lý tài khoản Admin (AdminAccountListState.canToggle)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra phương thức AdminAccountListState.canToggle trả về true khi admin hiện tại thao tác khóa một tài khoản admin khác (isCurrentUser=false) trong điều kiện có từ 2 admin đang hoạt động trở lên.
7. **Mục đích kiểm thử:** Xác minh quyền khóa tài khoản admin khác hợp lệ khi không vi phạm quy tắc tự khóa hoặc khóa admin cuối cùng.
8. **Điều kiện tiên quyết:** Khởi tạo AdminAccountModel other (active=true, isCurrentUser=false) và AdminAccountListState gồm [_admin('me', me: true), other] với active=2.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi state.canToggle(other). | other (isCurrentUser=false, status='active'), state có summary.active=2. | Kết quả trả về true. |

10. **Input từng bước:**
   - Bước 1: other (isCurrentUser=false, status='active'), state có summary.active=2.
11. **Kỳ vọng từng bước:**
   - Bước 1: Kết quả trả về true.
12. **File test tương ứng:** `smartspace_admin/test/features/admin_accounts/admin_account_models_test.dart`
13. **Ghi chú:** Không có.
