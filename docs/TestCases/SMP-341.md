# SMP-341: Luồng đăng nhập Admin, gọi /auth/me và đăng xuất qua Playwright API

1. **Mã số test case:** SMP-341
2. **Tên test case:** Luồng đăng nhập Admin, gọi /auth/me và đăng xuất qua Playwright API
3. **Project:** Spring Boot Backend
4. **Chức năng:** Đăng nhập / Hồ sơ / Đăng xuất (AuthController)
5. **Loại kiểm thử:** API Automation Test (Playwright)
6. **Mô tả test case:** Đăng nhập tài khoản Admin từ biến môi trường PW_ADMIN_EMAIL / PW_ADMIN_PASSWORD, dùng accessToken gọi GET /auth/me xác minh email khớp và gọi POST /auth/logout dọn phiên.
7. **Mục đích kiểm thử:** Xác minh chuỗi xác thực JWT đầu-cuối (login -> me -> logout) của role admin hoạt động đúng.
8. **Điều kiện tiên quyết:** Backend đang chạy; biến môi trường PW_ADMIN_EMAIL và PW_ADMIN_PASSWORD được cấu hình hợp lệ (nếu chưa cấu hình, test tự đánh dấu SKIPPED).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Kiểm tra PW_ADMIN_EMAIL / PW_ADMIN_PASSWORD; gọi POST /auth/login với role admin và deviceId ngẫu nhiên | email=PW_ADMIN_EMAIL, password=PW_ADMIN_PASSWORD, role=admin | HTTP 200, nhận accessToken hợp lệ |
| 2 | Gọi GET /auth/me kèm Bearer accessToken | Authorization: Bearer <accessToken> | HTTP 200, success=true, data.email khớp PW_ADMIN_EMAIL |
| 3 | Gọi POST /auth/logout trong finally để thu hồi phiên test | Authorization: Bearer <accessToken> | Phiên được dọn sạch sau test |

10. **Input từng bước:**
   - Bước 1: email=PW_ADMIN_EMAIL, password=PW_ADMIN_PASSWORD, role=admin
   - Bước 2: Authorization: Bearer <accessToken>
   - Bước 3: Authorization: Bearer <accessToken>
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200, nhận accessToken hợp lệ
   - Bước 2: HTTP 200, success=true, data.email khớp PW_ADMIN_EMAIL
   - Bước 3: Phiên được dọn sạch sau test
12. **File test tương ứng:** `playwright/backend/auth-api.spec.ts`
13. **Ghi chú:** Không hardcode thông tin đăng nhập trong code; nếu thiếu env test sẽ SKIPPED thay vì thất bại giả.
