# SMP-209: Bản đồ Client trả về 400 khi tham số filter không hợp lệ

1. **Mã số test case:** SMP-209
2. **Tên test case:** Bản đồ Client trả về 400 khi tham số filter không hợp lệ
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Client
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Gửi GET /reports/map với filter=rejected (không nằm trong tập cho phép all|mine|pending|processing|processed) và kiểm tra mã lỗi 400.
7. **Mục đích kiểm thử:** Đảm bảo API từ chối giá trị filter không hợp lệ phía Client.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; JWT client u2 hợp lệ.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Client u2 gửi GET /reports/map với bounds (10.7, 10.9, 106.6, 106.8) và filter=rejected. | JWT client u2; Query: min_lat=10.7&max_lat=10.9&min_lng=106.6&max_lng=106.8&filter=rejected | Server trả về HTTP 400. |

10. **Input từng bước:**
   - Bước 1: JWT client u2; Query: min_lat=10.7&max_lat=10.9&min_lng=106.6&max_lng=106.8&filter=rejected
11. **Kỳ vọng từng bước:**
   - Bước 1: Server trả về HTTP 400.
