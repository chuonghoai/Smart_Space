# SMP-287: Từ chối role null trong assertSelfRegistrableRole

1. **Mã số test case:** SMP-287
2. **Tên test case:** Từ chối role null trong assertSelfRegistrableRole
3. **Project:** Spring Boot Backend
4. **Chức năng:** Kiểm soát vai trò tự đăng ký (AuthenticationService)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra hàm assertSelfRegistrableRole(null) ném BadRequestException với thông điệp "auth.role.invalid".
7. **Mục đích kiểm thử:** Xác minh giá trị vai trò null bị coi là không hợp lệ khi kiểm tra điều kiện tự đăng ký.
8. **Điều kiện tiên quyết:** Unit test gọi trực tiếp authenticationService.assertSelfRegistrableRole(null).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi authenticationService.assertSelfRegistrableRole(null) | role = null | Ném BadRequestException với message "auth.role.invalid" |

10. **Input từng bước:**
   - Bước 1: role = null
11. **Kỳ vọng từng bước:**
   - Bước 1: Ném BadRequestException với message "auth.role.invalid"
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/auth/AuthenticationServiceSecurityTest.java`
13. **Ghi chú:** Thuộc nhóm @Nested SelfRegistration.
