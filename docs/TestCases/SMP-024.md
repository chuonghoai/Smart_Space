# SMP-024: Đổi timeframe bản đồ bỏ cache và tải lại với timeframe mới

1. **Mã số test case:** SMP-024
2. **Tên test case:** Đổi timeframe bản đồ bỏ cache và tải lại với timeframe mới
3. **Project:** Flutter Client
4. **Chức năng:** Bản đồ phản ánh (Map Reports Provider)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra sau khi đã tải viewport với timeframe mặc định 'all', gọi setTimeframe(ReportTimeframe.month3) cập nhật state.timeframe=month3, gửi timeframe='3m' lên repo và cập nhật reports=['tf-3m'].
7. **Mục đích kiểm thử:** Đảm bảo đổi khoảng thời gian trên bản đồ xóa cache và tải dữ liệu khớp tham số timeframe mới.
8. **Điều kiện tiên quyết:** Đã tải xong viewport ban đầu với timeframe mặc định 'all'.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tải viewport với ['a'] | viewport, timeframe mặc định 'all' | requestedTimeframes = ['all'] |
| 2 | Gọi setTimeframe(ReportTimeframe.month3) và hoàn tất request với ['tf-3m'] | ReportTimeframe.month3, response=['tf-3m'] | requestedTimeframes == ['all', '3m'], state.reports == ['tf-3m'], state.timeframe == ReportTimeframe.month3 |

10. **Input từng bước:**
   - Bước 1: viewport, timeframe mặc định 'all'
   - Bước 2: ReportTimeframe.month3, response=['tf-3m']
11. **Kỳ vọng từng bước:**
   - Bước 1: requestedTimeframes = ['all']
   - Bước 2: requestedTimeframes == ['all', '3m'], state.reports == ['tf-3m'], state.timeframe == ReportTimeframe.month3
12. **File test tương ứng:** `smartspace_client/test/features/reports/map_reports_provider_test.dart`
13. **Ghi chú:** Không có.
