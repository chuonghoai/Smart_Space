1. **Mã số test case:** SMP-267
2. **Tên test case:** Từ chối khi admin tự thay đổi trạng thái của chính mình

4. **Chức năng:** Quản lý tài khoản quản trị viên

8. **Điều kiện tiên quyết:** Mock dependency bằng Mockito; không cần stub repository.

11. **Kỳ vọng từng bước:**
