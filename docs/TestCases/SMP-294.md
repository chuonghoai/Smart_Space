# SMP-294: Render template mail/admin-credentials tiếng Anh và ẩn các phần tùy chọn

1. **Mã số test case:** SMP-294
2. **Tên test case:** Render template mail/admin-credentials tiếng Anh và ẩn các phần tùy chọn
3. **Project:** Spring Boot Backend
4. **Chức năng:** Template Email cấp tài khoản Admin (Thymeleaf Mail Templates)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra render template mail/admin-credentials với Locale.ENGLISH, fullName="Jane Doe", adminPortalUrl=null và supportEmail=null: HTML chứa nội dung tiếng Anh, ẩn nút "Open SmartSpace Admin Portal", ẩn "mailto:", không nhắc tới từ "staff", không thiếu key i18n và xuất preview.
7. **Mục đích kiểm thử:** Xác minh bản dịch tiếng Anh, điều kiện ẩn các khối CTA/hỗ trợ tùy chọn và đảm bảo nội dung email Admin không nhầm lẫn nhắc tới ứng dụng Staff.
8. **Điều kiện tiên quyết:** SpringTemplateEngine với template mail/admin-credentials và i18n/messages đã khởi tạo trong @BeforeAll.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Render template với Locale.ENGLISH và withOptional=false | locale=en, fullName="Jane Doe", adminPortalUrl=null, supportEmail=null, year="2026" | Trả về chuỗi HTML tiếng Anh |
| 2 | Kiểm tra nội dung tiếng Anh, điều kiện ẩn CTA/hỗ trợ và không chứa "staff" | html kết quả | Chứa "Hello Jane Doe," và "Get started in 3 steps"; không chứa "Open SmartSpace Admin Portal", "mailto:", "staff" (lowercase) và "??" |
| 3 | Ghi file preview HTML | target/mail-preview/admin-credentials_en.html | Xuất file thành công bằng UTF-8 |

10. **Input từng bước:**
   - Bước 1: locale=en, fullName="Jane Doe", adminPortalUrl=null, supportEmail=null, year="2026"
   - Bước 2: html kết quả
   - Bước 3: target/mail-preview/admin-credentials_en.html
11. **Kỳ vọng từng bước:**
   - Bước 1: Trả về chuỗi HTML tiếng Anh
   - Bước 2: Chứa "Hello Jane Doe," và "Get started in 3 steps"; không chứa "Open SmartSpace Admin Portal", "mailto:", "staff" (lowercase) và "??"
   - Bước 3: Xuất file thành công bằng UTF-8
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/mail/AdminCredentialsMailTemplateTest.java`
13. **Ghi chú:** Có ghi file preview vào target/mail-preview/admin-credentials_en.html.
