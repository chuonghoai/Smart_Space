# SMP-295: Kiểm tra HTML-escape giá trị người dùng trong template mail/admin-credentials

1. **Mã số test case:** SMP-295
2. **Tên test case:** Kiểm tra HTML-escape giá trị người dùng trong template mail/admin-credentials
3. **Project:** Spring Boot Backend
4. **Chức năng:** Template Email cấp tài khoản Admin (Thymeleaf Mail Templates)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra render template mail/admin-credentials với fullName="<script>alert(1)</script>" tự động escape thẻ script thành "&lt;script&gt;" và không xuất hiện thẻ script thực thi thô.
7. **Mục đích kiểm thử:** Đảm bảo giá trị tên quản trị viên được escape an toàn chống XSS khi render email HTML.
8. **Điều kiện tiên quyết:** SpringTemplateEngine với template mail/admin-credentials đã khởi tạo trong @BeforeAll.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Render template với fullName chứa thẻ script | locale=vi, fullName="<script>alert(1)</script>", withOptional=false | Trả về chuỗi HTML đã render |
| 2 | Kiểm tra kết quả escape HTML | html kết quả | Không chứa "<script>alert(1)</script>" và có chứa "&lt;script&gt;" |

10. **Input từng bước:**
   - Bước 1: locale=vi, fullName="<script>alert(1)</script>", withOptional=false
   - Bước 2: html kết quả
11. **Kỳ vọng từng bước:**
   - Bước 1: Trả về chuỗi HTML đã render
   - Bước 2: Không chứa "<script>alert(1)</script>" và có chứa "&lt;script&gt;"
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/mail/AdminCredentialsMailTemplateTest.java`
13. **Ghi chú:** Không có.
