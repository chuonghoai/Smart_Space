# SMP-058: Hiển thị NotificationReadFilter và chuyển sang "Chưa đọc" trên Light & Dark theme

1. **Mã số test case:** SMP-058
2. **Tên test case:** Hiển thị NotificationReadFilter và chuyển sang "Chưa đọc" trên Light & Dark theme
3. **Project:** Flutter Client
4. **Chức năng:** Bộ lọc đã đọc/chưa đọc thông báo (Notification Read Filter UI)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra NotificationReadFilter qua vòng lặp 2 biến thể theme ('light': AppTheme.lightTheme, 'dark': AppTheme.darkTheme) với unreadOnly=false và count=5: hiển thị 2 nửa 'Tất cả' và 'Chưa đọc', badge '5', và khi chạm 'Chưa đọc' gọi onChanged(true).
7. **Mục đích kiểm thử:** Xác minh giao diện thanh chuyển lọc thông báo và tương tác chuyển sang "Chưa đọc" hoạt động đúng trên cả Light Mode và Dark Mode.
8. **Điều kiện tiên quyết:** Render NotificationReadFilter trong _host dùng MaterialApp locale 'vi' cho từng theme trong danh sách [('light', AppTheme.lightTheme), ('dark', AppTheme.darkTheme)].
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Chạy biến thể Light Mode (AppTheme.lightTheme) và Dark Mode (AppTheme.darkTheme) với unreadOnly=false, count=5 | theme=lightTheme \| darkTheme, unreadOnly=false, count=5 | Cả 2 theme đều hiển thị 'Tất cả', 'Chưa đọc' và badge '5' |
| 2 | Tap vào text 'Chưa đọc' trên từng biến thể theme | Tap 'Chưa đọc' | Callback onChanged được gọi với giá trị true (changedTo == true) |

10. **Input từng bước:**
   - Bước 1: theme=lightTheme | darkTheme, unreadOnly=false, count=5
   - Bước 2: Tap 'Chưa đọc'
11. **Kỳ vọng từng bước:**
   - Bước 1: Cả 2 theme đều hiển thị 'Tất cả', 'Chưa đọc' và badge '5'
   - Bước 2: Callback onChanged được gọi với giá trị true (changedTo == true)
12. **File test tương ứng:** `smartspace_client/test/ui/notifications/notification_read_filter_test.dart`
13. **Ghi chú:** Test case logic đơn gộp 2 biến thể Light/Dark qua vòng lặp `for (final (name, theme) in ...)`.
