# SMP-297: Render template mail/staff-credentials tiếng Anh và ẩn các phần tùy chọn

1. **Mã số test case:** SMP-297
2. **Tên test case:** Render template mail/staff-credentials tiếng Anh và ẩn các phần tùy chọn
3. **Project:** Spring Boot Backend
4. **Chức năng:** Template Email cấp tài khoản Staff (Thymeleaf Mail Templates)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra render template mail/staff-credentials với Locale.ENGLISH, fullName="John Doe", positionName=null, staffAppUrl=null và supportEmail=null: HTML hiển thị tiếng Anh, ẩn CTA "Get the SmartSpace Staff app", ẩn "mailto:" và ẩn nhãn ">Position<", không thiếu key i18n và xuất preview.
7. **Mục đích kiểm thử:** Xác minh bản dịch tiếng Anh và cơ chế ẩn mục chức vụ, nút tải app, dòng hỗ trợ khi các biến tùy chọn là null.
8. **Điều kiện tiên quyết:** SpringTemplateEngine với template mail/staff-credentials và i18n/messages đã khởi tạo trong @BeforeAll.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Render template với Locale.ENGLISH, positionName=null và withOptional=false | locale=en, fullName="John Doe", positionName=null, staffAppUrl=null, supportEmail=null, year="2026" | Trả về chuỗi HTML tiếng Anh |
| 2 | Kiểm tra hiển thị tiếng Anh và việc ẩn các khối tùy chọn | html kết quả | Chứa "Hello John Doe," và "Get started in 3 steps"; không chứa "Get the SmartSpace Staff app", "mailto:", ">Position<" và "??" |
| 3 | Ghi file preview HTML | target/mail-preview/staff-credentials_en.html | Xuất file thành công bằng UTF-8 |

10. **Input từng bước:**
   - Bước 1: locale=en, fullName="John Doe", positionName=null, staffAppUrl=null, supportEmail=null, year="2026"
   - Bước 2: html kết quả
   - Bước 3: target/mail-preview/staff-credentials_en.html
11. **Kỳ vọng từng bước:**
   - Bước 1: Trả về chuỗi HTML tiếng Anh
   - Bước 2: Chứa "Hello John Doe," và "Get started in 3 steps"; không chứa "Get the SmartSpace Staff app", "mailto:", ">Position<" và "??"
   - Bước 3: Xuất file thành công bằng UTF-8
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/mail/StaffCredentialsMailTemplateTest.java`
13. **Ghi chú:** Có ghi file preview vào target/mail-preview/staff-credentials_en.html.
