# SMP-173: Bỏ phiếu đề xuất khóa trả về 400 khi decision sai và 404 khi đề xuất không tồn tại

1. **Mã số test case:** SMP-173
2. **Tên test case:** Bỏ phiếu đề xuất khóa trả về 400 khi decision sai và 404 khi đề xuất không tồn tại
3. **Project:** Spring Boot Backend
4. **Chức năng:** Biểu quyết khóa tài khoản (/admin/lock-requests/{id}/votes)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gửi POST /admin/lock-requests/not-exist/votes nhận HTTP 400 khi decision là "maybe" không hợp lệ và HTTP 404 khi decision là "approve" nhưng mã đề xuất không tồn tại.
7. **Mục đích kiểm thử:** Đảm bảo endpoint bỏ phiếu kiểm tra giá trị decision hợp lệ và sự tồn tại của đề xuất khóa.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); không tồn tại lock-request có id "not-exist"; JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin gửi POST /admin/lock-requests/not-exist/votes với decision không hợp lệ | {"decision":"maybe"} | HTTP 400 Bad Request. |
| 2 | Admin gửi POST /admin/lock-requests/not-exist/votes với decision "approve" | {"decision":"approve"} | HTTP 404 Not Found. |

10. **Input từng bước:**
   - Bước 1: {"decision":"maybe"}
   - Bước 2: {"decision":"approve"}
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 400 Bad Request.
   - Bước 2: HTTP 404 Not Found.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AccountLockRequestManagementTest.java`
13. **Ghi chú:** Không tạo side-effect. Class này chưa đăng ký trong testapi.ps1.
