# SMP-128: AdminHomeScreen hiển thị bố cục mobile và AdminQuickAccessBar cuộn ngang khi width < 1024

1. **Mã số test case:** SMP-128
2. **Tên test case:** AdminHomeScreen hiển thị bố cục mobile và AdminQuickAccessBar cuộn ngang khi width < 1024
3. **Project:** Flutter Admin
4. **Chức năng:** Trang chủ Admin (AdminHomeScreen Responsive)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra AdminHomeScreen trên kích thước mobile 400x900 (< 1024px) ẩn icon header desktop Icons.shield_outlined, sử dụng AdminQuickAccessBar ở chế độ cuộn ngang (isPanelMode == false) và vẫn hiển thị số liệu KPI '120'.
7. **Mục đích kiểm thử:** Xác minh breakpoint mobile (< 1024px) của AdminHomeScreen chuyển sang bố cục thu gọn phù hợp màn hình hẹp.
8. **Điều kiện tiên quyết:** Surface size Size(400, 900); _buildTestApp override các provider trang chủ giống SMP-127.
