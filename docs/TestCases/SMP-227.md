# SMP-227: Báo cáo trạng thái processed không thể chuyển sang trạng thái khác qua PATCH status

1. **Mã số test case:** SMP-227
2. **Tên test case:** Báo cáo trạng thái processed không thể chuyển sang trạng thái khác qua PATCH status
3. **Project:** Spring Boot Backend
4. **Chức năng:** Dashboard quản lý nhân viên
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Lấy một báo cáo đang có trạng thái processed thật trong DB rồi thử chuyển trạng thái về processing, pending và rejected qua PATCH /admin/reports/{id}/status để xác nhận bị từ chối.
7. **Mục đích kiểm thử:** Khóa giả định nghiệp vụ rằng processed là trạng thái cuối không thể sửa bằng PATCH /status (nhằm giữ tính đúng đắn khi thống kê dựa vào updatedAt).
8. **Điều kiện tiên quyết:** Backend đang chạy tại BASE_URL (mặc định http://localhost:8989); DB phải có ít nhất 1 report trạng thái processed (nếu không test sẽ skip qua assumeTrue).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin u1 gọi GET /admin/reports?status=processed&size=1 và trích xuất reportId đầu tiên qua assumeTrue. | JWT admin u1; GET /admin/reports?status=processed&size=1 | Tìm được ít nhất 1 reportId đang processed. |
| 2 | Lần lượt gửi PATCH /admin/reports/{reportId}/status với {"status": "processing"}, "pending" và "rejected". | JWT admin u1; 3 payload chuyển trạng thái từ processed | Cả 3 lần gọi đều trả về statusCode khác 200. |

10. **Input từng bước:**
   - Bước 1: JWT admin u1; GET /admin/reports?status=processed&size=1
   - Bước 2: JWT admin u1; 3 payload chuyển trạng thái từ processed
11. **Kỳ vọng từng bước:**
   - Bước 1: Tìm được ít nhất 1 reportId đang processed.
   - Bước 2: Cả 3 lần gọi đều trả về statusCode khác 200.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/staff/StaffDashboardTest.java`
13. **Ghi chú:** Phụ thuộc dữ liệu thật có report processed trong DB (skip nếu trống). Chỉ kiểm tra PATCH /admin/reports/{id}/status không trả HTTP 200 (chú ý ReviewReportRehandledTest kiểm tra reopen qua endpoint này nhưng ở đó có flow review unresolved trước đó).
