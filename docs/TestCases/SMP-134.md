# SMP-134: AppLayout hiển thị bottomNavigationBar trên bố cục mobile

1. **Mã số test case:** SMP-134
2. **Tên test case:** AppLayout hiển thị bottomNavigationBar trên bố cục mobile
3. **Project:** Flutter Admin
4. **Chức năng:** Responsive Mobile/Web - AppLayout bottomNavigationBar
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra AppLayout khi truyền tham số bottomNavigationBar trên kích thước mobile (400x800) sẽ hiển thị cả bottomNavigationBar lẫn nội dung chính.
7. **Mục đích kiểm thử:** Xác minh AppLayout giữ và hiển thị đúng widget bottomNavigationBar ở chế độ màn hình nhỏ.
8. **Điều kiện tiên quyết:** TestWidgetsFlutterBinding.ensureInitialized(); Surface size Size(400, 800); ProviderScope override notificationProvider (_TestNotificationRepo) và staffsProvider (_MockStaffsNotifier trả về []).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Đặt kích thước 400x800, render AppLayout(bottomNavigationBar: Text('BottomBarTest'), child: Text('ContentTest')) qua _buildTestApp và gọi pump(). | AppLayout với bottomNavigationBar: Text('BottomBarTest'), child: Text('ContentTest'); Size(400, 800). | Tìm thấy cả text 'BottomBarTest' và 'ContentTest' (mỗi text findsOneWidget). |

10. **Input từng bước:**
   - Bước 1: AppLayout với bottomNavigationBar: Text('BottomBarTest'), child: Text('ContentTest'); Size(400, 800).
11. **Kỳ vọng từng bước:**
   - Bước 1: Tìm thấy cả text 'BottomBarTest' và 'ContentTest' (mỗi text findsOneWidget).
