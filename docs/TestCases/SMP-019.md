# SMP-019: Lọc bỏ report có tọa độ (0, 0) khỏi danh sách bản đồ

1. **Mã số test case:** SMP-019
2. **Tên test case:** Lọc bỏ report có tọa độ (0, 0) khỏi danh sách bản đồ
3. **Project:** Flutter Client
4. **Chức năng:** Bản đồ phản ánh (Map Reports Provider)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra khi API trả về 2 report gồm 'a' (tọa độ hợp lệ 10.8, 106.7) và 'zero' (latitude=0, longitude=0), MapReportsNotifier lọc bỏ report 'zero' và chỉ lưu ['a'] vào state.
7. **Mục đích kiểm thử:** Ngăn marker rác có tọa độ không hợp lệ (0, 0) xuất hiện trên bản đồ.
8. **Điều kiện tiên quyết:** Response chứa 1 report tọa độ hợp lệ và 1 report tọa độ (0, 0).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi loadForViewport(viewport) và hoàn tất với [_report('a'), _report('zero').copyWith(latitude: 0, longitude: 0)] | reports=['a' (10.8,106.7), 'zero' (0,0)] | notifier.state.reports chỉ chứa ['a'] |

10. **Input từng bước:**
   - Bước 1: reports=['a' (10.8,106.7), 'zero' (0,0)]
11. **Kỳ vọng từng bước:**
   - Bước 1: notifier.state.reports chỉ chứa ['a']
12. **File test tương ứng:** `smartspace_client/test/features/reports/map_reports_provider_test.dart`
13. **Ghi chú:** Không có.
