# SMP-161: Đánh dấu truncated khi số lượng report đạt ngưỡng limit

1. **Mã số test case:** SMP-161
2. **Tên test case:** Đánh dấu truncated khi số lượng report đạt ngưỡng limit
3. **Project:** Flutter Staff
4. **Chức năng:** Bản đồ nhân viên (Staff Map)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra StaffMapReportsNotifier đặt thuộc tính truncated = true khi API trả về đúng 100 report (bằng StaffMapReportsNotifier.limit).
7. **Mục đích kiểm thử:** Đảm bảo UI nhận biết được khả năng dữ liệu bản đồ bị cắt bớt khi chạm giới hạn tối đa của endpoint.
8. **Điều kiện tiên quyết:** ProviderContainer với _FakeReportRepo đang chờ response cho request khởi tạo.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Hoàn tất Completer với danh sách 100 ReportModel (từ r0 đến r99) và đọc future. | List gồm 100 report (StaffMapReportsNotifier.limit = 100) | data.truncated trả về true. |

10. **Input từng bước:**
   - Bước 1: List gồm 100 report (StaffMapReportsNotifier.limit = 100)
11. **Kỳ vọng từng bước:**
   - Bước 1: data.truncated trả về true.
12. **File test tương ứng:** `smartspace_staff/test/features/map/staff_map_test.dart`
13. **Ghi chú:** Sử dụng _FakeReportRepo.
