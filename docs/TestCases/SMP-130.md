# SMP-130: MapLegend hiển thị đủ 4 nhãn trạng thái phản ánh

1. **Mã số test case:** SMP-130
2. **Tên test case:** MapLegend hiển thị đủ 4 nhãn trạng thái phản ánh
3. **Project:** Flutter Admin
4. **Chức năng:** Bản đồ sự cố Admin - Chú giải trạng thái (MapLegend)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra widget MapLegend hiển thị đủ 4 nhãn trạng thái phản ánh bằng tiếng Việt gồm 'Đang chờ', 'Đang xử lý', 'Đã xử lý' và 'Từ chối'.

8. **Điều kiện tiên quyết:** ProviderScope override mapStaffListProvider trả về Future.value([]); MaterialApp dùng AppLocalizations.delegate, locale 'vi'.
