# SMP-061: Template smoke test counter mặc định của Flutter trên SmartSpaceApp

1. **Mã số test case:** SMP-061
2. **Tên test case:** Template smoke test counter mặc định của Flutter trên SmartSpaceApp
3. **Project:** Flutter Client
4. **Chức năng:** Khởi tạo ứng dụng (Default Flutter Template)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Test template mặc định do Flutter sinh sẵn: pump const SmartSpaceApp(), kiểm tra text '0' tồn tại và '1' không tồn tại, tap Icons.add rồi kiểm tra text '1' xuất hiện.
7. **Mục đích kiểm thử:** Ghi nhận file test mặc định hiện có trong smartspace_client/test/widget_test.dart (theo code thực tế kiểm tra counter '0'/'1').
8. **Điều kiện tiên quyết:** Không cấu hình ProviderScope, dotenv, Firebase hay TokenStorage; chỉ gọi tester.pumpWidget(const SmartSpaceApp()).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi await tester.pumpWidget(const SmartSpaceApp()) | const SmartSpaceApp() | Theo code template kỳ vọng tìm thấy text '0' và không tìm thấy '1' (thực tế không khớp app SmartSpaceApp) |
| 2 | Tap Icons.add, pump() và kiểm tra tăng counter | Tap Icons.add | Theo code template kỳ vọng text '0' biến mất và text '1' xuất hiện (không khớp app thực tế) |

10. **Input từng bước:**
   - Bước 1: const SmartSpaceApp()
   - Bước 2: Tap Icons.add
11. **Kỳ vọng từng bước:**
   - Bước 1: Theo code template kỳ vọng tìm thấy text '0' và không tìm thấy '1' (thực tế không khớp app SmartSpaceApp)
   - Bước 2: Theo code template kỳ vọng text '0' biến mất và text '1' xuất hiện (không khớp app thực tế)
12. **File test tương ứng:** `smartspace_client/test/widget_test.dart`
13. **Ghi chú:** Đây là template counter mặc định của Flutter, giữ nguyên code không sửa. Test kiểm tra màn hình counter mặc định '0'/'1' với SmartSpaceApp() và sẽ FAIL khi thực thi vì SmartSpaceApp là root MaterialApp.router của SmartSpace chứ không phải màn hình counter mặc định (cũng chưa bọc ProviderScope/khởi tạo phụ thuộc).
