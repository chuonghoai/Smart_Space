# SMP-061: Smoke test khởi chạy SmartSpaceApp với Firebase test mock

1. **Mã số test case:** SMP-061
2. **Tên test case:** Smoke test khởi chạy SmartSpaceApp với Firebase test mock
3. **Project:** Flutter Client
4. **Chức năng:** Khởi tạo ứng dụng gốc (SmartSpaceApp)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Thiết lập helper mock Firebase test-only (`setupFirebaseTestMocks()`), `SharedPreferences.setMockInitialValues({})`, `FlutterSecureStorage.setMockInitialValues({})`, `TokenStorage.init(AppScope.client)`, `dotenv.loadFromString(...)`, override `nearbyAlertTimerProvider` thành stream rỗng để tránh timer định kỳ treo khi unmount, sau đó pump `ProviderScope` bọc `const SmartSpaceApp()`.
7. **Mục đích kiểm thử:** Xác minh `SmartSpaceApp` và `AppServicesInitializer` khởi tạo cây `MaterialApp` trong môi trường `flutter test` mà không phát sinh `FirebaseException` hay lỗi runtime, đồng thời không làm thay đổi mã nguồn production (`lib/`).
8. **Điều kiện tiên quyết:** Đã gọi `setupFirebaseTestMocks()` trong `setUpAll` (từ `smartspace_client/test/helpers/firebase_test_mock.dart`) và dọn handler trong `tearDownAll`.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Khởi tạo test-only Firebase mock và storage/env mock trong `setUpAll` | `setupFirebaseTestMocks()`, `AppScope.client` | Mock FirebaseApp `[DEFAULT]` và `MethodChannel` FCM sẵn sàng |
| 2 | Pump `ProviderScope(child: const SmartSpaceApp())` và pump frame | Root widget `SmartSpaceApp` | `tester.takeException()` là `null`, tìm thấy 1 `MaterialApp` |

10. **Input từng bước:**
   - Bước 1: `setupFirebaseTestMocks()`, mock `SharedPreferences`, `FlutterSecureStorage`, `TokenStorage.init(AppScope.client)`, `dotenv`
   - Bước 2: `ProviderScope` + `const SmartSpaceApp()`
11. **Kỳ vọng từng bước:**
   - Bước 1: Khởi tạo Firebase test mock hoàn tất, không lỗi
   - Bước 2: `tester.takeException()` bằng `null`, `find.byType(MaterialApp)` khớp 1 widget
12. **File test tương ứng:** `smartspace_client/test/widget_test.dart`
13. **Ghi chú:** Sử dụng test-only helper tại `smartspace_client/test/helpers/firebase_test_mock.dart`, tách biệt hoàn toàn khỏi `lib/`.
