# SMP-333: ClusterLayerColors.fromTheme tự động chọn màu chữ tương phản theo nền cảnh báo

1. **Mã số test case:** SMP-333
2. **Tên test case:** ClusterLayerColors.fromTheme tự động chọn màu chữ tương phản theo nền cảnh báo
3. **Project:** Flutter Shared (mobile_shared)
4. **Chức năng:** Khung nhìn & Cluster bản đồ (MapViewport)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra ClusterLayerColors.fromTheme(theme, alert: ...) tự chọn màu chữ onAlert: khi nền là vàng sáng (0xFFF9A825) thì onAlert là Colors.black, còn khi nền là xanh đậm (0xFF1565C0) thì onAlert là Colors.white.
7. **Mục đích kiểm thử:** Đảm bảo số đếm trên vòng tròn cluster luôn đủ độ tương phản dễ đọc với mọi màu cảnh báo tuỳ chọn.
8. **Điều kiện tiên quyết:** Tạo theme = ThemeData.light().
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi ClusterLayerColors.fromTheme(theme, alert: const Color(0xFFF9A825)). | alert = Color(0xFFF9A825) (nền sáng) | onAlert bằng Colors.black. |
| 2 | Gọi ClusterLayerColors.fromTheme(theme, alert: const Color(0xFF1565C0)). | alert = Color(0xFF1565C0) (nền tối) | onAlert bằng Colors.white. |

10. **Input từng bước:**
   - Bước 1: alert = Color(0xFFF9A825) (nền sáng)
   - Bước 2: alert = Color(0xFF1565C0) (nền tối)
11. **Kỳ vọng từng bước:**
   - Bước 1: onAlert bằng Colors.black.
   - Bước 2: onAlert bằng Colors.white.
12. **File test tương ứng:** `mobile_shared/test/features/map/map_viewport_test.dart`
13. **Ghi chú:** Không có.
