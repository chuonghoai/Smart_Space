# SMP-147: Debounce tìm kiếm đồng nghiệp và loại bỏ response cũ (stale)

1. **Mã số test case:** SMP-147
2. **Tên test case:** Debounce tìm kiếm đồng nghiệp và loại bỏ response cũ (stale)
3. **Project:** Flutter Staff
4. **Chức năng:** Nhờ đồng nghiệp làm giùm (Delegation)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra colleagueSearchProvider thực hiện tải mặc định với query '', sau đó khi gọi search('a') và search('an') liên tiếp thì debounce chỉ gửi 1 request cho 'an'; đồng thời nếu response của request cũ ('') về sau response mới ('an'), kết quả của request cũ sẽ bị bỏ qua.
7. **Mục đích kiểm thử:** Đảm bảo tìm kiếm đồng nghiệp tối ưu số lần gọi API bằng debounce và tránh ghi đè dữ liệu mới bởi phản hồi trễ (race condition).
8. **Điều kiện tiên quyết:** ProviderContainer với _FakeRepo ghi nhận mọi lời gọi searchColleagues và giữ danh sách Completer.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Lắng nghe colleagueSearchProvider và chờ microtask khởi tạo. | query mặc định '' | repo.colleagueCalls có 1 lời gọi với query = ''. |
| 2 | Gọi liên tiếp notifier.search('a') và notifier.search('an'), sau đó chờ hết thời gian ColleagueSearchNotifier.debounce + 50ms. | search('a') -> search('an'), đợi 350ms + 50ms | repo.colleagueCalls chỉ có danh sách query ['', 'an'] (không gọi cho 'a'). |
| 3 | Hoàn tất Completer mới nhất (index cuối) với ColleagueModel id='u7', rồi hoàn tất Completer cũ (index đầu) với id='u8'. | Response mới: id='u7'; response cũ: id='u8' | state.items chỉ chứa ['u7'], response cũ 'u8' bị bỏ qua. |

10. **Input từng bước:**
   - Bước 1: query mặc định ''
   - Bước 2: search('a') -> search('an'), đợi 350ms + 50ms
   - Bước 3: Response mới: id='u7'; response cũ: id='u8'
11. **Kỳ vọng từng bước:**
   - Bước 1: repo.colleagueCalls có 1 lời gọi với query = ''.
   - Bước 2: repo.colleagueCalls chỉ có danh sách query ['', 'an'] (không gọi cho 'a').
   - Bước 3: state.items chỉ chứa ['u7'], response cũ 'u8' bị bỏ qua.
12. **File test tương ứng:** `smartspace_staff/test/features/delegation/delegation_test.dart`
13. **Ghi chú:** ColleagueSearchNotifier.debounce có giá trị 350ms trong mã nguồn.
