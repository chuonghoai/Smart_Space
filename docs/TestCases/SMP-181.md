# SMP-181: Validation lỗi 400 khi tạo admin mới với fullName/email/phone không hợp lệ

1. **Mã số test case:** SMP-181
2. **Tên test case:** Validation lỗi 400 khi tạo admin mới với fullName/email/phone không hợp lệ
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản Hội đồng quản trị (POST /admin/admins)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gửi POST /admin/admins với fullName rỗng, email sai định dạng ("not-an-email") hoặc phone chứa ký tự không hợp lệ ("12ab") bị từ chối với HTTP 400 trước khi tạo tài khoản hay gửi email.
7. **Mục đích kiểm thử:** Đảm bảo Bean Validation kiểm tra chặt dữ liệu đầu vào khi tạo tài khoản admin mới.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi POST /admin/admins với fullName rỗng | {"fullName":"","email":"a@b.vn"} | HTTP 400 Bad Request. |
| 2 | Gửi POST /admin/admins với email sai định dạng | {"fullName":"A","email":"not-an-email"} | HTTP 400 Bad Request. |
| 3 | Gửi POST /admin/admins với phone không hợp lệ | {"fullName":"A","email":"a@b.vn","phone":"12ab"} | HTTP 400 Bad Request. |

10. **Input từng bước:**
   - Bước 1: {"fullName":"","email":"a@b.vn"}
   - Bước 2: {"fullName":"A","email":"not-an-email"}
   - Bước 3: {"fullName":"A","email":"a@b.vn","phone":"12ab"}
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 400 Bad Request.
   - Bước 2: HTTP 400 Bad Request.
   - Bước 3: HTTP 400 Bad Request.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminAccountManagementTest.java`
13. **Ghi chú:** Các request bị chặn ngay ở bước validation nên không tạo dữ liệu và không gửi email thật. Chưa đăng ký trong testapi.ps1.
