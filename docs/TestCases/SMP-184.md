# SMP-184: Danh sách người dùng của Admin chỉ gồm client, có reportCount, không lộ admin/staff

1. **Mã số test case:** SMP-184
2. **Tên test case:** Danh sách người dùng của Admin chỉ gồm client, có reportCount, không lộ admin/staff
3. **Project:** Spring Boot Backend
4. **Chức năng:** Admin quản lý người dùng (GET /admin/users)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gọi GET /admin/users?page=1&size=50&sort=newest trả về HTTP 200 với PageResponse chứa "content", "reportCount", có tài khoản client user@gmail.com và không chứa admin@gmail.com hay staff1@gmail.com.
7. **Mục đích kiểm thử:** Đảm bảo danh sách người dùng của Admin chỉ hiển thị tài khoản client kèm số lượng phản ánh và tách biệt hoàn toàn với tài khoản nội bộ.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); CSDL có seed_data.sql (u1=admin@gmail.com, u5=staff1@gmail.com, u2=user@gmail.com); JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin u1 gửi GET /admin/users?page=1&size=50&sort=newest | Query page=1, size=50, sort=newest kèm admin token u1 | HTTP 200; body chứa "content", "reportCount", "user@gmail.com" và không chứa "admin@gmail.com" hay "staff1@gmail.com". |

10. **Input từng bước:**
   - Bước 1: Query page=1, size=50, sort=newest kèm admin token u1
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; body chứa "content", "reportCount", "user@gmail.com" và không chứa "admin@gmail.com" hay "staff1@gmail.com".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminUserManagementTest.java`
13. **Ghi chú:** Class này đã đăng ký trong testapi.ps1 dưới lệnh AdminUsers.
