# SMP-316: Chuyển đổi khứ hồi MapFocusTarget qua URI query parameters

1. **Mã số test case:** SMP-316
2. **Tên test case:** Chuyển đổi khứ hồi MapFocusTarget qua URI query parameters
3. **Project:** Flutter Shared (mobile_shared)
4. **Chức năng:** Bản đồ dùng chung (MapFocusTarget)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra MapFocusTarget(reportId: 'r-1', latitude: 10.8231, longitude: 106.6297) khi gọi toLocation('/map') tạo ra URI có path '/map' và khi truyền queryParameters vào MapFocusTarget.fromQueryParameters trả về đối tượng bằng đúng target ban đầu.
7. **Mục đích kiểm thử:** Đảm bảo việc truyền thông tin report cần focus qua route query parameter (deep link) bảo toàn nguyên vẹn dữ liệu.
8. **Điều kiện tiên quyết:** Khởi tạo target = MapFocusTarget(reportId: 'r-1', latitude: 10.8231, longitude: 106.6297).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi target.toLocation('/map') và parse kết quả bằng Uri.parse. | mapPath = '/map', target = (r-1, 10.8231, 106.6297) | uri.path bằng '/map'. |
| 2 | Gọi MapFocusTarget.fromQueryParameters(uri.queryParameters). | uri.queryParameters | Kết quả trả về bằng đúng target ban đầu (reportId='r-1', latitude=10.8231, longitude=106.6297). |

10. **Input từng bước:**
   - Bước 1: mapPath = '/map', target = (r-1, 10.8231, 106.6297)
   - Bước 2: uri.queryParameters
11. **Kỳ vọng từng bước:**
   - Bước 1: uri.path bằng '/map'.
   - Bước 2: Kết quả trả về bằng đúng target ban đầu (reportId='r-1', latitude=10.8231, longitude=106.6297).
12. **File test tương ứng:** `mobile_shared/test/features/map/map_focus_target_test.dart`
13. **Ghi chú:** Không có.
