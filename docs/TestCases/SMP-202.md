# SMP-202: Luồng Client tạo phản ánh và Admin phân công cho Staff

1. **Mã số test case:** SMP-202
2. **Tên test case:** Luồng Client tạo phản ánh và Admin phân công cho Staff
3. **Project:** Spring Boot Backend
4. **Chức năng:** Tạo và phân công phản ánh
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Mô phỏng luồng Client u2 gửi POST /reports tạo phản ánh mất nước tòa A, sau đó Admin u1 gọi POST /admin/reports/{id}/assign phân công cho Staff u5 với mức độ high.
7. **Mục đích kiểm thử:** Kiểm tra tích hợp API tạo phản ánh và phân công xử lý giữa Client, Admin và Staff qua HTTP thật.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; dữ liệu seed có các user u1 (admin), u2 (client), u5 (staff).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tạo JWT client cho u2 và gửi POST /reports tạo phản ánh sự cố mất nước. | JWT u2 (scope=client); Payload JSON với title="Sự cố mất nước sinh hoạt tòa A", latitude=10.8506, longitude=106.7720, 1 image_url | HTTP 200; trích xuất được data.id khác null và không rỗng. |
| 2 | Tạo JWT admin cho u1 và gửi POST /admin/reports/{reportId}/assign. | JWT u1 (scope=ROLE_admin); Body: {"staffId": "u5", "severity": "high"} | HTTP 200 và response body chứa "success":true. |

10. **Input từng bước:**
   - Bước 1: JWT u2 (scope=client); Payload JSON với title="Sự cố mất nước sinh hoạt tòa A", latitude=10.8506, longitude=106.7720, 1 image_url
   - Bước 2: JWT u1 (scope=ROLE_admin); Body: {"staffId": "u5", "severity": "high"}
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; trích xuất được data.id khác null và không rỗng.
   - Bước 2: HTTP 200 và response body chứa "success":true.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/AssignReportTest.java`
13. **Ghi chú:** Console in nhắc kiểm tra realtime event thủ công trên app Client, nhưng test chỉ assert phản hồi HTTP REST và không kiểm tra WebSocket/Notification tự động.
