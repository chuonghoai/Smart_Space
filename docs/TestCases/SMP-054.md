1. **Mã số test case:** SMP-054
2. **Tên test case:** Nút cài đặt trên MapControls kích hoạt callback onSettingsPressed
3. **Project:** Flutter Client
4. **Chức năng:** Giao diện bản đồ mật độ (Map Density UI)
