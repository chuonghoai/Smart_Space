# SMP-344: Kiểm tra GET /reports/map không có token trả về 401

1. **Mã số test case:** SMP-344
2. **Tên test case:** Kiểm tra GET /reports/map không có token trả về 401
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh (ReportController)
5. **Loại kiểm thử:** API Automation Test (Playwright)
6. **Mô tả test case:** Gửi GET /reports/map kèm tham số bounding box hợp lệ nhưng không có token để kiểm tra phản hồi 401.
7. **Mục đích kiểm thử:** Xác minh API bản đồ phản ánh yêu cầu người dùng đã đăng nhập.
8. **Điều kiện tiên quyết:** Backend đang chạy tại PW_BACKEND_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /reports/map?min_lat=10.7&max_lat=10.9&min_lng=106.6&max_lng=106.8 không có token | min_lat=10.7, max_lat=10.9, min_lng=106.6, max_lng=106.8 | HTTP 401 Unauthorized |

10. **Input từng bước:**
   - Bước 1: min_lat=10.7, max_lat=10.9, min_lng=106.6, max_lng=106.8
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 401 Unauthorized
12. **File test tương ứng:** `playwright/backend/public-and-protected-api.spec.ts`
13. **Ghi chú:** Không có.
