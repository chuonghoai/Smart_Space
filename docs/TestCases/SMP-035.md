# SMP-035: ReportModel.fromJson parse trường user_id

1. **Mã số test case:** SMP-035
2. **Tên test case:** ReportModel.fromJson parse trường user_id
3. **Project:** Flutter Client
4. **Chức năng:** Chỉnh sửa & Hủy phản ánh (Report Edit & Cancel)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra ReportModel.fromJson parse đúng trường snake_case 'user_id': 'user-123' cùng id='rep-1' và status=ReportStatus.pending.
7. **Mục đích kiểm thử:** Đảm bảo xác định đúng chủ sở hữu báo cáo từ JSON để kiểm tra quyền chỉnh sửa/hủy.
8. **Điều kiện tiên quyết:** JSON ReportModel có 'id': 'rep-1', 'status': 'pending', 'user_id': 'user-123'.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi ReportModel.fromJson(json) | JSON ReportModel với user_id='user-123' | model.id == 'rep-1', model.userId == 'user-123', model.status == ReportStatus.pending |

10. **Input từng bước:**
   - Bước 1: JSON ReportModel với user_id='user-123'
11. **Kỳ vọng từng bước:**
   - Bước 1: model.id == 'rep-1', model.userId == 'user-123', model.status == ReportStatus.pending
12. **File test tương ứng:** `smartspace_client/test/features/reports/report_edit_cancel_test.dart`
13. **Ghi chú:** Không có.
