# SMP-186: Giới hạn pageSize tối đa về 50 cho GET /admin/users

1. **Mã số test case:** SMP-186
2. **Tên test case:** Giới hạn pageSize tối đa về 50 cho GET /admin/users
3. **Project:** Spring Boot Backend
4. **Chức năng:** Admin quản lý người dùng (GET /admin/users)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra khi Admin truyền size=100000 tới GET /admin/users?page=1&size=100000, server tự động giới hạn pageSize trả về tối đa 50.
7. **Mục đích kiểm thử:** Ngăn ngừa yêu cầu phân trang quá lớn gây ảnh hưởng hiệu năng hệ thống.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin u1 gửi GET /admin/users?page=1&size=100000 | Query page=1, size=100000 | HTTP 200 và body JSON chứa "pageSize":50. |

10. **Input từng bước:**
   - Bước 1: Query page=1, size=100000
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200 và body JSON chứa "pageSize":50.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminUserManagementTest.java`
13. **Ghi chú:** Class này đã đăng ký trong testapi.ps1 dưới lệnh AdminUsers.
