# SMP-210: Bản đồ Client kiểm tra bộ lọc pending, processing và mine

1. **Mã số test case:** SMP-210
2. **Tên test case:** Bản đồ Client kiểm tra bộ lọc pending, processing và mine
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Client
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra quyền hiển thị trên GET /reports/map giữa chủ report (u2) và người xem khác (userId ngẫu nhiên) theo trạng thái pending, processing và filter=mine.
7. **Mục đích kiểm thử:** Xác minh report pending/processing hiển thị cho mọi người theo đúng filter trạng thái, trong khi filter=mine chỉ hiển thị report của chính chủ.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; user seed u2 (client), u1 (admin), u5 (staff) tồn tại trong DB.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Client u2 (ownerToken) tạo report mới ở trạng thái pending tại point; tạo otherToken với userId="map-test-<uuid>". | ownerToken (u2), otherToken (map-test-<uuid>); POST /reports tại point | Tạo report thành công (HTTP 200). |
| 2 | Gọi GET /reports/map quanh point bằng otherToken (filter=pending, processing, mine) và ownerToken (filter=mine). | Bounds point ± 0.0005 với các filter pending, processing, mine | otherToken thấy report ở filter=pending, không thấy ở processing và mine; ownerToken thấy ở filter=mine. |
| 3 | Admin u1 phân công report cho Staff u5 (trạng thái chuyển sang processing), rồi otherToken kiểm tra lại filter=processing và filter=pending. | POST /admin/reports/{id}/assign với staffId=u5, severity=low; GET /reports/map với otherToken | otherToken thấy report ở filter=processing và không thấy ở filter=pending. |

10. **Input từng bước:**
   - Bước 1: ownerToken (u2), otherToken (map-test-<uuid>); POST /reports tại point
   - Bước 2: Bounds point ± 0.0005 với các filter pending, processing, mine
   - Bước 3: POST /admin/reports/{id}/assign với staffId=u5, severity=low; GET /reports/map với otherToken
11. **Kỳ vọng từng bước:**
   - Bước 1: Tạo report thành công (HTTP 200).
   - Bước 2: otherToken thấy report ở filter=pending, không thấy ở processing và mine; ownerToken thấy ở filter=mine.
   - Bước 3: otherToken thấy report ở filter=processing và không thấy ở filter=pending.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/MapReportsTest.java`
13. **Ghi chú:** Test tạo report mới vào DB và chuyển sang processing.
