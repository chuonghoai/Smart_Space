# SMP-310: Kiểm tra phân loại mức độ mật độ và mã màu tương ứng theo ngưỡng số lượng

1. **Mã số test case:** SMP-310
2. **Tên test case:** Kiểm tra phân loại mức độ mật độ và mã màu tương ứng theo ngưỡng số lượng
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ mật độ báo cáo H3 (ReportDensityServiceImpl)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra hai hàm tĩnh ReportDensityServiceImpl.classifyLevel và classifyColor phân loại chính xác các ngưỡng: 1-2 -> "LOW" ("#22C55E"), 3-5 -> "MEDIUM" ("#F59E0B"), và >5 (6, 20) -> "HIGH" ("#EF4444").
7. **Mục đích kiểm thử:** Xác minh bảng ngưỡng phân loại mật độ và mã màu hiển thị trên bản đồ nhiệt.
8. **Điều kiện tiên quyết:** Gọi trực tiếp hàm tĩnh ReportDensityServiceImpl.classifyLevel(int) và classifyColor(String).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Kiểm tra nhóm LOW với giá trị 1 và 2 | count = 1, 2 | classifyLevel trả về "LOW"; classifyColor("LOW") trả về "#22C55E" |
| 2 | Kiểm tra nhóm MEDIUM với giá trị 3, 4, 5 | count = 3, 4, 5 | classifyLevel trả về "MEDIUM"; classifyColor("MEDIUM") trả về "#F59E0B" |
| 3 | Kiểm tra nhóm HIGH với giá trị 6 và 20 | count = 6, 20 | classifyLevel trả về "HIGH"; classifyColor("HIGH") trả về "#EF4444" |

10. **Input từng bước:**
   - Bước 1: count = 1, 2
   - Bước 2: count = 3, 4, 5
   - Bước 3: count = 6, 20
11. **Kỳ vọng từng bước:**
   - Bước 1: classifyLevel trả về "LOW"; classifyColor("LOW") trả về "#22C55E"
   - Bước 2: classifyLevel trả về "MEDIUM"; classifyColor("MEDIUM") trả về "#F59E0B"
   - Bước 3: classifyLevel trả về "HIGH"; classifyColor("HIGH") trả về "#EF4444"
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/report/ReportDensityServiceTest.java`
13. **Ghi chú:** Không có.
