# SMP-200: Bản đồ Admin lọc đúng khung nhìn và vẫn hiển thị report rejected

1. **Mã số test case:** SMP-200
2. **Tên test case:** Bản đồ Admin lọc đúng khung nhìn và vẫn hiển thị report rejected
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Admin
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Tạo report mới tại tọa độ ngẫu nhiên, kiểm tra GET /admin/reports/map chỉ trả report trong khung bounds và sau khi Admin từ chối (rejected) thì Admin vẫn thấy report đó trên bản đồ.
7. **Mục đích kiểm thử:** Xác minh bộ lọc khung nhìn bounds và quy tắc nghiệp vụ Admin vẫn xem được report rejected.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; user seed u2 (client) và u1 (admin) tồn tại trong DB.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Dùng token client u2 gọi POST /reports tạo report tại tọa độ ngẫu nhiên quanh TP.HCM. | JWT client u2; Payload report tại tọa độ point (lat ∈ [10.70, 10.90), lng ∈ [106.60, 106.80)) | HTTP 200; lấy được data.id (reportId). |
| 2 | Dùng token admin u1 gọi GET /admin/reports/map với khung inside (point ± 0.0005) và khung outside (+0.01..+0.02). | JWT admin u1; Query bounds inside và outside | Khung inside chứa reportId; khung outside không chứa reportId. |
| 3 | Dùng token admin u1 gọi PATCH /admin/reports/{reportId}/status để từ chối report. | Body: {"status": "rejected"} | HTTP 200. |
| 4 | Gọi lại GET /admin/reports/map với khung inside. | JWT admin u1; Query bounds inside | data.reports vẫn chứa reportId vừa bị rejected. |

10. **Input từng bước:**
   - Bước 1: JWT client u2; Payload report tại tọa độ point (lat ∈ [10.70, 10.90), lng ∈ [106.60, 106.80))
   - Bước 2: JWT admin u1; Query bounds inside và outside
   - Bước 3: Body: {"status": "rejected"}
   - Bước 4: JWT admin u1; Query bounds inside
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; lấy được data.id (reportId).
   - Bước 2: Khung inside chứa reportId; khung outside không chứa reportId.
   - Bước 3: HTTP 200.
   - Bước 4: data.reports vẫn chứa reportId vừa bị rejected.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/AdminMapReportsTest.java`
13. **Ghi chú:** Test tạo dữ liệu thật vào DB qua POST /reports và cập nhật trạng thái thành rejected.
