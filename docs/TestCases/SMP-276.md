# SMP-276: Từ chối đăng nhập loginGoogle khi tài khoản client đã tồn tại nhưng bị khóa

1. **Mã số test case:** SMP-276
2. **Tên test case:** Từ chối đăng nhập loginGoogle khi tài khoản client đã tồn tại nhưng bị khóa
3. **Project:** Spring Boot Backend
4. **Chức năng:** Xác thực & Bảo mật tài khoản (AuthenticationService)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra loginGoogle với Google ID token hợp lệ cho vai trò ERole.client nhưng tài khoản trong DB đang ở trạng thái EUserStatus.blocked sẽ ném BadRequestException("auth.account.blocked") và không gọi jwtService.generateAccessToken.
7. **Mục đích kiểm thử:** Xác minh cơ chế chặn đăng nhập Google đối với tài khoản client đã bị khóa.
8. **Điều kiện tiên quyết:** Dùng Mockito.spy(authenticationService) stub verifyGoogleIdToken("google-id-token") trả về GoogleIdToken.Payload(email="someone@example.com", name="Someone"). Mock userRepository.findByEmailAndRole("someone@example.com", ERole.client) trả về User(role=ERole.client, status=EUserStatus.blocked).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tạo spy AuthenticationService bỏ qua xác thực Google thật và mock User client bị khóa | verifyGoogleIdToken("google-id-token") -> Payload(email="someone@example.com"); User(role=client, status=blocked) | Spy và repository mock trả về payload Google và User bị khóa |
| 2 | Gọi service.loginGoogle(request) | GoogleLoginRequest(idToken="google-id-token", deviceId="device-1", role=ERole.client) | Ném BadRequestException với message "auth.account.blocked" |
| 3 | Kiểm tra jwtService không sinh access token | verify(jwtService, never()).generateAccessToken(any(), anyString()) | Không có lượt gọi generateAccessToken nào |

10. **Input từng bước:**
   - Bước 1: verifyGoogleIdToken("google-id-token") -> Payload(email="someone@example.com"); User(role=client, status=blocked)
   - Bước 2: GoogleLoginRequest(idToken="google-id-token", deviceId="device-1", role=ERole.client)
   - Bước 3: verify(jwtService, never()).generateAccessToken(any(), anyString())
11. **Kỳ vọng từng bước:**
   - Bước 1: Spy và repository mock trả về payload Google và User bị khóa
   - Bước 2: Ném BadRequestException với message "auth.account.blocked"
   - Bước 3: Không có lượt gọi generateAccessToken nào
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/auth/AuthenticationServiceSecurityTest.java`
13. **Ghi chú:** Thuộc nhóm @Nested BlockedAccount.
