# SMP-231: Kiểm tra khởi động Spring Boot Application Context

1. **Mã số test case:** SMP-231
2. **Tên test case:** Kiểm tra khởi động Spring Boot Application Context
3. **Project:** Spring Boot Backend
4. **Chức năng:** Khởi động ứng dụng Spring Boot
5. **Loại kiểm thử:** Spring Boot Context Test
6. **Mô tả test case:** Test mặc định @SpringBootTest với thân hàm contextLoads() rỗng để kiểm tra toàn bộ Spring Boot application context (bao gồm autowire ConversationRepository, ReportRepository, ReportDeadlineSyncInitializer) khởi động không lỗi.
7. **Mục đích kiểm thử:** Xác minh cấu hình Spring Boot, bean wiring và kết nối hạ tầng khởi động thành công.
8. **Điều kiện tiên quyết:** MySQL và Redis phải đang chạy đúng cấu hình trong application properties để Spring Boot context khởi tạo thành công.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Chạy phương thức test contextLoads() dưới annotation @SpringBootTest. | Không có input nghiệp vụ (thân hàm rỗng). | Spring Boot context khởi động và inject các bean thành công mà không ném exception. Lưu ý: thân hàm rỗng, không có bất kỳ assertion nghiệp vụ bổ sung nào. |

10. **Input từng bước:**
   - Bước 1: Không có input nghiệp vụ (thân hàm rỗng).
11. **Kỳ vọng từng bước:**
   - Bước 1: Spring Boot context khởi động và inject các bean thành công mà không ném exception. Lưu ý: thân hàm rỗng, không có bất kỳ assertion nghiệp vụ bổ sung nào.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/SmartSpaceApplicationTests.java`
13. **Ghi chú:** Thân hàm rỗng không có assertion tường minh; chỉ kiểm tra Spring Boot context khởi động thành công (yêu cầu MySQL + Redis chạy), chưa có assertion nghiệp vụ bổ sung.
