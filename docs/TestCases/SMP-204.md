# SMP-204: Luồng E2E tạo, phân công và Staff hoàn tất xử lý phản ánh

1. **Mã số test case:** SMP-204
2. **Tên test case:** Luồng E2E tạo, phân công và Staff hoàn tất xử lý phản ánh
3. **Project:** Spring Boot Backend
4. **Chức năng:** Xử lý phản ánh (Staff)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm thử quy trình đầu-cuối 3 bước: Client u2 tạo report vỡ ống nước -> Admin u1 phân công cho Staff u5 (severity high) -> Staff u5 hoàn tất xử lý kèm ghi chú và 2 ảnh minh chứng.
7. **Mục đích kiểm thử:** Đảm bảo quy trình xử lý phản ánh từ lúc tạo đến khi Staff hoàn tất chuyển trạng thái và lưu minh chứng chính xác.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; dữ liệu seed có u1 (admin), u2 (client), u5 (staff).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Client u2 gửi POST /reports tạo report "Sự cố vỡ ống nước sinh hoạt tòa B". | JWT client u2; JSON report tọa độ (10.8506, 106.7720) | HTTP 200; lấy được data.id khác null và không rỗng. |
| 2 | Admin u1 gửi POST /admin/reports/{reportId}/assign để giao cho Staff u5. | JWT admin u1; Body: {"staffId": "u5", "severity": "high"} | HTTP 200. |
| 3 | Staff u5 gửi POST /reports/{reportId}/complete kèm ghi chú xử lý và 2 URL ảnh. | JWT staff u5 (ROLE_staff); Body có note và 2 image_urls | HTTP 200; success=true; data.status="processed"; data.resolved_note khớp ghi chú gửi lên; data.resolved_image_urls là mảng có 2 phần tử. |

10. **Input từng bước:**
   - Bước 1: JWT client u2; JSON report tọa độ (10.8506, 106.7720)
   - Bước 2: JWT admin u1; Body: {"staffId": "u5", "severity": "high"}
   - Bước 3: JWT staff u5 (ROLE_staff); Body có note và 2 image_urls
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; lấy được data.id khác null và không rỗng.
   - Bước 2: HTTP 200.
   - Bước 3: HTTP 200; success=true; data.status="processed"; data.resolved_note khớp ghi chú gửi lên; data.resolved_image_urls là mảng có 2 phần tử.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/HandleReportTest.java`
13. **Ghi chú:** Tạo dữ liệu thật trong DB qua các API live.
