# SMP-203: Client gửi yêu cầu tạo phản ánh sự cố qua POST /reports

1. **Mã số test case:** SMP-203
2. **Tên test case:** Client gửi yêu cầu tạo phản ánh sự cố qua POST /reports
3. **Project:** Spring Boot Backend
4. **Chức năng:** Tạo phản ánh
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Mô phỏng Client u2 gọi HTTP POST /reports một lần duy nhất với payload đầy đủ thông tin sự cố cây xanh gãy đổ, tọa độ, địa chỉ và 2 ảnh minh họa.
7. **Mục đích kiểm thử:** Xác minh endpoint POST /reports hoạt động đúng khi nhận payload thực tế từ ứng dụng Client.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; user u2 (client) tồn tại trong DB.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tạo JWT Bearer Token HS512 cho user u2 (user@gmail.com, scope=client). | JWT claims: subject=user@gmail.com, userId=u2, scope=client | Chuỗi Bearer token hợp lệ. |
| 2 | Gửi request POST /reports kèm JSON phản ánh sự cố cây xanh gãy đổ. | Header Authorization + JSON gồm title, description, 2 image_urls, latitude=10.8506, longitude=106.7720, is_anonymous=false, address, location_description | HTTP 200; response body khác null, chứa "success":true và chứa trường "id": |

10. **Input từng bước:**
   - Bước 1: JWT claims: subject=user@gmail.com, userId=u2, scope=client
   - Bước 2: Header Authorization + JSON gồm title, description, 2 image_urls, latitude=10.8506, longitude=106.7720, is_anonymous=false, address, location_description
11. **Kỳ vọng từng bước:**
   - Bước 1: Chuỗi Bearer token hợp lệ.
   - Bước 2: HTTP 200; response body khác null, chứa "success":true và chứa trường "id":
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/CreateReportTest.java`
13. **Ghi chú:** Log nhắc WebSocket & Notification được kích hoạt trên server nhưng test không có assertion kiểm chứng realtime event; ghi 1 bản ghi report vào DB.
