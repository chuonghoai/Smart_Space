2. **Tên test case:** Màn hình quên mật khẩu Admin ẩn AuthBrandingPanel trên mobile khi chiều rộng < 850px
3. **Project:** Flutter Admin
4. **Chức năng:** Xác thực - Quên mật khẩu Admin (Responsive)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra AdminForgotPasswordScreen trên màn hình mobile 400x800 (< 850px) ẩn AuthBrandingPanel và giữ nguyên 4 ô TextField.
