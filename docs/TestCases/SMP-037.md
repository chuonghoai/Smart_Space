# SMP-037: Quy tắc chỉ phản ánh pending mới được phép chỉnh sửa

1. **Mã số test case:** SMP-037
2. **Tên test case:** Quy tắc chỉ phản ánh pending mới được phép chỉnh sửa
3. **Project:** Flutter Client
4. **Chức năng:** Chỉnh sửa & Hủy phản ánh (Report Edit & Cancel)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Khởi tạo 4 ReportModel với 4 trạng thái (pending, processing, processed, rejected) và kiểm tra điều kiện status == ReportStatus.pending chỉ trả về true cho pendingReport.
7. **Mục đích kiểm thử:** Ghi nhận và kiểm tra điều kiện nghiệp vụ chỉ cho phép chỉnh sửa phản ánh ở trạng thái đang chờ xử lý (pending).
8. **Điều kiện tiên quyết:** 4 đối tượng ReportModel cục bộ có trạng thái lần lượt là pending, processing, processed, rejected.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | So sánh thuộc tính status == ReportStatus.pending trên cả 4 model | pendingReport, processingReport, processedReport, rejectedReport | Chỉ pendingReport cho true; 3 trạng thái còn lại cho false |

10. **Input từng bước:**
   - Bước 1: pendingReport, processingReport, processedReport, rejectedReport
11. **Kỳ vọng từng bước:**
   - Bước 1: Chỉ pendingReport cho true; 3 trạng thái còn lại cho false
12. **File test tương ứng:** `smartspace_client/test/features/reports/report_edit_cancel_test.dart`
13. **Ghi chú:** Trong mã nguồn test hiện tại, assertion chỉ kiểm tra trực tiếp biểu thức `report.status == ReportStatus.pending` trên các instance ReportModel tạo sẵn chứ chưa gọi qua UI widget hay hàm validator riêng của màn hình sửa.
