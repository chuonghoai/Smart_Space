# SMP-112: Màn hình đăng nhập Admin hiển thị bố cục desktop chia đôi khi chiều rộng >= 850px

1. **Mã số test case:** SMP-112
2. **Tên test case:** Màn hình đăng nhập Admin hiển thị bố cục desktop chia đôi khi chiều rộng >= 850px
3. **Project:** Flutter Admin
4. **Chức năng:** Xác thực - Đăng nhập Admin (Responsive)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra AdminLoginScreen khi chiều rộng màn hình là 1200px (>= 850px) sẽ hiển thị bố cục chia đôi gồm AuthBrandingPanel, 2 ô TextField (Email và Mật khẩu) và 1 nút FilledButton.
7. **Mục đích kiểm thử:** Xác minh breakpoint desktop (>= 850px) của màn hình đăng nhập Admin hiển thị đầy đủ panel thương hiệu và form đăng nhập.
8. **Điều kiện tiên quyết:** Surface size đặt thành Size(1200, 800); MaterialApp dùng AppTheme.lightTheme, AppLocalizations, locale mặc định 'en'.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Đặt kích thước bề mặt 1200x800, render AdminLoginScreen bằng _buildTestApp và gọi pump(). | AdminLoginScreen(); Size(1200, 800); locale 'en'; AppTheme.lightTheme. | Tìm thấy 1 AuthBrandingPanel, 2 TextField và 1 FilledButton. |

10. **Input từng bước:**
   - Bước 1: AdminLoginScreen(); Size(1200, 800); locale 'en'; AppTheme.lightTheme.
11. **Kỳ vọng từng bước:**
   - Bước 1: Tìm thấy 1 AuthBrandingPanel, 2 TextField và 1 FilledButton.
12. **File test tương ứng:** `smartspace_admin/test/ui/screen/auth/auth_responsive_test.dart`
13. **Ghi chú:** Không có.
