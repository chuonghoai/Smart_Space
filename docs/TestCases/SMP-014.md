# SMP-014: Gọi lại API khi cache viewport quá hạn freshness

1. **Mã số test case:** SMP-014
2. **Tên test case:** Gọi lại API khi cache viewport quá hạn freshness
3. **Project:** Flutter Client
4. **Chức năng:** Bản đồ phản ánh (Map Reports Provider)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra sau khi tải viewport, nếu thời gian hiện tại vượt quá MapReportsNotifier.freshness + 1 giây thì gọi loadForViewport(insideViewport) vẫn gửi request API mới.
7. **Mục đích kiểm thử:** Đảm bảo dữ liệu bản đồ cũ quá thời gian freshness được làm mới từ server.
8. **Điều kiện tiên quyết:** Đã tải viewport; điều chỉnh biến now tiến thêm MapReportsNotifier.freshness + 1s.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tải viewport và hoàn tất với ['a'] | viewport, now = 2026-01-01 12:00 | Tạo request thứ 1 |
| 2 | Tăng now thêm freshness + 1s rồi gọi loadForViewport(insideViewport) | now += freshness + 1s, insideViewport | repo.requestedBounds tăng lên 2 |

10. **Input từng bước:**
   - Bước 1: viewport, now = 2026-01-01 12:00
   - Bước 2: now += freshness + 1s, insideViewport
11. **Kỳ vọng từng bước:**
   - Bước 1: Tạo request thứ 1
   - Bước 2: repo.requestedBounds tăng lên 2
12. **File test tương ứng:** `smartspace_client/test/features/reports/map_reports_provider_test.dart`
13. **Ghi chú:** Không có.
