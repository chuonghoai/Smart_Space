# SMP-182: Từ chối 400 khi tạo admin mới trùng email đã tồn tại

1. **Mã số test case:** SMP-182
2. **Tên test case:** Từ chối 400 khi tạo admin mới trùng email đã tồn tại
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản Hội đồng quản trị (POST /admin/admins)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gửi POST /admin/admins với email "admin@gmail.com" đã tồn tại trong CSDL bị từ chối với HTTP 400.
7. **Mục đích kiểm thử:** Đảm bảo hệ thống không cho phép tạo tài khoản admin mới trùng email với tài khoản hiện có.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); email admin@gmail.com đã tồn tại theo seed_data.sql; JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin u1 gửi POST /admin/admins với email admin@gmail.com | {"fullName":"Dup","email":"admin@gmail.com"} | HTTP 400 Bad Request. |

10. **Input từng bước:**
   - Bước 1: {"fullName":"Dup","email":"admin@gmail.com"}
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 400 Bad Request.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminAccountManagementTest.java`
13. **Ghi chú:** Không tạo bản ghi mới hay gửi email. Class này chưa đăng ký trong testapi.ps1.
