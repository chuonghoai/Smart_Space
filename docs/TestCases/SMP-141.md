# SMP-141: Parse JSON sang DelegationModel đầy đủ thuộc tính

1. **Mã số test case:** SMP-141
2. **Tên test case:** Parse JSON sang DelegationModel đầy đủ thuộc tính
3. **Project:** Flutter Staff
4. **Chức năng:** Nhờ đồng nghiệp làm giùm (Delegation)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra DelegationModel.fromJson chuyển đổi đúng JSON đầu vào sang model, bao gồm status 'ACCEPTED' -> DelegationStatus.accepted (isActive = true), severity 'low' -> ReportSeverity.low, thông tin requester/helper, các hàm kiểm tra vai trò isRequester/isHelper và parse trường expires_at.
7. **Mục đích kiểm thử:** Đảm bảo DelegationModel giải mã chính xác dữ liệu JSON từ backend và xác định đúng vai trò requester/helper cùng trạng thái hoạt động.
8. **Điều kiện tiên quyết:** Dữ liệu JSON mẫu tạo bởi _delegationJson('1', status: 'ACCEPTED') gồm requester id='u5', helper id='u6' (position_name='Kỹ thuật'), severity='low' và expires_at='2026-11-01T10:00:00'.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi DelegationModel.fromJson với JSON mẫu status 'ACCEPTED'. | _delegationJson('1', status: 'ACCEPTED') | Khởi tạo thành công DelegationModel với status = DelegationStatus.accepted và status.isActive = true. |
| 2 | Kiểm tra các thuộc tính severity, requester.fullName, helper.positionName, expiresAt và gọi isRequester('u5'), isHelper('u5'). | staffId = 'u5' | severity = ReportSeverity.low, requester.fullName = 'Requester', helper.positionName = 'Kỹ thuật', expiresAt khác null, isRequester('u5') = true, isHelper('u5') = false. |

10. **Input từng bước:**
   - Bước 1: _delegationJson('1', status: 'ACCEPTED')
   - Bước 2: staffId = 'u5'
11. **Kỳ vọng từng bước:**
   - Bước 1: Khởi tạo thành công DelegationModel với status = DelegationStatus.accepted và status.isActive = true.
   - Bước 2: severity = ReportSeverity.low, requester.fullName = 'Requester', helper.positionName = 'Kỹ thuật', expiresAt khác null, isRequester('u5') = true, isHelper('u5') = false.
12. **File test tương ứng:** `smartspace_staff/test/features/delegation/delegation_test.dart`
13. **Ghi chú:** Không có.
