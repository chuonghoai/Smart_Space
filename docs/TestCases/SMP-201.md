# SMP-201: Bản đồ Admin cắt danh sách theo limit và đặt truncated = true

1. **Mã số test case:** SMP-201
2. **Tên test case:** Bản đồ Admin cắt danh sách theo limit và đặt truncated = true
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Admin
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Tạo 2 report nằm trong cùng một khung nhìn nhỏ và gọi GET /admin/reports/map?limit=1 để kiểm tra kết quả bị cắt còn 1 phần tử với truncated = true.
7. **Mục đích kiểm thử:** Xác minh cơ chế phân giới hạn số lượng marker và báo hiệu bị cắt bớt dữ liệu trên bản đồ Admin.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; user seed u2 (client) và u1 (admin) tồn tại trong DB.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Dùng token client u2 gọi POST /reports tạo 2 report gần nhau tại point và (point[0]+0.0001, point[1]+0.0001). | JWT client u2; 2 payload POST /reports cách nhau 0.0001 độ | Cả 2 request tạo report trả về HTTP 200. |
| 2 | Dùng token admin u1 gọi GET /admin/reports/map?limit=1 kèm bounds (point ± 0.0005). | JWT admin u1; limit=1 và bounds chứa cả 2 report | HTTP 200; data.reports.size() == 1 và data.truncated == true. |

10. **Input từng bước:**
   - Bước 1: JWT client u2; 2 payload POST /reports cách nhau 0.0001 độ
   - Bước 2: JWT admin u1; limit=1 và bounds chứa cả 2 report
11. **Kỳ vọng từng bước:**
   - Bước 1: Cả 2 request tạo report trả về HTTP 200.
   - Bước 2: HTTP 200; data.reports.size() == 1 và data.truncated == true.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/AdminMapReportsTest.java`
13. **Ghi chú:** Test tạo 2 bản ghi report mới trong DB khi chạy.
