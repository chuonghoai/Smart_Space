1. **Mã số test case:** SMP-052
2. **Tên test case:** Hiển thị chú giải mật độ bản đồ MapDensityLegend
3. **Project:** Flutter Client
4. **Chức năng:** Giao diện bản đồ mật độ (Map Density UI)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra widget MapDensityLegend render đầy đủ trong MaterialApp locale 'vi': có widget MapDensityLegend, icon Icons.layers_rounded, tiêu đề 'Mật độ phản ánh' và 3 dòng mức độ ('1–2 phản ánh (Thấp)', '3–5 phản ánh (Trung bình)', 'Trên 5 phản ánh (Cao)').
