# SMP-340: Kiểm tra POST /auth/logout thiếu header Authorization trả về 401

1. **Mã số test case:** SMP-340
2. **Tên test case:** Kiểm tra POST /auth/logout thiếu header Authorization trả về 401
3. **Project:** Spring Boot Backend
4. **Chức năng:** Đăng xuất (AuthController)
5. **Loại kiểm thử:** API Automation Test (Playwright)
6. **Mô tả test case:** Gửi POST /auth/logout không đính kèm Bearer token (endpoint bỏ qua bearer filter mặc định của SecurityConfig và kiểm tra thủ công trong controller).
7. **Mục đích kiểm thử:** Xác minh AuthController.logout từ chối request thiếu Bearer token với mã 401.
8. **Điều kiện tiên quyết:** Backend đang chạy tại PW_BACKEND_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi POST /auth/logout không có header Authorization | POST /auth/logout | HTTP Status 401 Unauthorized |

10. **Input từng bước:**
   - Bước 1: POST /auth/logout
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP Status 401 Unauthorized
12. **File test tương ứng:** `playwright/backend/auth-api.spec.ts`
13. **Ghi chú:** Đối chiếu AuthController.java dòng 96-102.
