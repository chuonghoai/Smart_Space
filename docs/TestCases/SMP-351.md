# SMP-351: Boot Flutter Staff Web và hiển thị màn hình đăng nhập nhân viên

1. **Mã số test case:** SMP-351
2. **Tên test case:** Boot Flutter Staff Web và hiển thị màn hình đăng nhập nhân viên
3. **Project:** Flutter Staff
4. **Chức năng:** Khởi tạo & Đăng nhập Web (SplashScreen -> MobileLoginScreen)
5. **Loại kiểm thử:** Web UI Automation Test (Playwright)
6. **Mô tả test case:** Mở Flutter Staff Web, chờ redirect sang /#/login, bật semantics tree và kiểm tra không pageerror, tiêu đề SmartSpace Staff và nhãn 'Đăng nhập nhân viên'.
7. **Mục đích kiểm thử:** Xác minh bản build Flutter Web của smartspace_staff khởi chạy không lỗi trên trình duyệt và hiển thị giao diện đăng nhập.
8. **Điều kiện tiên quyết:** Static SPA server đang phục vụ build/web của smartspace_staff tại PW_STAFF_URL (mặc định http://localhost:9102).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Truy cập / và chờ redirect sang /#/login | url=/ | URL chứa /login; không có pageerror |
| 2 | Kích hoạt Flutter semantics và kiểm tra tiêu đề + nhãn đăng nhập | flt-semantics-placeholder | Title khớp SmartSpace Staff; semantics có 'Đăng nhập nhân viên' và nút 'Đăng nhập' |

10. **Input từng bước:**
   - Bước 1: url=/
   - Bước 2: flt-semantics-placeholder
11. **Kỳ vọng từng bước:**
   - Bước 1: URL chứa /login; không có pageerror
   - Bước 2: Title khớp SmartSpace Staff; semantics có 'Đăng nhập nhân viên' và nút 'Đăng nhập'
12. **File test tương ứng:** `playwright/staff/staff-web.spec.ts`
13. **Ghi chú:** smartspace_staff dùng hash routing mặc định (/#/login) vì main.dart không gọi usePathUrlStrategy().
