# SMP-338: Kiểm tra POST /auth/login với payload rỗng trả về HTTP 400

1. **Mã số test case:** SMP-338
2. **Tên test case:** Kiểm tra POST /auth/login với payload rỗng trả về HTTP 400
3. **Project:** Spring Boot Backend
4. **Chức năng:** Đăng nhập (AuthController)
5. **Loại kiểm thử:** API Automation Test (Playwright)
6. **Mô tả test case:** Gửi request POST /auth/login với body JSON rỗng {} để kiểm tra Jakarta Bean Validation từ chối đầu vào thiếu thông tin.
7. **Mục đích kiểm thử:** Xác minh validation đầu vào trên API đăng nhập hoạt động đúng.
8. **Điều kiện tiên quyết:** Backend đang chạy tại PW_BACKEND_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi POST /auth/login với body JSON {} | POST /auth/login, data={} | HTTP Status 400 Bad Request |

10. **Input từng bước:**
   - Bước 1: POST /auth/login, data={}
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP Status 400 Bad Request
12. **File test tương ứng:** `playwright/backend/auth-api.spec.ts`
13. **Ghi chú:** Không sử dụng dữ liệu người dùng thật.
