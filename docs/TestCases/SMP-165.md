# SMP-165: Parse URL valkeys:// giải mã mật khẩu URL-encoded, giữ dấu '+' thô và database index

1. **Mã số test case:** SMP-165
2. **Tên test case:** Parse URL valkeys:// giải mã mật khẩu URL-encoded, giữ dấu '+' thô và database index
3. **Project:** Spring Boot Backend
4. **Chức năng:** Cấu hình kết nối Redis (RedisConfig)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra RedisConfig.parseRedisUrl(String) xử lý giao thức valkeys:// có mật khẩu chứa ký tự mã hóa URL (%40, %2B) và dấu '+' thô, cùng path chỉ định chỉ số database (/3).
7. **Mục đích kiểm thử:** Đảm bảo bộ phân tích URL không chuyển nhầm dấu '+' thô thành khoảng trắng khi URL-decode mật khẩu và đọc đúng database index cho giao thức valkeys://.
8. **Điều kiện tiên quyết:** Không cần Redis server hoặc Spring context; gọi trực tiếp phương thức static RedisConfig.parseRedisUrl(...).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi RedisConfig.parseRedisUrl với URL valkeys:// có mật khẩu URL-encoded và path /3 | rawUrl = "valkeys://svc_user:p%40ss%2Bw0rd+raw@valkey.internal:26379/3" | Trả về ResolvedRedisSettings với tls() = true và database() = 3. |
| 2 | Kiểm tra thông tin xác thực và database trong standaloneConfiguration() | settings.standaloneConfiguration() | getUsername() = "svc_user", password giải mã thành "p@ss+w0rd+raw" (giữ nguyên dấu '+' thô), getDatabase() = 3. |

10. **Input từng bước:**
   - Bước 1: rawUrl = "valkeys://svc_user:p%40ss%2Bw0rd+raw@valkey.internal:26379/3"
   - Bước 2: settings.standaloneConfiguration()
11. **Kỳ vọng từng bước:**
   - Bước 1: Trả về ResolvedRedisSettings với tls() = true và database() = 3.
   - Bước 2: getUsername() = "svc_user", password giải mã thành "p@ss+w0rd+raw" (giữ nguyên dấu '+' thô), getDatabase() = 3.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/configuration/redis/RedisConfigTest.java`
13. **Ghi chú:** Không có.
