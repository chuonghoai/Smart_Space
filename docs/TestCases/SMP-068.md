# SMP-068: Không cho phép khóa admin đang hoạt động cuối cùng

1. **Mã số test case:** SMP-068
2. **Tên test case:** Không cho phép khóa admin đang hoạt động cuối cùng
3. **Project:** Flutter Admin
4. **Chức năng:** Quản lý tài khoản Admin (AdminAccountListState.canToggle)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra phương thức AdminAccountListState.canToggle trả về false khi định khóa một admin đang active nhưng trong hệ thống chỉ còn duy nhất 1 admin đang hoạt động (active = 1).
7. **Mục đích kiểm thử:** Xác minh quy tắc đảm bảo hệ thống luôn còn ít nhất một tài khoản quản trị viên hoạt động.
8. **Điều kiện tiên quyết:** Khởi tạo AdminAccountModel only (active=true, isCurrentUser=false) và AdminAccountListState gồm [only, _admin('b', active: false)] với active=1.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi state.canToggle(only). | only (active=true, isCurrentUser=false), state có summary.active=1. | Kết quả trả về false. |

10. **Input từng bước:**
   - Bước 1: only (active=true, isCurrentUser=false), state có summary.active=1.
11. **Kỳ vọng từng bước:**
   - Bước 1: Kết quả trả về false.
12. **File test tương ứng:** `smartspace_admin/test/features/admin_accounts/admin_account_models_test.dart`
13. **Ghi chú:** Không có.
