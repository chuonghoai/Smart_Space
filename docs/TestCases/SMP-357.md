# SMP-357: Validate form đăng nhập Client Web khi bỏ trống Email và Mật khẩu

1. **Mã số test case:** SMP-357
2. **Tên test case:** Validate form đăng nhập Client Web khi bỏ trống Email và Mật khẩu
3. **Project:** Flutter Client
4. **Chức năng:** Validation Đăng nhập Client (LoginController)
5. **Loại kiểm thử:** Web UI Automation Test (Playwright)
6. **Mô tả test case:** Trên màn hình đăng nhập Client Web, nhấn nút 'Đăng nhập' khi bỏ trống email và mật khẩu để kiểm tra hiển thị cảnh báo 'Vui lòng nhập email và mật khẩu'.
7. **Mục đích kiểm thử:** Xác minh kiểm tra đầu vào phía client trên smartspace_client hoạt động đúng.
8. **Điều kiện tiên quyết:** Flutter Client Web server đang chạy tại PW_CLIENT_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Boot Client Web tới /login | Không nhập email và password | Màn hình đăng nhập hiển thị |
| 2 | Nhấn nút 'Đăng nhập' | Click button 'Đăng nhập' (exact) | Semantics hiển thị 'Vui lòng nhập email và mật khẩu'; URL giữ nguyên /login |

10. **Input từng bước:**
   - Bước 1: Không nhập email và password
   - Bước 2: Click button 'Đăng nhập' (exact)
11. **Kỳ vọng từng bước:**
   - Bước 1: Màn hình đăng nhập hiển thị
   - Bước 2: Semantics hiển thị 'Vui lòng nhập email và mật khẩu'; URL giữ nguyên /login
12. **File test tương ứng:** `playwright/client/client-web.spec.ts`
13. **Ghi chú:** Sử dụng { name: 'Đăng nhập', exact: true } để phân biệt với nút 'Đăng nhập với Google'.
