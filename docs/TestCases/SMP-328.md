# SMP-328: Xử lý truncated: tải lại cho khung khác và chống lặp cho cùng khung

1. **Mã số test case:** SMP-328
2. **Tên test case:** Xử lý truncated: tải lại cho khung khác và chống lặp cho cùng khung
3. **Project:** Flutter Shared (mobile_shared)
4. **Chức năng:** Khung nhìn & Cluster bản đồ (MapViewport)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra khi gọi gate.succeed(request, truncated: true) cho viewport, gọi lại gate.begin(viewport) với đúng khung vừa yêu cầu trả về null (tránh vòng lặp idle), còn gọi gate.begin(inside) với khung khác trả về request khác null vì vùng rộng trước đó có thể chưa đủ dữ liệu.
7. **Mục đích kiểm thử:** Đảm bảo khi server cắt bớt số bản ghi trả về (truncated), zoom/kéo sang khung khác vẫn tải lại để lấy đủ điểm nhưng không lặp lại request trên chính khung vừa tải.
8. **Điều kiện tiên quyết:** gate đã gọi begin(viewport) và succeed(..., truncated: true).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi gate.succeed(gate.begin(viewport)!, truncated: true). | truncated: true | Lưu trạng thái dữ liệu bị cắt bớt. |
| 2 | Gọi gate.begin(viewport) và sau đó gọi gate.begin(inside). | viewport cũ và khung inside mới | begin(viewport) trả về null; begin(inside) trả về khác null. |

10. **Input từng bước:**
   - Bước 1: truncated: true
   - Bước 2: viewport cũ và khung inside mới
11. **Kỳ vọng từng bước:**
   - Bước 1: Lưu trạng thái dữ liệu bị cắt bớt.
   - Bước 2: begin(viewport) trả về null; begin(inside) trả về khác null.
12. **File test tương ứng:** `mobile_shared/test/features/map/map_viewport_test.dart`
13. **Ghi chú:** Không có.
