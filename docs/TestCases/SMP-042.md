# SMP-042: ReportFeedNotifier đổi mức độ tải lại trang 1 với severity

1. **Mã số test case:** SMP-042
2. **Tên test case:** ReportFeedNotifier đổi mức độ tải lại trang 1 với severity
3. **Project:** Flutter Client
4. **Chức năng:** Bộ lọc danh sách phản ánh (Report List Filters)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra sau khi tải trang đầu tiên (total=12), gọi notifier.setSeverity(EReportSeverity.high) gửi API với severity=high, page=1, bật state.isLoading=true và state.isFiltering=true.
7. **Mục đích kiểm thử:** Đảm bảo đổi bộ lọc mức độ trên Bảng tin luôn reset về trang 1 và cập nhật trạng thái đang tải/đang lọc.
8. **Điều kiện tiên quyết:** ReportFeedNotifier dùng _FakeReportRepo và getPosition trả về (10.77, 106.69).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Khởi tạo notifier và hoàn tất request đầu tiên với total=12 | _feedPage(total: 12) | Tải trang ban đầu hoàn tất |
| 2 | Gọi notifier.setSeverity(EReportSeverity.high) và flush | EReportSeverity.high | feedCalls.last.severity == high, page == 1, state.isLoading == true, state.isFiltering == true |

10. **Input từng bước:**
   - Bước 1: _feedPage(total: 12)
   - Bước 2: EReportSeverity.high
11. **Kỳ vọng từng bước:**
   - Bước 1: Tải trang ban đầu hoàn tất
   - Bước 2: feedCalls.last.severity == high, page == 1, state.isLoading == true, state.isFiltering == true
12. **File test tương ứng:** `smartspace_client/test/features/reports/report_list_filters_test.dart`
