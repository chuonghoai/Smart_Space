# SMP-164: Parse URL rediss:// gồm host, port, credentials và bật TLS

1. **Mã số test case:** SMP-164
2. **Tên test case:** Parse URL rediss:// gồm host, port, credentials và bật TLS
3. **Project:** Spring Boot Backend
4. **Chức năng:** Cấu hình kết nối Redis (RedisConfig)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra RedisConfig.parseRedisUrl(String) phân tích chính xác URL giao thức rediss:// có username, password, host và port tùy chỉnh, đồng thời bật TLS và đặt database mặc định là 0.
7. **Mục đích kiểm thử:** Đảm bảo RedisConfig phân tích đúng chuỗi kết nối TLS rediss:// cho môi trường production (như Aiven Valkey/Redis) và ánh xạ chính xác vào RedisStandaloneConfiguration.
8. **Điều kiện tiên quyết:** Không cần Redis server hoặc Spring context; gọi trực tiếp phương thức static RedisConfig.parseRedisUrl(...).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi RedisConfig.parseRedisUrl với URL rediss:// có username, password, host và port | rawUrl = "rediss://default:super-secret@valkey-prod.aivencloud.com:25061" | Trả về ResolvedRedisSettings với tls() = true, host() = "valkey-prod.aivencloud.com", port() = 25061, database() = 0. |
| 2 | Kiểm tra đối tượng standaloneConfiguration() được tạo từ ResolvedRedisSettings | settings.standaloneConfiguration() | getHostName() = "valkey-prod.aivencloud.com", getPort() = 25061, getUsername() = "default", password = "super-secret". |

10. **Input từng bước:**
   - Bước 1: rawUrl = "rediss://default:super-secret@valkey-prod.aivencloud.com:25061"
   - Bước 2: settings.standaloneConfiguration()
11. **Kỳ vọng từng bước:**
   - Bước 1: Trả về ResolvedRedisSettings với tls() = true, host() = "valkey-prod.aivencloud.com", port() = 25061, database() = 0.
   - Bước 2: getHostName() = "valkey-prod.aivencloud.com", getPort() = 25061, getUsername() = "default", password = "super-secret".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/configuration/redis/RedisConfigTest.java`
13. **Ghi chú:** Không có.
