# SMP-172: Validation lỗi 400/404 khi Admin tạo đề xuất khóa tài khoản không hợp lệ

1. **Mã số test case:** SMP-172
2. **Tên test case:** Validation lỗi 400/404 khi Admin tạo đề xuất khóa tài khoản không hợp lệ
3. **Project:** Spring Boot Backend
4. **Chức năng:** Biểu quyết khóa tài khoản (/admin/lock-requests)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gửi POST /admin/lock-requests bị từ chối với HTTP 400 khi lý do quá ngắn hoặc danh sách ảnh bằng chứng rỗng, và HTTP 404 khi đối tượng nhắm tới là tài khoản staff (u5).
7. **Mục đích kiểm thử:** Đảm bảo backend validate chặt chẽ lý do, bằng chứng đính kèm và chỉ cho phép lập đề xuất khóa đối với client hợp lệ.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); CSDL có seed_data.sql (u1=admin, u2=client, u5=staff); JWT HS512 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin gửi POST /admin/lock-requests với lý do quá ngắn ("ngắn") cho u2 | {"targetUserId":"u2","reason":"ngắn","evidenceImageUrls":["https://x/a.jpg"]} | HTTP 400 Bad Request. |
| 2 | Admin gửi POST /admin/lock-requests với mảng evidenceImageUrls rỗng cho u2 | {"targetUserId":"u2","reason":"Đăng nhiều phản ánh sai sự thật và spam liên tục.","evidenceImageUrls":[]} | HTTP 400 Bad Request. |
| 3 | Admin gửi POST /admin/lock-requests nhắm tới staff u5 với lý do và ảnh hợp lệ | {"targetUserId":"u5","reason":"Đăng nhiều phản ánh sai sự thật và spam liên tục.","evidenceImageUrls":["https://x/a.jpg"]} | HTTP 404 Not Found. |

10. **Input từng bước:**
   - Bước 1: {"targetUserId":"u2","reason":"ngắn","evidenceImageUrls":["https://x/a.jpg"]}
   - Bước 2: {"targetUserId":"u2","reason":"Đăng nhiều phản ánh sai sự thật và spam liên tục.","evidenceImageUrls":[]}
   - Bước 3: {"targetUserId":"u5","reason":"Đăng nhiều phản ánh sai sự thật và spam liên tục.","evidenceImageUrls":["https://x/a.jpg"]}
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 400 Bad Request.
   - Bước 2: HTTP 400 Bad Request.
   - Bước 3: HTTP 404 Not Found.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AccountLockRequestManagementTest.java`
13. **Ghi chú:** Chỉ kiểm tra các trường hợp bị từ chối trước khi lưu nên không tạo đề xuất thật trên DB. Chưa đăng ký trong testapi.ps1.
