# SMP-293: Render template mail/admin-credentials tiếng Việt với đầy đủ các phần

1. **Mã số test case:** SMP-293
2. **Tên test case:** Render template mail/admin-credentials tiếng Việt với đầy đủ các phần
3. **Project:** Spring Boot Backend
4. **Chức năng:** Template Email cấp tài khoản Admin (Thymeleaf Mail Templates)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra render template mail/admin-credentials với locale "vi", fullName="Trần Thị B", email="quantri@smartspace.vn", password="Ab3#xK9pQ2", adminPortalUrl="https://admin.smartspace.vn" và supportEmail="support@smartspace.vn": HTML hiển thị đủ lời chào, thông tin đăng nhập, nút "Mở SmartSpace Admin Portal", liên kết hỗ trợ, bản quyền, không thiếu key i18n và xuất preview.
7. **Mục đích kiểm thử:** Xác minh template email cấp tài khoản Admin hiển thị chính xác toàn bộ nội dung tiếng Việt và các phần tùy chọn khi được cấu hình.
8. **Điều kiện tiên quyết:** @BeforeAll khởi tạo SpringTemplateEngine với templates/mail/admin-credentials.html và ResourceBundleMessageSource (i18n/messages).
