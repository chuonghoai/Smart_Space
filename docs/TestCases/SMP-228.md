# SMP-228: Luồng chính nhờ làm giùm (Staff Delegation): gửi, nhận, người nhờ bị chặn hoàn tất, người làm giùm hoàn tất

1. **Mã số test case:** SMP-228
2. **Tên test case:** Luồng chính nhờ làm giùm (Staff Delegation): gửi, nhận, người nhờ bị chặn hoàn tất, người làm giùm hoàn tất
3. **Project:** Spring Boot Backend
4. **Chức năng:** Nhờ làm giùm giữa Staff (Staff Delegation)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm thử đầy đủ luồng chính: u5 tạo yêu cầu nhờ u6 -> chặn tạo trùng lần 2 (400) -> u6 accept (ACCEPTED) -> kiểm tra viewer_role -> chặn u5 tự complete (403) -> u6 complete thành công và delegation chuyển COMPLETED.
7. **Mục đích kiểm thử:** Xác minh toàn bộ vòng đời và chuyển giao quyền hoàn tất nhiệm vụ khi Staff nhờ đồng nghiệp làm giùm.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; dữ liệu seed có u1 (admin), u2 (client), u5 (requester), u6 (helper).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tạo report mới qua u2 và Admin u1 giao cho u5 (severity=low); kiểm tra can_request=true qua GET /staff/delegations/report/{id}. | JWT u2, u1, u5 | HTTP 200; can_request=true. |
| 2 | u5 gửi POST /staff/delegations nhờ u6, sau đó thử gửi trùng thêm 1 yêu cầu nữa. | JWT u5; {"report_id": reportId, "helper_id": "u6", "note": "Nhờ giúp"} | Lần 1 trả HTTP 200 (status=PENDING); lần 2 trả HTTP 400. |
| 3 | u6 gọi POST /staff/delegations/{delegationId}/accept, rồi kiểm tra trạng thái qua GET /staff/delegations/report/{reportId}. | JWT u6 accept; GET state bằng u5 và u6 | Accept trả HTTP 200 (status=ACCEPTED); active_delegation.status="ACCEPTED"; viewer_role của u5 là REQUESTER và của u6 là HELPER. |
| 4 | u5 gọi POST /reports/{reportId}/complete, sau đó u6 gọi POST /reports/{reportId}/complete. | JWT u5 và JWT u6 gọi /complete | u5 nhận HTTP 403; u6 nhận HTTP 200. |
| 5 | Kiểm tra GET /staff/delegations?box=sent của u5 và GET /staff/delegations/report/{reportId} của u6, u5. | JWT u5 và JWT u6 | Yêu cầu trong box=sent có status=COMPLETED; active_delegation là null/missing; completed_delegation.id == delegationId; viewer_role vẫn là HELPER (u6) và REQUESTER (u5). |

10. **Input từng bước:**
   - Bước 1: JWT u2, u1, u5
   - Bước 2: JWT u5; {"report_id": reportId, "helper_id": "u6", "note": "Nhờ giúp"}
   - Bước 3: JWT u6 accept; GET state bằng u5 và u6
   - Bước 4: JWT u5 và JWT u6 gọi /complete
   - Bước 5: JWT u5 và JWT u6
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; can_request=true.
   - Bước 2: Lần 1 trả HTTP 200 (status=PENDING); lần 2 trả HTTP 400.
   - Bước 3: Accept trả HTTP 200 (status=ACCEPTED); active_delegation.status="ACCEPTED"; viewer_role của u5 là REQUESTER và của u6 là HELPER.
   - Bước 4: u5 nhận HTTP 403; u6 nhận HTTP 200.
   - Bước 5: Yêu cầu trong box=sent có status=COMPLETED; active_delegation là null/missing; completed_delegation.id == delegationId; viewer_role vẫn là HELPER (u6) và REQUESTER (u5).
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/staff/StaffDelegationTest.java`
13. **Ghi chú:** Tạo dữ liệu report và delegation thật trong DB.
