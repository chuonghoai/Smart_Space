# SMP-043: ReportFeedNotifier bỏ qua response cũ về sau response mới

1. **Mã số test case:** SMP-043
2. **Tên test case:** ReportFeedNotifier bỏ qua response cũ về sau response mới
3. **Project:** Flutter Client
4. **Chức năng:** Bộ lọc danh sách phản ánh (Report List Filters)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra khi request bảng tin ban đầu (firstRequest) trả về total=99 sau khi request của setStatus(ReportStatus.processing) đã trả về total=5, state giữ totalElements=5 và statusFilter=processing.
7. **Mục đích kiểm thử:** Ngăn phản hồi chậm của truy vấn cũ ghi đè kết quả lọc trạng thái mới trên Bảng tin.
8. **Điều kiện tiên quyết:** ReportFeedNotifier dùng _FakeReportRepo giữ 2 Completer để đảo thứ tự hoàn tất.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Khởi tạo notifier và giữ firstRequest = repo.feedPending.last | firstRequest pending | Request ban đầu đang chờ |
| 2 | Gọi notifier.setStatus(ReportStatus.processing), hoàn tất request mới với total=5 rồi mới hoàn tất firstRequest với total=99 | processing response total=5; firstRequest total=99 | notifier.state.totalElements == 5 và statusFilter == ReportStatus.processing |

10. **Input từng bước:**
   - Bước 1: firstRequest pending
   - Bước 2: processing response total=5; firstRequest total=99
11. **Kỳ vọng từng bước:**
   - Bước 1: Request ban đầu đang chờ
   - Bước 2: notifier.state.totalElements == 5 và statusFilter == ReportStatus.processing
12. **File test tương ứng:** `smartspace_client/test/features/reports/report_list_filters_test.dart`
13. **Ghi chú:** Không có.
