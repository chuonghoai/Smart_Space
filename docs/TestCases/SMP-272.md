# SMP-272: Mở khóa admin thành công và không cần lock danh sách admin

1. **Mã số test case:** SMP-272
2. **Tên test case:** Mở khóa admin thành công và không cần lock danh sách admin
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản quản trị viên
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AdminAccountServiceImpl.updateAdminStatus(...) khi chuyển admin đang blocked sang active sẽ cập nhật trạng thái thành active, gọi authenticationService.restoreUserAccess và không gọi lockByRoleAndStatus.
7. **Mục đích kiểm thử:** Xác minh luồng mở khóa admin khôi phục phiên và bỏ qua khóa ghi danh sách admin vốn chỉ cần cho thao tác khóa.
8. **Điều kiện tiên quyết:** Stub findById("admin-other") trả về other đang blocked; stub findById("admin-me") trả về me active.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.updateAdminStatus("admin-other", new UpdateAdminStatusRequest("active"), "admin-me") | targetAdminId="admin-other", status="active", currentAdminId="admin-me" | other.status=EUserStatus.active, gọi authenticationService.restoreUserAccess("admin-other") và verify(userRepository, never()).lockByRoleAndStatus(any(), any()) |

10. **Input từng bước:**
   - Bước 1: targetAdminId="admin-other", status="active", currentAdminId="admin-me"
11. **Kỳ vọng từng bước:**
   - Bước 1: other.status=EUserStatus.active, gọi authenticationService.restoreUserAccess("admin-other") và verify(userRepository, never()).lockByRoleAndStatus(any(), any())
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/admin/AdminAccountServiceImplTest.java`
13. **Ghi chú:** Tên test method: Status.unblock_restoresAccess.
