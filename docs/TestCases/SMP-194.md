# SMP-194: Lọc thông báo chưa đọc (unread=true) chỉ trả về isRead=false và không vượt số badge

1. **Mã số test case:** SMP-194
2. **Tên test case:** Lọc thông báo chưa đọc (unread=true) chỉ trả về isRead=false và không vượt số badge
3. **Project:** Spring Boot Backend
4. **Chức năng:** Lọc danh sách thông báo (/notifications/my, /notifications/unread-count)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Client u2 gọi GET /notifications/my?page=0&size=50&unread=true chỉ nhận về các thông báo có isRead=false và tổng số phần tử totalElements không vượt quá giá trị notifNumber từ GET /notifications/unread-count.
7. **Mục đích kiểm thử:** Đảm bảo bộ lọc thông báo chưa đọc loại bỏ chính xác thông báo đã đọc và nhất quán với bộ đếm badge chưa đọc.
8. **Điều kiện tiên quyết:** Backend đang chạy cố định tại http://localhost:8989 (@BeforeAll fail nếu không kết nối được socket); CSDL có tài khoản client u2 (user@gmail.com); JWT client u2 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /notifications/my?page=0&size=50&unread=true với token client u2 | Token user@gmail.com (u2, ROLE_client), unread=true | HTTP 200; mọi phần tử trong data.content đều có isRead == false. |
| 2 | Gửi GET /notifications/unread-count và so sánh totalElements với data.notifNumber | Token client u2 | HTTP 200 và page.totalElements <= badge (notifNumber). |

10. **Input từng bước:**
   - Bước 1: Token user@gmail.com (u2, ROLE_client), unread=true
   - Bước 2: Token client u2
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; mọi phần tử trong data.content đều có isRead == false.
   - Bước 2: HTTP 200 và page.totalElements <= badge (notifNumber).
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/notification/NotificationFilterTest.java`
13. **Ghi chú:** Chỉ đọc dữ liệu, không gây side-effect. Class này chưa đăng ký trong testapi.ps1.
