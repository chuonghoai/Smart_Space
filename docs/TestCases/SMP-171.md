# SMP-171: Chặn 403 đối với Staff và Client ở các API biểu quyết khóa / mở khóa

1. **Mã số test case:** SMP-171
2. **Tên test case:** Chặn 403 đối với Staff và Client ở các API biểu quyết khóa / mở khóa
3. **Project:** Spring Boot Backend
4. **Chức năng:** Biểu quyết khóa và mở khóa tài khoản (/admin/lock-requests, /admin/users/{id}/unlock)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra phân quyền bảo vệ endpoint: Staff bị trả về 403 khi xem danh sách đề xuất khóa; Client bị trả về 403 khi tạo đề xuất khóa và khi gọi API mở khóa tài khoản.
7. **Mục đích kiểm thử:** Đảm bảo chỉ tài khoản có quyền admin mới được phép truy cập các endpoint biểu quyết khóa và mở khóa tài khoản người dùng.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); CSDL có seed_data.sql (u5 = staff1@gmail.com, u2 = user@gmail.com); JWT HS512 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /admin/lock-requests với token Staff (u5, ROLE_staff) | Token staff1@gmail.com (u5, ROLE_staff) | HTTP 403 Forbidden. |
| 2 | Gửi POST /admin/lock-requests với token Client (u2, ROLE_client) | Token user@gmail.com (u2, ROLE_client), body targetUserId="u2", reason hợp lệ, 1 URL ảnh | HTTP 403 Forbidden. |
| 3 | Gửi PUT /admin/users/u2/unlock với token Client (u2, ROLE_client) | Token user@gmail.com (u2, ROLE_client), body {"reason":"Đã xác minh lại"} | HTTP 403 Forbidden. |

10. **Input từng bước:**
   - Bước 1: Token staff1@gmail.com (u5, ROLE_staff)
   - Bước 2: Token user@gmail.com (u2, ROLE_client), body targetUserId="u2", reason hợp lệ, 1 URL ảnh
   - Bước 3: Token user@gmail.com (u2, ROLE_client), body {"reason":"Đã xác minh lại"}
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 403 Forbidden.
   - Bước 2: HTTP 403 Forbidden.
   - Bước 3: HTTP 403 Forbidden.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AccountLockRequestManagementTest.java`
13. **Ghi chú:** Không tạo side-effect. Class này chưa được đăng ký trong testapi.ps1.
