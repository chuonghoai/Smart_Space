# SMP-222: Contract JSON nhiệm vụ processing cho bản đồ Staff

1. **Mã số test case:** SMP-222
2. **Tên test case:** Contract JSON nhiệm vụ processing cho bản đồ Staff
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ nhiệm vụ Staff
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Staff u5 gọi GET /reports/staff/assigned?status=processing&limit=100 để kiểm tra data là mảng không vượt 100 phần tử, mọi phần tử đều ở trạng thái processing và có đủ các trường cần cho bản đồ Staff.
7. **Mục đích kiểm thử:** Xác minh contract JSON của API nhiệm vụ được giao đáp ứng đúng yêu cầu hiển thị marker trên bản đồ Staff.
8. **Điều kiện tiên quyết:** Backend đang chạy tại BASE_URL (mặc định http://localhost:8989); seed staff u5 tồn tại.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tạo JWT staff cho u5 (staff1@gmail.com, scope=ROLE_staff) và gửi GET /reports/staff/assigned?status=processing&limit=100. | JWT u5 (ROLE_staff); status=processing&limit=100 | HTTP 200; data là mảng JSON có size <= 100. |
| 2 | Kiểm tra từng phần tử trong mảng data. | Mỗi phần tử JSON trong data | status == "processing"; có đủ các trường id, title, latitude, longitude, severity, imageUrl và isReviewResolved. |

10. **Input từng bước:**
   - Bước 1: JWT u5 (ROLE_staff); status=processing&limit=100
   - Bước 2: Mỗi phần tử JSON trong data
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; data là mảng JSON có size <= 100.
   - Bước 2: status == "processing"; có đủ các trường id, title, latitude, longitude, severity, imageUrl và isReviewResolved.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/staff/StaffAssignedMapTest.java`
13. **Ghi chú:** Nếu staff u5 hiện không có nhiệm vụ processing nào trong DB, vòng lặp kiểm tra field từng item sẽ không chạy.
