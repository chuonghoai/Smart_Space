# SMP-296: Render template mail/staff-credentials tiếng Việt với đầy đủ các phần

1. **Mã số test case:** SMP-296
2. **Tên test case:** Render template mail/staff-credentials tiếng Việt với đầy đủ các phần
3. **Project:** Spring Boot Backend
4. **Chức năng:** Template Email cấp tài khoản Staff (Thymeleaf Mail Templates)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra render template mail/staff-credentials với locale "vi", fullName="Nguyễn Văn A", positionName="Kỹ thuật viên", staffAppUrl="https://smartspace.vn/staff-app" và supportEmail="support@smartspace.vn": HTML hiển thị đầy đủ thông tin tài khoản, chức vụ, hướng dẫn đổi mật khẩu tại Cài đặt, link app, hỗ trợ, bản quyền, không thiếu i18n và xuất preview.
7. **Mục đích kiểm thử:** Xác minh template email cấp tài khoản nhân viên hiển thị đầy đủ nội dung tiếng Việt và các khối tùy chọn khi đủ biến.
8. **Điều kiện tiên quyết:** @BeforeAll khởi tạo SpringTemplateEngine với templates/mail/staff-credentials.html và ResourceBundleMessageSource (i18n/messages).
9. **Các bước kiểm thử:**
