# SMP-002: Bỏ qua response bộ lọc thông báo cũ về sau

1. **Mã số test case:** SMP-002
2. **Tên test case:** Bỏ qua response bộ lọc thông báo cũ về sau
3. **Project:** Flutter Client
4. **Chức năng:** Thông báo (Notifications)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra cơ chế chống race condition trong NotificationNotifier: khi request tải tất cả ban đầu (allRequest) hoàn tất sau request của bộ lọc unreadOnly=true, response của bộ lọc cũ (['x', 'y']) bị bỏ qua.
7. **Mục đích kiểm thử:** Đảm bảo dữ liệu trả về chậm từ bộ lọc trước không ghi đè trạng thái của bộ lọc hiện tại.
8. **Điều kiện tiên quyết:** NotificationNotifier dùng _FakeNotificationRepo giữ danh sách Completer để điều khiển thứ tự hoàn tất bất đồng bộ.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi notifier.fetchNotifications() và giữ reference request đầu tiên allRequest | fetchNotifications() (pending allRequest) | Request tải tất cả đang ở trạng thái chờ |
| 2 | Gọi notifier.setUnreadOnly(true) và hoàn tất request mới trước với ['unread-1'] | setUnreadOnly(true); response mới=[_notif('unread-1')] | State cập nhật danh sách ['unread-1'] |
| 3 | Hoàn tất request cũ allRequest với ['x', 'y' (isRead=true)] | allRequest.complete([_notif('x'), _notif('y', isRead: true)]) | Response cũ bị bỏ qua; notifier.state.notifications vẫn là ['unread-1'] và unreadOnly == true |

10. **Input từng bước:**
   - Bước 1: fetchNotifications() (pending allRequest)
   - Bước 2: setUnreadOnly(true); response mới=[_notif('unread-1')]
   - Bước 3: allRequest.complete([_notif('x'), _notif('y', isRead: true)])
11. **Kỳ vọng từng bước:**
   - Bước 1: Request tải tất cả đang ở trạng thái chờ
   - Bước 2: State cập nhật danh sách ['unread-1']
   - Bước 3: Response cũ bị bỏ qua; notifier.state.notifications vẫn là ['unread-1'] và unreadOnly == true
12. **File test tương ứng:** `smartspace_client/test/features/notifications/notification_filter_test.dart`
13. **Ghi chú:** Không có.
