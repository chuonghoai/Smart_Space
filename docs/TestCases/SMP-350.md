# SMP-350: Luồng E2E đăng nhập Admin Web thành công vào trang chủ /home

1. **Mã số test case:** SMP-350
2. **Tên test case:** Luồng E2E đăng nhập Admin Web thành công vào trang chủ /home
3. **Project:** Flutter Admin
4. **Chức năng:** Đăng nhập E2E Admin Web
5. **Loại kiểm thử:** E2E Web Automation Test (Playwright)
6. **Mô tả test case:** Nhập email và mật khẩu Admin từ biến môi trường PW_ADMIN_EMAIL / PW_ADMIN_PASSWORD vào form đăng nhập trên trình duyệt, nhấn Đăng nhập và kiểm tra chuyển sang /home.
7. **Mục đích kiểm thử:** Xác minh tích hợp đầu-cuối từ giao diện Flutter Admin Web tới API /auth/login Backend và điều hướng trang chủ.
8. **Điều kiện tiên quyết:** Backend và Admin Web server đang chạy; có PW_ADMIN_EMAIL và PW_ADMIN_PASSWORD (nếu thiếu sẽ SKIPPED).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Boot Admin Web tới /login và điền email, password từ env | PW_ADMIN_EMAIL, PW_ADMIN_PASSWORD | Hai textbox nhận đủ dữ liệu |
| 2 | Nhấn nút 'Đăng nhập' và chờ chuyển trang | Click 'Đăng nhập' | URL chuyển sang /home |

10. **Input từng bước:**
   - Bước 1: PW_ADMIN_EMAIL, PW_ADMIN_PASSWORD
   - Bước 2: Click 'Đăng nhập'
11. **Kỳ vọng từng bước:**
   - Bước 1: Hai textbox nhận đủ dữ liệu
   - Bước 2: URL chuyển sang /home
12. **File test tương ứng:** `playwright/admin/admin-web.spec.ts`
13. **Ghi chú:** Không hardcode thông tin đăng nhập; tự SKIPPED khi thiếu biến môi trường.
