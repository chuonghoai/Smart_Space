# SMP-219: Client đánh giá phản ánh là Đã xử lý (Resolved) kèm 5 sao

1. **Mã số test case:** SMP-219
2. **Tên test case:** Client đánh giá phản ánh là Đã xử lý (Resolved) kèm 5 sao
3. **Project:** Spring Boot Backend
4. **Chức năng:** Đánh giá phản ánh
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Mô phỏng Client u2 tạo report -> Admin u1 gán Staff u5 -> Staff u5 hoàn tất -> Client u2 gửi POST /reports/{id}/review với is_resolved=true, rating=5 và nhận xét.
7. **Mục đích kiểm thử:** Xác minh Client có thể xác nhận phản ánh đã được xử lý và chấm điểm đánh giá nhân viên.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; các user seed u1 (admin), u2 (client), u5 (staff) tồn tại trong DB.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Client u2 tạo report "Bóng đèn hành lang tầng 5 bị cháy", Admin u1 giao cho Staff u5 (severity=low), Staff u5 gọi complete. | JWT u2, u1, u5 cho các bước POST /reports, /assign và /complete | Cả 3 bước trả HTTP 200; report chuyển trạng thái processed. |
| 2 | Client u2 gửi POST /reports/{reportId}/review với is_resolved=true, rating=5 và reason. | JWT u2; Body: {"is_resolved": true, "rating": 5, "reason": "Nhân viên hỗ trợ rất nhanh nhẹn..."} | HTTP 200; success=true; data.is_review_resolved=true; data.rating=5; data.review_note khớp reason; data.reviewed_at không rỗng. |

10. **Input từng bước:**
   - Bước 1: JWT u2, u1, u5 cho các bước POST /reports, /assign và /complete
   - Bước 2: JWT u2; Body: {"is_resolved": true, "rating": 5, "reason": "Nhân viên hỗ trợ rất nhanh nhẹn..."}
11. **Kỳ vọng từng bước:**
   - Bước 1: Cả 3 bước trả HTTP 200; report chuyển trạng thái processed.
   - Bước 2: HTTP 200; success=true; data.is_review_resolved=true; data.rating=5; data.review_note khớp reason; data.reviewed_at không rỗng.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/ReviewReportResolvedTest.java`
13. **Ghi chú:** Không có.
