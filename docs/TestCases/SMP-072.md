# SMP-072: Parse ReportDensityCell mức độ HIGH từ JSON

1. **Mã số test case:** SMP-072
2. **Tên test case:** Parse ReportDensityCell mức độ HIGH từ JSON
3. **Project:** Flutter Admin
4. **Chức năng:** Bản đồ mật độ phản ánh (ReportDensityCell)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra ReportDensityCell.fromJson parse chính xác một ô mật độ mức HIGH và chuyển đổi mã màu hex #EF4444 thành đối tượng Color.
7. **Mục đích kiểm thử:** Xác minh model ReportDensityCell nhận diện đúng DensityLevel.high và mã màu tương ứng.
8. **Điều kiện tiên quyết:** TestWidgetsFlutterBinding.ensureInitialized() đã gọi; setUp gán mock SharedPreferences.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi ReportDensityCell.fromJson với JSON mức HIGH. | {'cellId': 'cell_2', 'count': 10, 'level': 'HIGH', 'color': '#EF4444', 'latitude': 10.8, 'longitude': 106.6, 'coordinates': []} | cell.level là DensityLevel.high và cell.color là Color(0xFFEF4444). |

10. **Input từng bước:**
   - Bước 1: {'cellId': 'cell_2', 'count': 10, 'level': 'HIGH', 'color': '#EF4444', 'latitude': 10.8, 'longitude': 106.6, 'coordinates': []}
11. **Kỳ vọng từng bước:**
   - Bước 1: cell.level là DensityLevel.high và cell.color là Color(0xFFEF4444).
