# SMP-021: Đổi filter bản đồ bỏ cache và tải lại với filter mới

1. **Mã số test case:** SMP-021
2. **Tên test case:** Đổi filter bản đồ bỏ cache và tải lại với filter mới
3. **Project:** Flutter Client
4. **Chức năng:** Bản đồ phản ánh (Map Reports Provider)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra sau khi đã tải viewport với filter all, gọi notifier.setFilter(MapReportFilter.mine) cập nhật state.filter=mine, bỏ cache cũ và gọi ngay API cho khung gần nhất (viewport.expandBy(prefetchFactor)) với filter=mine.
7. **Mục đích kiểm thử:** Đảm bảo thay đổi bộ lọc trên bản đồ luôn tải dữ liệu khớp bộ lọc mới thay vì dùng lại cache của bộ lọc cũ.
8. **Điều kiện tiên quyết:** Đã tải xong viewport với filter mặc định MapReportFilter.all.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tải viewport với ['a'] | viewport, filter=all | Hoàn tất tải ban đầu |
| 2 | Gọi setFilter(MapReportFilter.mine) và hoàn tất request thứ 2 với ['mine-1'] | filter=MapReportFilter.mine, response=['mine-1'] | requestedFilters=[all, mine], bounds đúng prefetch viewport, state.reports=['mine-1'], state.filter=mine |

10. **Input từng bước:**
   - Bước 1: viewport, filter=all
   - Bước 2: filter=MapReportFilter.mine, response=['mine-1']
11. **Kỳ vọng từng bước:**
   - Bước 1: Hoàn tất tải ban đầu
   - Bước 2: requestedFilters=[all, mine], bounds đúng prefetch viewport, state.reports=['mine-1'], state.filter=mine
12. **File test tương ứng:** `smartspace_client/test/features/reports/map_reports_provider_test.dart`
13. **Ghi chú:** Không có.
