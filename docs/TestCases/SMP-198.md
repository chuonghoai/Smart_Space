# SMP-198: Bản đồ Admin không truyền bounds trả về toàn bản đồ theo limit

1. **Mã số test case:** SMP-198
2. **Tên test case:** Bản đồ Admin không truyền bounds trả về toàn bản đồ theo limit
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Admin
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra gọi GET /admin/reports/map?limit=5 bằng token Admin khi không truyền tham số bounds vẫn hợp lệ và trả về cấu trúc reports + truncated.
7. **Mục đích kiểm thử:** Xác minh Admin có thể truy vấn toàn bản đồ mà không bắt buộc bounds và giới hạn limit được áp dụng.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; SIGNER_KEY hợp lệ để tạo JWT admin (u1, ROLE_admin).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tạo JWT cho admin u1 (scope: ROLE_admin) và gửi GET /admin/reports/map?limit=5. | JWT admin (admin@gmail.com, userId=u1, scope=ROLE_admin); Query: limit=5 (không truyền minLat/maxLat/minLng/maxLng) | HTTP 200; data.reports là mảng JSON có kích thước <= 5; data có trường truncated. |

10. **Input từng bước:**
   - Bước 1: JWT admin (admin@gmail.com, userId=u1, scope=ROLE_admin); Query: limit=5 (không truyền minLat/maxLat/minLng/maxLng)
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; data.reports là mảng JSON có kích thước <= 5; data có trường truncated.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/AdminMapReportsTest.java`
13. **Ghi chú:** Không có.
