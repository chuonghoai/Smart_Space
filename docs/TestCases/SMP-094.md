# SMP-094: Render AdminSummaryBadges không lỗi ở Dark Mode

1. **Mã số test case:** SMP-094
2. **Tên test case:** Render AdminSummaryBadges không lỗi ở Dark Mode
3. **Project:** Flutter Admin
4. **Chức năng:** Hội đồng quản trị - Badge lọc trạng thái Admin (AdminSummaryBadges)
5. **Loại kiểm thử:** Widget Test

8. **Điều kiện tiên quyết:** Pump AdminSummaryBadges với theme = AppTheme.darkTheme và _FakeAdminAccountListNotifier.

| 1 | Pump AdminSummaryBadges với AppTheme.darkTheme và pumpAndSettle. | theme: AppTheme.darkTheme | Tìm thấy text 'Đã khoá' và tester.takeException() trả về null. |

10. **Input từng bước:**
   - Bước 1: theme: AppTheme.darkTheme
11. **Kỳ vọng từng bước:**
