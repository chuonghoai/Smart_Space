# SMP-167: Parse URL redis:// không chỉ định port dùng mặc định 6379

1. **Mã số test case:** SMP-167
2. **Tên test case:** Parse URL redis:// không chỉ định port dùng mặc định 6379
3. **Project:** Spring Boot Backend
4. **Chức năng:** Cấu hình kết nối Redis (RedisConfig)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra RedisConfig.parseRedisUrl(String) với URL redis:// không truyền cổng (redis://cache.local) sẽ tắt TLS và áp dụng cổng mặc định 6379.
7. **Mục đích kiểm thử:** Đảm bảo URL Redis hợp lệ không ghi rõ cổng vẫn fallback chính xác về cổng mặc định 6379.
8. **Điều kiện tiên quyết:** Không cần Redis server hoặc Spring context; gọi trực tiếp phương thức static RedisConfig.parseRedisUrl(...).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi RedisConfig.parseRedisUrl với URL thiếu port | rawUrl = "redis://cache.local" | tls() = false, host() = "cache.local", port() = 6379. |

10. **Input từng bước:**
   - Bước 1: rawUrl = "redis://cache.local"
11. **Kỳ vọng từng bước:**
   - Bước 1: tls() = false, host() = "cache.local", port() = 6379.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/configuration/redis/RedisConfigTest.java`
13. **Ghi chú:** Không có.
