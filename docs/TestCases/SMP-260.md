2. **Tên test case:** Lấy bộ đếm getPendingCount gồm cả số đã kết thúc và hạn gần nhất
3. **Project:** Spring Boot Backend
4. **Chức năng:** Điều kiện đề xuất khóa, bộ lọc và bộ đếm
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AccountLockRequestServiceImpl.getPendingCount("admin-b") tổng hợp chính xác số lượng đề xuất pending, số đề xuất chờ chính admin bỏ phiếu (awaitingMyVote), số đề xuất đã kết thúc (resolved) và mốc hạn gần nhất (nextDeadlineAt).
