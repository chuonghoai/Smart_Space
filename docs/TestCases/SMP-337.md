# SMP-337: Kiểm tra GET /auth/me không có Bearer token bị chặn 401

1. **Mã số test case:** SMP-337
2. **Tên test case:** Kiểm tra GET /auth/me không có Bearer token bị chặn 401
3. **Project:** Spring Boot Backend
4. **Chức năng:** Xác thực JWT (AuthController)
5. **Loại kiểm thử:** API Automation Test (Playwright)
6. **Mô tả test case:** Gửi request GET /auth/me không đính kèm header Authorization và kiểm tra SecurityFilterChain từ chối với HTTP 401.
7. **Mục đích kiểm thử:** Xác minh endpoint lấy thông tin cá nhân bắt buộc phải có JWT hợp lệ.
8. **Điều kiện tiên quyết:** Backend đang chạy tại PW_BACKEND_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /auth/me không có header Authorization | GET /auth/me | HTTP Status 401 Unauthorized |

10. **Input từng bước:**
   - Bước 1: GET /auth/me
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP Status 401 Unauthorized
12. **File test tương ứng:** `playwright/backend/auth-api.spec.ts`
13. **Ghi chú:** Không sử dụng dữ liệu production hay mock.
