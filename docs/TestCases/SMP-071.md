# SMP-071: Parse ReportDensityCell mức độ LOW từ JSON

1. **Mã số test case:** SMP-071
2. **Tên test case:** Parse ReportDensityCell mức độ LOW từ JSON
3. **Project:** Flutter Admin
4. **Chức năng:** Bản đồ mật độ phản ánh (ReportDensityCell)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra ReportDensityCell.fromJson parse chính xác một ô mật độ mức LOW kèm số lượng phản ánh, mã màu hex #22C55E và mảng tọa độ đa giác.
7. **Mục đích kiểm thử:** Xác minh model ReportDensityCell giải mã đúng cell mật độ thấp và màu hiển thị tương ứng.
8. **Điều kiện tiên quyết:** TestWidgetsFlutterBinding.ensureInitialized() đã gọi; setUp gán mock SharedPreferences.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi ReportDensityCell.fromJson với JSON mức LOW. | {'cellId': 'cell_1', 'count': 2, 'level': 'LOW', 'color': '#22C55E', 'latitude': 10.8, 'longitude': 106.6, 'coordinates': [[10.8, 106.6], [10.81, 106.61]]} | cellId='cell_1', count=2, level=DensityLevel.low, color=Color(0xFF22C55E), coordinates.length=2. |

10. **Input từng bước:**
   - Bước 1: {'cellId': 'cell_1', 'count': 2, 'level': 'LOW', 'color': '#22C55E', 'latitude': 10.8, 'longitude': 106.6, 'coordinates': [[10.8, 106.6], [10.81, 106.61]]}
11. **Kỳ vọng từng bước:**
   - Bước 1: cellId='cell_1', count=2, level=DensityLevel.low, color=Color(0xFF22C55E), coordinates.length=2.
