# SMP-229: Các luồng đóng yêu cầu nhờ làm giùm: từ chối, huỷ và Admin phân công lại

1. **Mã số test case:** SMP-229
2. **Tên test case:** Các luồng đóng yêu cầu nhờ làm giùm: từ chối, huỷ và Admin phân công lại
3. **Project:** Spring Boot Backend
4. **Chức năng:** Nhờ làm giùm giữa Staff (Staff Delegation)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra 3 kịch bản đóng yêu cầu nhờ làm giùm: helper u6 từ chối (DECLINED), helper bị chặn huỷ (403) còn requester u5 huỷ xong thì không accept được nữa (400), và Admin phân công lại khiến active_delegation đóng về null.
7. **Mục đích kiểm thử:** Đảm bảo các trạng thái kết thúc bất thường hoặc thay đổi phân công đều đóng đúng yêu cầu delegation đang mở.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; dữ liệu seed có u1 (admin), u2 (client), u5 (requester), u6 (helper).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tạo report #1 giao u5, u5 nhờ u6, sau đó u6 gọi POST /staff/delegations/{id1}/decline. | JWT u6; POST /staff/delegations/{id1}/decline | HTTP 200 và status == "DECLINED". |
| 2 | Tạo report #2 giao u5, u5 nhờ u6; u6 thử gọi cancel; u5 gọi cancel; u6 thử gọi accept lại. | POST /cancel bằng u6 rồi u5; sau đó POST /accept bằng u6 | u6 gọi cancel bị 403; u5 gọi cancel thành công 200; u6 gọi accept sau huỷ bị 400. |
| 3 | Tạo report #3 giao u5, u5 nhờ u6; Admin u1 gọi POST /admin/reports/{id}/assign giao lại trực tiếp cho u6 (severity=low). | JWT admin u1 assign lại cho u6; GET /staff/delegations/report/{id} bằng u5 | Admin assign trả HTTP 200; active_delegation trả về null. |

10. **Input từng bước:**
   - Bước 1: JWT u6; POST /staff/delegations/{id1}/decline
   - Bước 2: POST /cancel bằng u6 rồi u5; sau đó POST /accept bằng u6
   - Bước 3: JWT admin u1 assign lại cho u6; GET /staff/delegations/report/{id} bằng u5
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200 và status == "DECLINED".
   - Bước 2: u6 gọi cancel bị 403; u5 gọi cancel thành công 200; u6 gọi accept sau huỷ bị 400.
   - Bước 3: Admin assign trả HTTP 200; active_delegation trả về null.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/staff/StaffDelegationTest.java`
13. **Ghi chú:** Tạo 3 report mới và các delegation tương ứng trong DB.
