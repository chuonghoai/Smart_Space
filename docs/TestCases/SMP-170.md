# SMP-170: Admin lấy danh sách đề xuất khóa pending và số lượng chờ biểu quyết

1. **Mã số test case:** SMP-170
2. **Tên test case:** Admin lấy danh sách đề xuất khóa pending và số lượng chờ biểu quyết
3. **Project:** Spring Boot Backend
4. **Chức năng:** Biểu quyết khóa tài khoản (/admin/lock-requests)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gọi GET /admin/lock-requests?status=pending và GET /admin/lock-requests/pending-count nhận được mã HTTP 200 với cấu trúc dữ liệu chứa trường content và awaitingMyVote.
7. **Mục đích kiểm thử:** Xác minh API truy vấn danh sách đề xuất khóa đang chờ xử lý và đếm số đề xuất chờ admin hiện tại bỏ phiếu hoạt động đúng.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989, @BeforeAll fail nếu socket không mở); CSDL có seed_data.sql (u1 = admin@gmail.com); JWT HS512 ký bằng SIGNER_KEY khớp backend.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /admin/lock-requests?status=pending kèm Bearer token admin u1 | Header Authorization: Bearer <adminToken(u1, ROLE_admin)> | HTTP 200 và body phản hồi chứa "content". |
| 2 | Gửi GET /admin/lock-requests/pending-count kèm Bearer token admin u1 | Header Authorization: Bearer <adminToken(u1, ROLE_admin)> | HTTP 200 và body phản hồi chứa "awaitingMyVote". |

10. **Input từng bước:**
   - Bước 1: Header Authorization: Bearer <adminToken(u1, ROLE_admin)>
   - Bước 2: Header Authorization: Bearer <adminToken(u1, ROLE_admin)>
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200 và body phản hồi chứa "content".
   - Bước 2: HTTP 200 và body phản hồi chứa "awaitingMyVote".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AccountLockRequestManagementTest.java`
13. **Ghi chú:** Test chỉ đọc dữ liệu, không tạo side-effect. Class này chưa được đăng ký trong testapi.ps1.
