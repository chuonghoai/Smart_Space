# SMP-185: Tìm kiếm người dùng theo email trên GET /admin/users

1. **Mã số test case:** SMP-185
2. **Tên test case:** Tìm kiếm người dùng theo email trên GET /admin/users
3. **Project:** Spring Boot Backend
4. **Chức năng:** Admin quản lý người dùng (GET /admin/users)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gọi GET /admin/users?search=cudan@gmail trả về HTTP 200 chứa đúng tài khoản cudan@gmail.com và loại bỏ user@gmail.com.
7. **Mục đích kiểm thử:** Xác minh chức năng tìm kiếm theo từ khóa email lọc chính xác người dùng tương ứng.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); CSDL seed_data.sql có tài khoản client cudan@gmail.com và user@gmail.com; JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin u1 gửi GET /admin/users?search=cudan@gmail | Query search=cudan@gmail | HTTP 200; body chứa "cudan@gmail.com" và không chứa "user@gmail.com". |

10. **Input từng bước:**
   - Bước 1: Query search=cudan@gmail
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; body chứa "cudan@gmail.com" và không chứa "user@gmail.com".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminUserManagementTest.java`
13. **Ghi chú:** Class này đã đăng ký trong testapi.ps1 dưới lệnh AdminUsers.
