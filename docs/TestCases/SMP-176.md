# SMP-176: Giới hạn pageSize tối đa về 50 cho GET /admin/admins

1. **Mã số test case:** SMP-176
2. **Tên test case:** Giới hạn pageSize tối đa về 50 cho GET /admin/admins
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản Hội đồng quản trị (/admin/admins)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra khi Admin truyền tham số size=100000 tới GET /admin/admins?page=1&size=100000, server tự động kẹp giá trị pageSize trong phản hồi về 50.
7. **Mục đích kiểm thử:** Ngăn chặn truy vấn kích thước trang quá lớn làm quá tải bộ nhớ và CSDL.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /admin/admins?page=1&size=100000 kèm admin token u1 | Query page=1, size=100000 | HTTP 200 và body JSON chứa "pageSize":50. |

10. **Input từng bước:**
   - Bước 1: Query page=1, size=100000
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200 và body JSON chứa "pageSize":50.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminAccountManagementTest.java`
13. **Ghi chú:** Không gây side-effect. Class này chưa đăng ký trong testapi.ps1.
