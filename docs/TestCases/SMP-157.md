# SMP-157: Tạo URL chỉ đường Google Maps từ toạ độ report

1. **Mã số test case:** SMP-157
2. **Tên test case:** Tạo URL chỉ đường Google Maps từ toạ độ report
3. **Project:** Flutter Staff
4. **Chức năng:** Bản đồ nhân viên (Staff Map)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra hàm googleMapsDirectionsUri(10.8231, 106.6297) trả về Uri hợp lệ với scheme 'https', host 'www.google.com', path '/maps/dir/' và queryParameters {'api': '1', 'destination': '10.8231,106.6297'}.
7. **Mục đích kiểm thử:** Đảm bảo liên kết mở Google Maps dẫn đường tới vị trí sự cố tuân thủ chuẩn Maps URLs API.
8. **Điều kiện tiên quyết:** Tồn tại hàm googleMapsDirectionsUri(double lat, double lng).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi googleMapsDirectionsUri(10.8231, 106.6297) và kiểm tra scheme, host, path, queryParameters. | lat = 10.8231, lng = 106.6297 | scheme='https', host='www.google.com', path='/maps/dir/', queryParameters={'api': '1', 'destination': '10.8231,106.6297'}. |

10. **Input từng bước:**
   - Bước 1: lat = 10.8231, lng = 106.6297
11. **Kỳ vọng từng bước:**
   - Bước 1: scheme='https', host='www.google.com', path='/maps/dir/', queryParameters={'api': '1', 'destination': '10.8231,106.6297'}.

13. **Ghi chú:** Không có.
