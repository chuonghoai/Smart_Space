# SMP-264: Xử lý xung đột unique khi tạo admin đồng thời

1. **Mã số test case:** SMP-264
2. **Tên test case:** Xử lý xung đột unique khi tạo admin đồng thời
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản quản trị viên
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AdminAccountServiceImpl.createAdmin(...) bắt DataIntegrityViolationException tại bước saveAndFlush (tình huống race condition tạo đồng thời) và chuyển thành BadRequestException("auth.email.exists") trước khi gửi mail.
7. **Mục đích kiểm thử:** Đảm bảo thông báo lỗi nghiệp vụ thống nhất khi hai yêu cầu tạo admin cùng email chạy song song.
8. **Điều kiện tiên quyết:** Stub existsByEmailAndRole("new@example.com", ERole.admin)=false, passwordEncoder.encode="hashed", và userRepository.saveAndFlush(...) ném DataIntegrityViolationException("uk_email_role").
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.createAdmin(request, "admin-me") | CreateAdminRequest(" New Admin ", " new@example.com ", ""), currentAdminId="admin-me" | Ném BadRequestException với message "auth.email.exists" và verifyNoInteractions(mailService) |

10. **Input từng bước:**
   - Bước 1: CreateAdminRequest(" New Admin ", " new@example.com ", ""), currentAdminId="admin-me"
11. **Kỳ vọng từng bước:**
   - Bước 1: Ném BadRequestException với message "auth.email.exists" và verifyNoInteractions(mailService)
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/admin/AdminAccountServiceImplTest.java`
13. **Ghi chú:** Tên test method: Create.concurrentDuplicate_isRejected.
