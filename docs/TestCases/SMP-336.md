# SMP-336: Kiểm tra GET /v3/api-docs trả về HTTP 200 và OpenAPI JSON hợp lệ

1. **Mã số test case:** SMP-336
2. **Tên test case:** Kiểm tra GET /v3/api-docs trả về HTTP 200 và OpenAPI JSON hợp lệ
3. **Project:** Spring Boot Backend
4. **Chức năng:** Health Check & OpenAPI Documentation (/v3/api-docs)
5. **Loại kiểm thử:** API Automation Test (Playwright)
6. **Mô tả test case:** Gửi request GET /v3/api-docs tới Backend đang chạy để kiểm tra readiness endpoint và cấu trúc OpenAPI JSON trả về.
7. **Mục đích kiểm thử:** Xác minh Spring Boot Backend hoạt động ổn định và public endpoint /v3/api-docs phục vụ đúng OpenAPI schema.
8. **Điều kiện tiên quyết:** Spring Boot Backend đang chạy tại PW_BACKEND_URL (mặc định http://localhost:8989).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /v3/api-docs qua Playwright APIRequestContext | GET /v3/api-docs | HTTP Status 200 OK |
| 2 | Parse JSON phản hồi và kiểm tra các khóa bắt buộc | Response JSON | Có trường openapi và paths khác rỗng |

10. **Input từng bước:**
   - Bước 1: GET /v3/api-docs
   - Bước 2: Response JSON
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP Status 200 OK
   - Bước 2: Có trường openapi và paths khác rỗng
12. **File test tương ứng:** `playwright/backend/auth-api.spec.ts`
13. **Ghi chú:** Endpoint này cũng được dùng làm health check readiness trong playwright/helpers/service-manager.mjs.
