# SMP-162: Giữ dữ liệu bản đồ cũ khi refresh gặp lỗi

1. **Mã số test case:** SMP-162
2. **Tên test case:** Giữ dữ liệu bản đồ cũ khi refresh gặp lỗi
3. **Project:** Flutter Staff
4. **Chức năng:** Bản đồ nhân viên (Staff Map)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra sau khi StaffMapReportsNotifier tải thành công report 'a', nếu gọi refresh() thì trong lúc đang tải vẫn giữ valueOrNull cũ; và khi lần refresh nhận ApiResponse(success: false, message: 'boom'), state.hasError là true nhưng valueOrNull vẫn giữ nguyên report 'a'.
7. **Mục đích kiểm thử:** Đảm bảo thao tác làm mới bị lỗi không làm mất dữ liệu đang hiển thị trên bản đồ của nhân viên.
8. **Điều kiện tiên quyết:** ProviderContainer đã nạp thành công lần đầu với 1 report id='a'.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Hoàn tất lần tải đầu với [_report('a')] và chờ future xong. | [_report('a')] | Provider có dữ liệu report 'a'. |
| 2 | Gọi notifier.refresh() và kiểm tra state trước khi Completer thứ 2 hoàn tất. | refresh() đang pending | state.isLoading = true và state.valueOrNull?.reports.single.id = 'a'. |
| 3 | Hoàn tất Completer thứ 2 bằng ApiResponse(success: false, message: 'boom') và chờ refresh xong. | ApiResponse(success: false, message: 'boom') | state.hasError = true và state.valueOrNull?.reports.single.id vẫn là 'a'. |

10. **Input từng bước:**
   - Bước 1: [_report('a')]
   - Bước 2: refresh() đang pending
   - Bước 3: ApiResponse(success: false, message: 'boom')
11. **Kỳ vọng từng bước:**
   - Bước 1: Provider có dữ liệu report 'a'.
   - Bước 2: state.isLoading = true và state.valueOrNull?.reports.single.id = 'a'.
   - Bước 3: state.hasError = true và state.valueOrNull?.reports.single.id vẫn là 'a'.
12. **File test tương ứng:** `smartspace_staff/test/features/map/staff_map_test.dart`
13. **Ghi chú:** Sử dụng _FakeReportRepo.
