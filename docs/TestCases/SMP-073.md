# SMP-073: Parse ReportDensityResult gồm danh sách cell và GeoJSON

1. **Mã số test case:** SMP-073
2. **Tên test case:** Parse ReportDensityResult gồm danh sách cell và GeoJSON
3. **Project:** Flutter Admin
4. **Chức năng:** Bản đồ mật độ phản ánh (ReportDensityResult)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra ReportDensityResult.fromJson parse đầy đủ thông số độ phân giải H3, zoom, danh sách cells và chuyển đổi đối tượng geojson sang chuỗi JSON hợp lệ trong geojsonString.
7. **Mục đích kiểm thử:** Xác minh dữ liệu mật độ tổng hợp và GeoJSON được parse đúng để cấp cho lớp hiển thị bản đồ.
8. **Điều kiện tiên quyết:** TestWidgetsFlutterBinding.ensureInitialized() đã gọi; setUp gán mock SharedPreferences.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi ReportDensityResult.fromJson với JSON chứa 1 cell và đối tượng FeatureCollection. | {'resolution': 11, 'zoom': 14.5, 'totalCells': 1, 'truncated': false, 'cells': [{'cellId': 'c1', 'count': 1, 'level': 'LOW', 'color': '#22C55E', 'latitude': 10.0, 'longitude': 106.0, 'coordinates': []}], 'geojson': {'type': 'FeatureCollection', 'features': []}} | resolution=11, zoom=14.5, cells.length=1, geojsonString khác null và jsonDecode(geojsonString)['type'] bằng 'FeatureCollection'. |

10. **Input từng bước:**
   - Bước 1: {'resolution': 11, 'zoom': 14.5, 'totalCells': 1, 'truncated': false, 'cells': [{'cellId': 'c1', 'count': 1, 'level': 'LOW', 'color': '#22C55E', 'latitude': 10.0, 'longitude': 106.0, 'coordinates': []}], 'geojson': {'type': 'FeatureCollection', 'features': []}}
11. **Kỳ vọng từng bước:**
   - Bước 1: resolution=11, zoom=14.5, cells.length=1, geojsonString khác null và jsonDecode(geojsonString)['type'] bằng 'FeatureCollection'.
