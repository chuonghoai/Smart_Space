# SMP-169: Cấu hình LettuceClientConfiguration với SSL FULL, autoReconnect và keepAlive

1. **Mã số test case:** SMP-169
2. **Tên test case:** Cấu hình LettuceClientConfiguration với SSL FULL, autoReconnect và keepAlive
3. **Project:** Spring Boot Backend
4. **Chức năng:** Cấu hình kết nối Redis (RedisConfig)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra RedisConfig.buildClientConfiguration(boolean) thiết lập đúng bật/tắt SSL, chế độ xác thực chứng chỉ SslVerifyMode.FULL, autoReconnect và socket keepAlive.
7. **Mục đích kiểm thử:** Đảm bảo kết nối Lettuce tới Redis kích hoạt xác thực chứng chỉ TLS đầy đủ (FULL), tự động kết nối lại và giữ kết nối TCP khi bật TLS, đồng thời tắt SSL khi useTls=false.
8. **Điều kiện tiên quyết:** Không cần Redis server hoặc Spring context; gọi trực tiếp phương thức static RedisConfig.buildClientConfiguration(boolean).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi RedisConfig.buildClientConfiguration(true) và kiểm tra tùy chọn SSL cùng ClientOptions | useTls = true | isUseSsl() = true, getVerifyMode() = SslVerifyMode.FULL, clientOptions.isAutoReconnect() = true, socketOptions.isKeepAlive() = true. |
| 2 | Gọi RedisConfig.buildClientConfiguration(false) | useTls = false | isUseSsl() = false. |

10. **Input từng bước:**
   - Bước 1: useTls = true
   - Bước 2: useTls = false
11. **Kỳ vọng từng bước:**
   - Bước 1: isUseSsl() = true, getVerifyMode() = SslVerifyMode.FULL, clientOptions.isAutoReconnect() = true, socketOptions.isKeepAlive() = true.
   - Bước 2: isUseSsl() = false.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/configuration/redis/RedisConfigTest.java`
13. **Ghi chú:** Không có.
