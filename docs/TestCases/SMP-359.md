# SMP-359: Điều hướng từ Đăng nhập sang Quên mật khẩu trên Client Web

1. **Mã số test case:** SMP-359
2. **Tên test case:** Điều hướng từ Đăng nhập sang Quên mật khẩu trên Client Web
3. **Project:** Flutter Client
4. **Chức năng:** Điều hướng Quên mật khẩu (GoRouter Client)
5. **Loại kiểm thử:** Web UI Automation Test (Playwright)
6. **Mô tả test case:** Trên màn hình đăng nhập Client Web, nhấn nút 'Quên mật khẩu?' và kiểm tra mở màn hình MobileForgotPasswordScreen.
7. **Mục đích kiểm thử:** Xác minh liên kết điều hướng sang màn hình khôi phục mật khẩu trên Client Web.
8. **Điều kiện tiên quyết:** Flutter Client Web server đang chạy tại PW_CLIENT_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Boot Client Web tới /login | URL /login | Nút 'Quên mật khẩu?' hiển thị |
| 2 | Nhấn nút 'Quên mật khẩu?' | Click button 'Quên mật khẩu?' | Màn hình Quên mật khẩu hiển thị 'Nhập email của bạn để nhận mã OTP' và nút 'Đặt lại mật khẩu' |

10. **Input từng bước:**
   - Bước 1: URL /login
   - Bước 2: Click button 'Quên mật khẩu?'
11. **Kỳ vọng từng bước:**
   - Bước 1: Nút 'Quên mật khẩu?' hiển thị
   - Bước 2: Màn hình Quên mật khẩu hiển thị 'Nhập email của bạn để nhận mã OTP' và nút 'Đặt lại mật khẩu'
12. **File test tương ứng:** `playwright/client/client-web.spec.ts`
13. **Ghi chú:** MobileLoginScreen dùng context.push(RouterPath.forgotPassword) nên theo mặc định GoRouter trên Web URL thanh địa chỉ không đổi.
