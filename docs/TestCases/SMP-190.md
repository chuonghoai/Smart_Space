# SMP-190: Chi tiết người dùng u2 ẩn các phản ánh ẩn danh (r3, r15)

1. **Mã số test case:** SMP-190
2. **Tên test case:** Chi tiết người dùng u2 ẩn các phản ánh ẩn danh (r3, r15)
3. **Project:** Spring Boot Backend
4. **Chức năng:** Chi tiết người dùng Admin (GET /admin/users/{id})
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gọi GET /admin/users/u2 nhận HTTP 200 với trường reportStats và recentReports, đồng thời không làm lộ 2 phản ánh ẩn danh r3 và r15 của u2.
7. **Mục đích kiểm thử:** Bảo vệ danh tính người gửi phản ánh ẩn danh ngay cả trong màn hình chi tiết người dùng của Admin.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); theo seed_data.sql, client u2 có phản ánh ẩn danh id r3 và r15; JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin u1 gửi GET /admin/users/u2 | Path id = "u2", token admin u1 | HTTP 200; body chứa "reportStats" và "recentReports", không chứa "id":"r3" hay "id":"r15". |

10. **Input từng bước:**
   - Bước 1: Path id = "u2", token admin u1
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; body chứa "reportStats" và "recentReports", không chứa "id":"r3" hay "id":"r15".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminUserManagementTest.java`
13. **Ghi chú:** Phụ thuộc dữ liệu r3, r15 của u2 trong seed_data.sql. Đã đăng ký trong testapi.ps1 dưới lệnh AdminUsers.
