# SMP-263: Từ chối tạo admin khi email đã tồn tại với role admin

1. **Mã số test case:** SMP-263
2. **Tên test case:** Từ chối tạo admin khi email đã tồn tại với role admin
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản quản trị viên
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AdminAccountServiceImpl.createAdmin(...) chuẩn hóa email bằng trim, phát hiện trùng qua existsByEmailAndRole và ném BadRequestException mà không lưu DB hay gửi email.
7. **Mục đích kiểm thử:** Ngăn tạo trùng tài khoản quản trị viên theo email.
8. **Điều kiện tiên quyết:** CreateAdminRequest(" New Admin ", " new@example.com ", ""); stub userRepository.existsByEmailAndRole("new@example.com", ERole.admin) trả về true.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.createAdmin(request, "admin-me") | CreateAdminRequest(fullName=" New Admin ", email=" new@example.com ", phone=""), currentAdminId="admin-me" | Ném BadRequestException với message "auth.email.exists" |
| 2 | Xác minh không lưu DB và không gửi email | userRepository, mailService | verify(userRepository, never()).saveAndFlush(any()) và verifyNoInteractions(mailService) |

10. **Input từng bước:**
   - Bước 1: CreateAdminRequest(fullName=" New Admin ", email=" new@example.com ", phone=""), currentAdminId="admin-me"
   - Bước 2: userRepository, mailService
11. **Kỳ vọng từng bước:**
   - Bước 1: Ném BadRequestException với message "auth.email.exists"
   - Bước 2: verify(userRepository, never()).saveAndFlush(any()) và verifyNoInteractions(mailService)
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/admin/AdminAccountServiceImplTest.java`
13. **Ghi chú:** Tên test method: Create.duplicateEmail_isRejected.
