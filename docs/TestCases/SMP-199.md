# SMP-199: Bản đồ Admin từ chối tham số bounds thiếu hoặc không hợp lệ

1. **Mã số test case:** SMP-199
2. **Tên test case:** Bản đồ Admin từ chối tham số bounds thiếu hoặc không hợp lệ
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Admin
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra GET /admin/reports/map trả về HTTP 400 khi chỉ truyền một phần bounds, khi minLat > maxLat hoặc khi longitude vượt phạm vi [-180, 180].
7. **Mục đích kiểm thử:** Đảm bảo backend validate đầy đủ các tham số khung nhìn địa lý cho bản đồ Admin.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; JWT admin (u1, ROLE_admin) hợp lệ.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /admin/reports/map chỉ có minLat=10.7&maxLat=10.9 (thiếu minLng, maxLng). | JWT admin u1; Query: minLat=10.7&maxLat=10.9 | Server trả về HTTP 400. |
| 2 | Gửi GET /admin/reports/map với minLat > maxLat. | JWT admin u1; Query: minLat=10.900000&maxLat=10.700000&minLng=106.600000&maxLng=106.800000 | Server trả về HTTP 400. |
| 3 | Gửi GET /admin/reports/map với maxLng=190 (ngoài [-180, 180]). | JWT admin u1; Query: minLat=10.700000&maxLat=10.900000&minLng=106.600000&maxLng=190.000000 | Server trả về HTTP 400. |

10. **Input từng bước:**
   - Bước 1: JWT admin u1; Query: minLat=10.7&maxLat=10.9
   - Bước 2: JWT admin u1; Query: minLat=10.900000&maxLat=10.700000&minLng=106.600000&maxLng=106.800000
   - Bước 3: JWT admin u1; Query: minLat=10.700000&maxLat=10.900000&minLng=106.600000&maxLng=190.000000
11. **Kỳ vọng từng bước:**
   - Bước 1: Server trả về HTTP 400.
   - Bước 2: Server trả về HTTP 400.
   - Bước 3: Server trả về HTTP 400.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/AdminMapReportsTest.java`
13. **Ghi chú:** Không có.
