# SMP-212: Kiểm tra API cảnh báo phản ánh gần đây trong bán kính 200m

1. **Mã số test case:** SMP-212
2. **Tên test case:** Kiểm tra API cảnh báo phản ánh gần đây trong bán kính 200m
3. **Project:** Spring Boot Backend
4. **Chức năng:** Cảnh báo phản ánh lân cận
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Mô phỏng Client u2 gọi GET /reports/nearby-alerts tại tọa độ TP.HCM với bán kính 200m và kiểm tra cấu trúc JSON phản hồi.
7. **Mục đích kiểm thử:** Xác minh endpoint cảnh báo sự cố gần vị trí người dùng hoạt động và trả về đúng schema JSON cơ bản.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; cấu hình JWT secret khớp SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Tạo JWT client cho u2 (client.test@smartspace.vn, scope=client) và gửi GET /reports/nearby-alerts. | JWT u2; Query: lat=10.8505&lng=106.7719&radius=200.0 | HTTP 200; body khác null; chứa chuỗi "success":true, "count" và "reports". |

10. **Input từng bước:**
   - Bước 1: JWT u2; Query: lat=10.8505&lng=106.7719&radius=200.0
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; body khác null; chứa chuỗi "success":true, "count" và "reports".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/NearbyReportsAlertTest.java`
13. **Ghi chú:** Test không chủ động tạo report mẫu gần tọa độ trước khi gọi và không assert giá trị cụ thể của count hay danh sách reports bên trong; chỉ kiểm tra HTTP 200 và các khóa JSON chính.
