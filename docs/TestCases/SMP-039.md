# SMP-039: ReportService.updateReport và cancelReport với ReportRepoMock

1. **Mã số test case:** SMP-039
2. **Tên test case:** ReportService.updateReport và cancelReport với ReportRepoMock
3. **Project:** Flutter Client
4. **Chức năng:** Chỉnh sửa & Hủy phản ánh (Report Edit & Cancel)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra ReportService(reportRepo: ReportRepoMock()) khi gọi updateReport('rep-1', updateDto) trả về success=true, title='Updated Title', status=pending; sau đó gọi cancelReport('rep-1') trả về success=true và status=rejected.
7. **Mục đích kiểm thử:** Xác minh luồng cập nhật và hủy phản ánh qua ReportService hoạt động đúng trên repository mock.
8. **Điều kiện tiên quyết:** Khởi tạo ReportService với ReportRepoMock và ReportDto mới.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi await service.updateReport('rep-1', updateDto) | id='rep-1', title='Updated Title', description='Updated Description' | updateRes.success == true, data.title == 'Updated Title', data.status == ReportStatus.pending |
| 2 | Gọi await service.cancelReport('rep-1') | id='rep-1' | cancelRes.success == true và data.status == ReportStatus.rejected |

10. **Input từng bước:**
   - Bước 1: id='rep-1', title='Updated Title', description='Updated Description'
   - Bước 2: id='rep-1'
11. **Kỳ vọng từng bước:**
   - Bước 1: updateRes.success == true, data.title == 'Updated Title', data.status == ReportStatus.pending
   - Bước 2: cancelRes.success == true và data.status == ReportStatus.rejected
12. **File test tương ứng:** `smartspace_client/test/features/reports/report_edit_cancel_test.dart`
13. **Ghi chú:** Test sử dụng ReportRepoMock tích hợp sẵn trong codebase (không gọi backend thực tế).
