# SMP-009: ReportModel.fromJson khi thiếu trường severity

1. **Mã số test case:** SMP-009
2. **Tên test case:** ReportModel.fromJson khi thiếu trường severity
3. **Project:** Flutter Client
4. **Chức năng:** Bản đồ phản ánh (Map Models)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra ReportModel.fromJson khi trường severity là null trả về report.severity == null và report.isDangerous == false.
7. **Mục đích kiểm thử:** Đảm bảo báo cáo thiếu severity không bị đánh dấu nhầm là nguy hiểm.
8. **Điều kiện tiên quyết:** JSON ReportModel có 'severity': null.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi ReportModel.fromJson(json(null)) | {'id': 'r1', ..., 'severity': null} | report.severity == null và report.isDangerous == false |

10. **Input từng bước:**
   - Bước 1: {'id': 'r1', ..., 'severity': null}
11. **Kỳ vọng từng bước:**
   - Bước 1: report.severity == null và report.isDangerous == false
12. **File test tương ứng:** `smartspace_client/test/features/reports/map_models_test.dart`
13. **Ghi chú:** Không có.
