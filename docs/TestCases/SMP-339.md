# SMP-339: Kiểm tra POST /auth/login với tài khoản không tồn tại bị từ chối

1. **Mã số test case:** SMP-339
2. **Tên test case:** Kiểm tra POST /auth/login với tài khoản không tồn tại bị từ chối
3. **Project:** Spring Boot Backend
4. **Chức năng:** Đăng nhập (AuthController)
5. **Loại kiểm thử:** API Automation Test (Playwright)
6. **Mô tả test case:** Gửi POST /auth/login với email nonexistent-pw@smartspace.invalid, password bất kỳ và role client; kiểm tra Backend từ chối với 400/401 và success=false.
7. **Mục đích kiểm thử:** Xác minh Backend không cấp token và trả phản hồi thất bại cho tài khoản không tồn tại.
8. **Điều kiện tiên quyết:** Backend đang chạy tại PW_BACKEND_URL; email nonexistent-pw@smartspace.invalid không tồn tại trong DB.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi POST /auth/login với tài khoản không tồn tại | email=nonexistent-pw@smartspace.invalid, role=client | HTTP Status 400 hoặc 401; JSON body có success=false |

10. **Input từng bước:**
   - Bước 1: email=nonexistent-pw@smartspace.invalid, role=client
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP Status 400 hoặc 401; JSON body có success=false
12. **File test tương ứng:** `playwright/backend/auth-api.spec.ts`
13. **Ghi chú:** Sử dụng email giả định đuôi .invalid theo RFC 2606.
