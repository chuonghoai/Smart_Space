# SMP-125: ConnectionIndicator hiển thị icon wifi_off khi mất kết nối

1. **Mã số test case:** SMP-125
2. **Tên test case:** ConnectionIndicator hiển thị icon wifi_off khi mất kết nối
3. **Project:** Flutter Admin
4. **Chức năng:** Trạng thái kết nối (ConnectionIndicator)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra widget ConnectionIndicator khi connectionStateProvider ở trạng thái disconnected sẽ hiển thị icon Icons.wifi_off.
7. **Mục đích kiểm thử:** Xác minh chỉ báo kết nối chuyển sang biểu tượng mất kết nối khi connectionStateProvider bị ngắt.
8. **Điều kiện tiên quyết:** Gọi connectionStateProvider.setDisconnected(); render ConnectionIndicator() trong Scaffold qua _buildTestApp.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Thiết lập connectionStateProvider.setDisconnected(), render ConnectionIndicator() và gọi pump(). | connectionStateProvider ở trạng thái disconnected. | Tìm thấy 1 Icons.wifi_off (findsOneWidget). |

10. **Input từng bước:**
   - Bước 1: connectionStateProvider ở trạng thái disconnected.
11. **Kỳ vọng từng bước:**
   - Bước 1: Tìm thấy 1 Icons.wifi_off (findsOneWidget).
12. **File test tương ứng:** `smartspace_admin/test/ui/screen/home/home_responsive_test.dart`
