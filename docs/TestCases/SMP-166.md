# SMP-166: Parse URL redis://localhost:6379 tắt TLS

1. **Mã số test case:** SMP-166
2. **Tên test case:** Parse URL redis://localhost:6379 tắt TLS
3. **Project:** Spring Boot Backend
4. **Chức năng:** Cấu hình kết nối Redis (RedisConfig)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra RedisConfig.parseRedisUrl(String) với URL kết nối cục bộ redis://localhost:6379 tắt chế độ TLS và ánh xạ đúng host, port.
7. **Mục đích kiểm thử:** Đảm bảo môi trường local dùng redis:// không bị bật TLS nhầm và cấu hình đúng host, port.
8. **Điều kiện tiên quyết:** Không cần Redis server hoặc Spring context; gọi trực tiếp phương thức static RedisConfig.parseRedisUrl(...).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi RedisConfig.parseRedisUrl với URL redis://localhost:6379 | rawUrl = "redis://localhost:6379" | tls() = false, host() = "localhost", port() = 6379; standaloneConfiguration() có hostName = "localhost" và port = 6379. |

10. **Input từng bước:**
   - Bước 1: rawUrl = "redis://localhost:6379"
11. **Kỳ vọng từng bước:**
   - Bước 1: tls() = false, host() = "localhost", port() = 6379; standaloneConfiguration() có hostName = "localhost" và port = 6379.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/configuration/redis/RedisConfigTest.java`
13. **Ghi chú:** Không có.
