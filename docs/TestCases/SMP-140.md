# SMP-140: Template smoke test counter mặc định của Flutter với SmartSpaceAdminApp

1. **Mã số test case:** SMP-140
2. **Tên test case:** Template smoke test counter mặc định của Flutter với SmartSpaceAdminApp
3. **Project:** Flutter Admin
4. **Chức năng:** Smoke Test mặc định (Template Flutter)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Template smoke test mặc định do Flutter tạo sẵn, khởi chạy SmartSpaceAdminApp() rồi kiểm tra bộ đếm bắt đầu từ '0', nhấn nút Icons.add và tăng lên '1'.
7. **Mục đích kiểm thử:** Ghi nhận và chuẩn hóa file widget_test.dart mặc định hiện có trong repository theo đúng code thực tế (hiện không phù hợp với ứng dụng SmartSpaceAdminApp thật).
8. **Điều kiện tiên quyết:** Không có mock/ProviderScope; test gọi trực tiếp tester.pumpWidget(const SmartSpaceAdminApp()).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi tester.pumpWidget(const SmartSpaceAdminApp()). | Widget gốc const SmartSpaceAdminApp(). | Code test kỳ vọng tìm thấy text '0' (findsOneWidget) và không tìm thấy '1' (findsNothing). |
| 2 | Nhấn Icons.add bằng tester.tap(find.byIcon(Icons.add)) và gọi tester.pump(). | Thao tác tap vào Icons.add. | Code test kỳ vọng '0' biến mất (findsNothing) và '1' xuất hiện (findsOneWidget). |

10. **Input từng bước:**
   - Bước 1: Widget gốc const SmartSpaceAdminApp().
   - Bước 2: Thao tác tap vào Icons.add.
11. **Kỳ vọng từng bước:**
   - Bước 1: Code test kỳ vọng tìm thấy text '0' (findsOneWidget) và không tìm thấy '1' (findsNothing).
   - Bước 2: Code test kỳ vọng '0' biến mất (findsNothing) và '1' xuất hiện (findsOneWidget).
12. **File test tương ứng:** `smartspace_admin/test/widget_test.dart`
13. **Ghi chú:** Đây là template counter mặc định của Flutter, giữ nguyên code không sửa. Test kiểm tra màn hình counter mặc định '0'/'1' với nút Icons.add trên SmartSpaceAdminApp() và sẽ fail khi thực thi vì không khớp với ứng dụng thực tế (SmartSpaceAdminApp trong smartspace_admin/lib/main.dart dùng AppServicesInitializer và MaterialApp.router, không phải màn hình counter).
