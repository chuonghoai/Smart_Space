# SMP-312: Kiểm tra hằng số tỷ lệ phóng đại diện tích và bán kính đa giác lục giác

1. **Mã số test case:** SMP-312
2. **Tên test case:** Kiểm tra hằng số tỷ lệ phóng đại diện tích và bán kính đa giác lục giác
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ mật độ báo cáo H3 (ReportDensityServiceImpl)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra giá trị các hằng số tĩnh ReportDensityServiceImpl.HEXAGON_AREA_SCALE == 1.5 (sai số 0.0001) và HEXAGON_RADIUS_SCALE == Math.sqrt(1.5) (sai số 0.000001).
7. **Mục đích kiểm thử:** Xác minh cấu hình hệ số phóng đại đa giác lục giác (tăng diện tích 1.5 lần, tương ứng bán kính nhân căn bậc hai của 1.5).
8. **Điều kiện tiên quyết:** Truy cập trực tiếp hằng số public static final trên lớp ReportDensityServiceImpl.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | So sánh HEXAGON_AREA_SCALE và HEXAGON_RADIUS_SCALE với giá trị kỳ vọng | ReportDensityServiceImpl.HEXAGON_AREA_SCALE, HEXAGON_RADIUS_SCALE | HEXAGON_AREA_SCALE = 1.5 (±0.0001) và HEXAGON_RADIUS_SCALE = Math.sqrt(1.5) (±0.000001) |

10. **Input từng bước:**
   - Bước 1: ReportDensityServiceImpl.HEXAGON_AREA_SCALE, HEXAGON_RADIUS_SCALE
11. **Kỳ vọng từng bước:**
   - Bước 1: HEXAGON_AREA_SCALE = 1.5 (±0.0001) và HEXAGON_RADIUS_SCALE = Math.sqrt(1.5) (±0.000001)
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/report/ReportDensityServiceTest.java`
