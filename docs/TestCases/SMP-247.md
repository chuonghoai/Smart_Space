# SMP-247: Từ chối khi admin bỏ phiếu lần thứ hai

1. **Mã số test case:** SMP-247
2. **Tên test case:** Từ chối khi admin bỏ phiếu lần thứ hai
3. **Project:** Spring Boot Backend
4. **Chức năng:** Biểu quyết đề xuất khóa tài khoản
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AccountLockRequestServiceImpl.vote(...) từ chối khi voteRepository.existsByRequestIdAndVoterId trả về true và không lưu thêm phiếu mới.
7. **Mục đích kiểm thử:** Đảm bảo mỗi quản trị viên chỉ được bỏ phiếu tối đa một lần cho mỗi đề xuất khóa.
8. **Điều kiện tiên quyết:** Stub đề xuất pending còn hạn và voteRepository.existsByRequestIdAndVoterId("req-1", "admin-b") trả về true.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.vote(...) từ admin đã bỏ phiếu trước đó | requestId="req-1", AccountLockVoteRequest(decision="approve", comment=null), adminId="admin-b" | Ném BadRequestException với message "lock_request.already_voted" và verify(voteRepository, never()).save(any()) |

10. **Input từng bước:**
   - Bước 1: requestId="req-1", AccountLockVoteRequest(decision="approve", comment=null), adminId="admin-b"
11. **Kỳ vọng từng bước:**
   - Bước 1: Ném BadRequestException với message "lock_request.already_voted" và verify(voteRepository, never()).save(any())
