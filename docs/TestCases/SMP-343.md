# SMP-343: Kiểm tra các endpoint quản trị /admin/* không có token bị chặn 401

1. **Mã số test case:** SMP-343
2. **Tên test case:** Kiểm tra các endpoint quản trị /admin/* không có token bị chặn 401
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bảo mật Quản trị (AdminHomeController & PositionController)
5. **Loại kiểm thử:** API Automation Test (Playwright)
6. **Mô tả test case:** Gửi GET /admin/home/overview và GET /admin/positions không đính kèm JWT để xác minh cả hai đều bị chặn 401.
7. **Mục đích kiểm thử:** Xác minh các endpoint quản trị không bị lộ công khai khi thiếu xác thực.
8. **Điều kiện tiên quyết:** Backend đang chạy tại PW_BACKEND_URL.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi GET /admin/home/overview không kèm token | GET /admin/home/overview | HTTP 401 Unauthorized |
| 2 | Gửi GET /admin/positions không kèm token | GET /admin/positions | HTTP 401 Unauthorized |

10. **Input từng bước:**
   - Bước 1: GET /admin/home/overview
   - Bước 2: GET /admin/positions
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 401 Unauthorized
   - Bước 2: HTTP 401 Unauthorized
12. **File test tương ứng:** `playwright/backend/public-and-protected-api.spec.ts`
13. **Ghi chú:** Không có.
