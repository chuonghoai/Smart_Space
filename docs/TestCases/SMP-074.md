2. **Tên test case:** Ánh xạ mã khung thời gian ReportTimeframe.fromCode
3. **Project:** Flutter Admin
4. **Chức năng:** Bản đồ mật độ phản ánh (ReportTimeframe)
5. **Loại kiểm thử:** Unit Test
