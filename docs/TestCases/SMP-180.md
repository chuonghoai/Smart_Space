# SMP-180: Từ chối 400 khi cập nhật trạng thái admin với giá trị status không hợp lệ hoặc body rỗng

1. **Mã số test case:** SMP-180
2. **Tên test case:** Từ chối 400 khi cập nhật trạng thái admin với giá trị status không hợp lệ hoặc body rỗng
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản Hội đồng quản trị (/admin/admins/{id}/status)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gửi PUT /admin/admins/u5/status với status "deleted" hoặc JSON rỗng {} nhận được HTTP 400 Bad Request.
7. **Mục đích kiểm thử:** Đảm bảo DTO/validation từ chối giá trị trạng thái ngoài danh sách cho phép hoặc payload thiếu trường status.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin gửi PUT /admin/admins/u5/status với body {"status":"deleted"} | {"status":"deleted"} | HTTP 400 Bad Request. |
| 2 | Admin gửi PUT /admin/admins/u5/status với body rỗng {} | {} | HTTP 400 Bad Request. |

10. **Input từng bước:**
   - Bước 1: {"status":"deleted"}
   - Bước 2: {}
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 400 Bad Request.
   - Bước 2: HTTP 400 Bad Request.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminAccountManagementTest.java`
13. **Ghi chú:** Không gây side-effect. Class này chưa đăng ký trong testapi.ps1.
