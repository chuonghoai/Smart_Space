# SMP-356: Boot Flutter Client Web và hiển thị màn hình đăng nhập Client

1. **Mã số test case:** SMP-356
2. **Tên test case:** Boot Flutter Client Web và hiển thị màn hình đăng nhập Client
3. **Project:** Flutter Client
4. **Chức năng:** Khởi tạo & Đăng nhập Web (SplashScreen -> MobileLoginScreen)
5. **Loại kiểm thử:** Web UI Automation Test (Playwright)
6. **Mô tả test case:** Mở Flutter Client Web, chờ redirect sang /login, bật semantics tree và kiểm tra không pageerror, hiển thị 'Chào mừng trở lại', nút 'Đăng nhập' và nút 'Đăng ký'.
7. **Mục đích kiểm thử:** Xác minh bản build Flutter Web của smartspace_client khởi chạy ổn định trên Chromium và render đúng màn hình đăng nhập.
8. **Điều kiện tiên quyết:** Static SPA server đang phục vụ build/web của smartspace_client tại PW_CLIENT_URL (mặc định http://localhost:9103).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Mở / và đợi redirect sang /login | url=/ | URL chứa /login; không có pageerror |
| 2 | Kích hoạt semantics và kiểm tra các thành phần màn hình đăng nhập | flt-semantics-placeholder | Title chứa SmartSpace; semantics có 'Chào mừng trở lại', nút 'Đăng nhập' và 'Đăng ký' |

10. **Input từng bước:**
   - Bước 1: url=/
   - Bước 2: flt-semantics-placeholder
11. **Kỳ vọng từng bước:**
   - Bước 1: URL chứa /login; không có pageerror
   - Bước 2: Title chứa SmartSpace; semantics có 'Chào mừng trở lại', nút 'Đăng nhập' và 'Đăng ký'
12. **File test tương ứng:** `playwright/client/client-web.spec.ts`
13. **Ghi chú:** smartspace_client sử dụng usePathUrlStrategy() nên static server phải có SPA fallback.
