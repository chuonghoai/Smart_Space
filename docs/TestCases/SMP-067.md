# SMP-067: Không cho phép admin tự khóa chính mình qua canToggle

1. **Mã số test case:** SMP-067
2. **Tên test case:** Không cho phép admin tự khóa chính mình qua canToggle
3. **Project:** Flutter Admin
4. **Chức năng:** Quản lý tài khoản Admin (AdminAccountListState.canToggle)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra phương thức AdminAccountListState.canToggle trả về false khi tài khoản mục tiêu có isCurrentUser = true, ngăn quản trị viên tự khóa tài khoản của chính mình ngay cả khi vẫn còn admin khác đang hoạt động.
7. **Mục đích kiểm thử:** Xác minh quy tắc bảo vệ không cho phép tự khóa tài khoản đang đăng nhập.
8. **Điều kiện tiên quyết:** Khởi tạo AdminAccountModel me (active=true, me=true) và AdminAccountListState có 2 admin hoạt động ([me, _admin('x')], active: 2).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi state.canToggle(me). | me (isCurrentUser=true, status='active'), state có summary.active=2. | Kết quả trả về false. |

10. **Input từng bước:**
   - Bước 1: me (isCurrentUser=true, status='active'), state có summary.active=2.
11. **Kỳ vọng từng bước:**
   - Bước 1: Kết quả trả về false.
12. **File test tương ứng:** `smartspace_admin/test/features/admin_accounts/admin_account_models_test.dart`
13. **Ghi chú:** Không có.
