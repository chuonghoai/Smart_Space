# SMP-324: MapBounds.toQueryParameters xuất đúng key snake_case

1. **Mã số test case:** SMP-324
2. **Tên test case:** MapBounds.toQueryParameters xuất đúng key snake_case
3. **Project:** Flutter Shared (mobile_shared)
4. **Chức năng:** Khung nhìn & Cluster bản đồ (MapViewport)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra bounds.toQueryParameters() trên bounds(10..11, 106..107) trả về Map gồm 4 key snake_case: 'min_lat', 'max_lat', 'min_lng', 'max_lng' với giá trị double tương ứng.

8. **Điều kiện tiên quyết:** Khởi tạo bounds = MapBounds(minLat: 10, maxLat: 11, minLng: 106, maxLng: 107).

| 1 | Gọi bounds.toQueryParameters(). | bounds(10..11, 106..107) | Trả về {'min_lat': 10.0, 'max_lat': 11.0, 'min_lng': 106.0, 'max_lng': 107.0}. |
