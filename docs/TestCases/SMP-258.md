# SMP-258: Kiểm tra proposalBlockedReason theo số lượng admin đang hoạt động

1. **Mã số test case:** SMP-258
2. **Tên test case:** Kiểm tra proposalBlockedReason theo số lượng admin đang hoạt động
3. **Project:** Spring Boot Backend
4. **Chức năng:** Điều kiện đề xuất khóa, bộ lọc và bộ đếm
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AccountLockRequestServiceImpl.proposalBlockedReason(User) trả về "not_enough_admins" khi tổng số admin active là 2 và trả về null (cho phép đề xuất) khi tổng số admin active là 3.
7. **Mục đích kiểm thử:** Xác minh ngưỡng tối thiểu 3 admin active (người xem + ít nhất 2 admin khác) để được phép tạo đề xuất khóa.
8. **Điều kiện tiên quyết:** Target là client active; requestRepository.existsByTargetIdAndStatus mặc định false; stub userRepository.countByRoleAndStatus(ERole.admin, EUserStatus.active) trả về lần lượt 2L rồi 3L.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.proposalBlockedReason(target) lần 1 khi số admin active bằng 2 | target=active client, countByRoleAndStatus=2L | Trả về "not_enough_admins" |
| 2 | Gọi service.proposalBlockedReason(target) lần 2 khi số admin active bằng 3 | target=active client, countByRoleAndStatus=3L | Trả về null |

10. **Input từng bước:**
   - Bước 1: target=active client, countByRoleAndStatus=2L
   - Bước 2: target=active client, countByRoleAndStatus=3L
11. **Kỳ vọng từng bước:**
   - Bước 1: Trả về "not_enough_admins"
   - Bước 2: Trả về null
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/admin/AccountLockRequestServiceImplTest.java`
13. **Ghi chú:** Tên test method: Eligibility.blockedReasons_adminCount.
