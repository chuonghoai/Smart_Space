# SMP-280: Xác minh revokeUserAccess xóa mọi phiên và đặt cờ chặn lâu hơn TTL access token

1. **Mã số test case:** SMP-280
2. **Tên test case:** Xác minh revokeUserAccess xóa mọi phiên và đặt cờ chặn lâu hơn TTL access token
3. **Project:** Spring Boot Backend
4. **Chức năng:** Xác thực & Bảo mật tài khoản (AuthenticationService)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra revokeUserAccess("user-1") xóa tất cả RefreshTokenSession tìm được theo userId và lưu khóa Redis "blocked_user:user-1" với giá trị "1" và thời hạn Duration.ofMinutes(JwtService.ACCESS_TOKEN_TTL_MINUTES + 1).
7. **Mục đích kiểm thử:** Đảm bảo thao tác thu hồi quyền truy cập vừa xóa refresh token session vừa duy trì cờ chặn lâu hơn thời gian sống của access token.
8. **Điều kiện tiên quyết:** Mock sessionRepository.findByUserId("user-1") trả về List.of(RefreshTokenSession(id="user-1:d")) và stringRedisTemplate.opsForValue() trả về mock ValueOperations.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi authenticationService.revokeUserAccess("user-1") | userId = "user-1"; sessions = [RefreshTokenSession(id="user-1:d")] | Phương thức thực thi không lỗi |
| 2 | Kiểm tra thao tác xóa phiên và ghi cờ Redis | verify(sessionRepository).deleteAll(sessions); verify(valueOperations).set("blocked_user:user-1", "1", Duration.ofMinutes(JwtService.ACCESS_TOKEN_TTL_MINUTES + 1)) | sessionRepository.deleteAll xóa toàn bộ sessions và Redis ghi "blocked_user:user-1" = "1" với TTL = 31 phút (ACCESS_TOKEN_TTL_MINUTES=30 + 1) |

10. **Input từng bước:**
   - Bước 1: userId = "user-1"; sessions = [RefreshTokenSession(id="user-1:d")]
   - Bước 2: verify(sessionRepository).deleteAll(sessions); verify(valueOperations).set("blocked_user:user-1", "1", Duration.ofMinutes(JwtService.ACCESS_TOKEN_TTL_MINUTES + 1))
11. **Kỳ vọng từng bước:**
   - Bước 1: Phương thức thực thi không lỗi
   - Bước 2: sessionRepository.deleteAll xóa toàn bộ sessions và Redis ghi "blocked_user:user-1" = "1" với TTL = 31 phút (ACCESS_TOKEN_TTL_MINUTES=30 + 1)
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/auth/AuthenticationServiceSecurityTest.java`
13. **Ghi chú:** Thuộc nhóm @Nested BlockedAccount. Giá trị JwtService.ACCESS_TOKEN_TTL_MINUTES được xác nhận trong JwtService.java là 30 phút.
