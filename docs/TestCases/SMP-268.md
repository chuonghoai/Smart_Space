# SMP-268: Từ chối cập nhật trạng thái admin khi giá trị status không hợp lệ

1. **Mã số test case:** SMP-268
2. **Tên test case:** Từ chối cập nhật trạng thái admin khi giá trị status không hợp lệ
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản quản trị viên
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AdminAccountServiceImpl.updateAdminStatus(...) ném BadRequestException khi chuỗi status truyền vào không thuộc enum EUserStatus.

8. **Điều kiện tiên quyết:** Mock dependency bằng Mockito.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.updateAdminStatus(...) với status="deleted" | targetAdminId="admin-other", UpdateAdminStatusRequest("deleted"), currentAdminId="admin-me" | Ném BadRequestException với message "admin.account.status_invalid" |

10. **Input từng bước:**
   - Bước 1: targetAdminId="admin-other", UpdateAdminStatusRequest("deleted"), currentAdminId="admin-me"
11. **Kỳ vọng từng bước:**
