1. **Mã số test case:** SMP-115
2. **Tên test case:** Màn hình quên mật khẩu Admin hiển thị bố cục desktop khi chiều rộng >= 850px
3. **Project:** Flutter Admin
4. **Chức năng:** Xác thực - Quên mật khẩu Admin (Responsive)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra AdminForgotPasswordScreen trên màn hình desktop 1200x800 (>= 850px) hiển thị AuthBrandingPanel và đủ 4 ô TextField (Email, OTP, Mật khẩu mới, Xác nhận mật khẩu).

8. **Điều kiện tiên quyết:** Surface size đặt thành Size(1200, 800); MaterialApp dùng AppTheme.lightTheme, locale mặc định 'en'.
