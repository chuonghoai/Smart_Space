# SMP-197: Kiểm tra phân quyền API bản đồ Admin (401/403)

1. **Mã số test case:** SMP-197
2. **Tên test case:** Kiểm tra phân quyền API bản đồ Admin (401/403)
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bản đồ phản ánh Admin
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra endpoint GET /admin/reports/map từ chối truy cập khi thiếu Bearer token (HTTP 401) và khi người gọi dùng token role client (HTTP 403).
7. **Mục đích kiểm thử:** Đảm bảo API bản đồ dành riêng cho Admin được bảo vệ xác thực và phân quyền đúng vai trò.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; cấu hình JWT secret khớp SIGNER_KEY trong test.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gửi request GET /admin/reports/map không kèm header Authorization. | Token: null; Path: /admin/reports/map | Server trả về mã trạng thái HTTP 401. |
| 2 | Tạo JWT HS512 cho client u2 (scope: ROLE_client) và gửi request GET /admin/reports/map. | JWT (email=user@gmail.com, userId=u2, scope=ROLE_client); Path: /admin/reports/map | Server trả về mã trạng thái HTTP 403. |

10. **Input từng bước:**
   - Bước 1: Token: null; Path: /admin/reports/map
   - Bước 2: JWT (email=user@gmail.com, userId=u2, scope=ROLE_client); Path: /admin/reports/map
11. **Kỳ vọng từng bước:**
   - Bước 1: Server trả về mã trạng thái HTTP 401.
   - Bước 2: Server trả về mã trạng thái HTTP 403.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/AdminMapReportsTest.java`
13. **Ghi chú:** Sử dụng JWT tự ký bằng SIGNER_KEY hardcode trong test class.
