# SMP-049: MyReportsNotifier chọn lại đúng khoảng ngày cũ không gọi lại API

1. **Mã số test case:** SMP-049
2. **Tên test case:** MyReportsNotifier chọn lại đúng khoảng ngày cũ không gọi lại API
3. **Project:** Flutter Client
4. **Chức năng:** Bộ lọc danh sách phản ánh (Report List Filters)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra trên MyReportsNotifier, sau khi chọn setDateRange(march), gọi lại setDateRange với một instance ReportDateRange khác có cùng ngày 2026-03-01..2026-03-15 không phát sinh thêm lời gọi API; truyền null sẽ xóa bộ lọc ngày.
7. **Mục đích kiểm thử:** Tránh gọi lại API thừa khi chọn trùng khoảng ngày đang lọc trong Phản ánh của tôi và cho phép bỏ lọc ngày.
8. **Điều kiện tiên quyết:** MyReportsNotifier dùng _FakeReportRepo và khoảng ngày march (2026-03-01..2026-03-15).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi notifier.setDateRange(march) | march | myCalls.last.dateRange == march; lưu số lần gọi callsAfterFirstPick |
| 2 | Gọi notifier.setDateRange(ReportDateRange(start: 2026-03-01, end: 2026-03-15)) | instance mới cùng khoảng ngày march | repo.myCalls.length == callsAfterFirstPick (không gọi API thêm) |
| 3 | Gọi notifier.setDateRange(null) | null | myCalls.last.dateRange == null |

10. **Input từng bước:**
   - Bước 1: march
   - Bước 2: instance mới cùng khoảng ngày march
   - Bước 3: null
11. **Kỳ vọng từng bước:**
   - Bước 1: myCalls.last.dateRange == march; lưu số lần gọi callsAfterFirstPick
   - Bước 2: repo.myCalls.length == callsAfterFirstPick (không gọi API thêm)
   - Bước 3: myCalls.last.dateRange == null
12. **File test tương ứng:** `smartspace_client/test/features/reports/report_list_filters_test.dart`
13. **Ghi chú:** Không có.
