# SMP-069: Cho phép mở khóa admin bị khóa kể cả khi chỉ còn 1 admin hoạt động

1. **Mã số test case:** SMP-069
2. **Tên test case:** Cho phép mở khóa admin bị khóa kể cả khi chỉ còn 1 admin hoạt động
3. **Project:** Flutter Admin
4. **Chức năng:** Quản lý tài khoản Admin (AdminAccountListState.canToggle)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra phương thức AdminAccountListState.canToggle trả về true đối với tài khoản đang bị khóa (status='blocked') ngay cả khi tổng số admin đang hoạt động chỉ là 1.
7. **Mục đích kiểm thử:** Xác minh thao tác mở khóa luôn được phép để tăng số lượng admin hoạt động.
8. **Điều kiện tiên quyết:** Khởi tạo AdminAccountModel blocked (active=false) và AdminAccountListState gồm [_admin('me', me: true), blocked] với active=1.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi state.canToggle(blocked). | blocked (status='blocked'), state có summary.active=1. | Kết quả trả về true. |

10. **Input từng bước:**
   - Bước 1: blocked (status='blocked'), state có summary.active=1.
11. **Kỳ vọng từng bước:**
   - Bước 1: Kết quả trả về true.
12. **File test tương ứng:** `smartspace_admin/test/features/admin_accounts/admin_account_models_test.dart`
13. **Ghi chú:** Không có.
