# SMP-183: Lọc nhật ký hoạt động quản trị theo actorId

1. **Mã số test case:** SMP-183
2. **Tên test case:** Lọc nhật ký hoạt động quản trị theo actorId
3. **Project:** Spring Boot Backend
4. **Chức năng:** Nhật ký hoạt động quản trị (GET /admin/activities)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Kiểm tra Admin gọi GET /admin/activities?page=1&size=5&actorId=u1 trả về HTTP 200 và body chứa mảng phân trang "content".
7. **Mục đích kiểm thử:** Xác minh API truy vấn nhật ký hoạt động hỗ trợ tham số lọc actorId và phân trang.
8. **Điều kiện tiên quyết:** Backend đang chạy tại -Dsmartspace.baseUrl (mặc định http://localhost:8989); JWT admin u1 ký bằng SIGNER_KEY.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Admin u1 gửi GET /admin/activities?page=1&size=5&actorId=u1 | Query page=1, size=5, actorId=u1 kèm admin token u1 | HTTP 200 và body JSON chứa "content". |

10. **Input từng bước:**
   - Bước 1: Query page=1, size=5, actorId=u1 kèm admin token u1
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200 và body JSON chứa "content".
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/admin/AdminAccountManagementTest.java`
13. **Ghi chú:** Chỉ đọc dữ liệu, không kiểm tra sâu nội dung từng item trong content. Class này chưa đăng ký trong testapi.ps1.
