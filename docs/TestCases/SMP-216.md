# SMP-216: Bảng tin tìm kiếm từ khóa khớp tiêu đề, mô tả hoặc địa chỉ

1. **Mã số test case:** SMP-216
2. **Tên test case:** Bảng tin tìm kiếm từ khóa khớp tiêu đề, mô tả hoặc địa chỉ
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bảng tin phản ánh (Report Feed)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Lấy tiêu đề từ 1 phản ánh có sẵn trên Bảng tin để trích từ khóa tìm kiếm (tối đa 4 ký tự đầu), sau đó kiểm tra kết quả từ GET /reports/feed?search=... đều chứa từ khóa trong title, description hoặc address.
7. **Mục đích kiểm thử:** Xác minh chức năng tìm kiếm trên Bảng tin lọc đúng theo nội dung báo cáo.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; DB phải có ít nhất 1 report hiển thị trên /reports/feed (nếu không test sẽ bị skip qua assumeTrue).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi GET /reports/feed?size=1&page=1, kiểm tra assumeTrue(all.size() > 0) và lấy tối đa 4 ký tự đầu của title làm keyword. | JWT client u2; size=1&page=1 | HTTP 200; lấy được keyword không rỗng nếu DB có dữ liệu. |
| 2 | Gọi GET /reports/feed?size=20&page=1&search=<URLEncoded keyword>. | Query search đã URL-encode từ keyword bước 1 | HTTP 200; data.content.size() > 0 và mỗi item có (title + description + address) chứa keyword (không phân biệt hoa thường). |

10. **Input từng bước:**
   - Bước 1: JWT client u2; size=1&page=1
   - Bước 2: Query search đã URL-encode từ keyword bước 1
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; lấy được keyword không rỗng nếu DB có dữ liệu.
   - Bước 2: HTTP 200; data.content.size() > 0 và mỗi item có (title + description + address) chứa keyword (không phân biệt hoa thường).
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/ReportFeedTest.java`
13. **Ghi chú:** Phụ thuộc dữ liệu DB thật; sử dụng assumeTrue nên test sẽ bị skip (aborted) nếu Bảng tin trống.
