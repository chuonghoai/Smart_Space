# SMP-217: Bảng tin lọc chính xác theo một ngày duy nhất (from = to)

1. **Mã số test case:** SMP-217
2. **Tên test case:** Bảng tin lọc chính xác theo một ngày duy nhất (from = to)
3. **Project:** Spring Boot Backend
4. **Chức năng:** Bảng tin phản ánh (Report Feed)
5. **Loại kiểm thử:** API Integration Test (Live HTTP)
6. **Mô tả test case:** Lấy ngày tạo (yyyy-MM-dd) của phản ánh mới nhất trên Bảng tin và gọi GET /reports/feed với from=day&to=day để xác nhận mọi kết quả đều tạo trong đúng ngày đó.
7. **Mục đích kiểm thử:** Xác minh bộ lọc khoảng ngày khi ngày bắt đầu trùng ngày kết thúc không bị lệch múi giờ hay sai điều kiện biên.
8. **Điều kiện tiên quyết:** Backend đang chạy tại http://localhost:8989; DB phải có ít nhất 1 report trên /reports/feed (nếu không test sẽ bị skip qua assumeTrue).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi GET /reports/feed?size=1&page=1, kiểm tra assumeTrue(latest.size() > 0) và trích xuất day = created_at.substring(0, 10). | JWT client u2; size=1&page=1 | HTTP 200; lấy được chuỗi ngày yyyy-MM-dd. |
| 2 | Gọi GET /reports/feed?size=20&page=1&from={day}&to={day}. | Query from=day, to=day | HTTP 200; data.content.size() > 0 và mọi phần tử có created_at bắt đầu bằng chuỗi day. |

10. **Input từng bước:**
   - Bước 1: JWT client u2; size=1&page=1
   - Bước 2: Query from=day, to=day
11. **Kỳ vọng từng bước:**
   - Bước 1: HTTP 200; lấy được chuỗi ngày yyyy-MM-dd.
   - Bước 2: HTTP 200; data.content.size() > 0 và mọi phần tử có created_at bắt đầu bằng chuỗi day.
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/controller/report/ReportFeedTest.java`
13. **Ghi chú:** Phụ thuộc dữ liệu DB thật; sử dụng assumeTrue nên bị skip nếu Bảng tin không có dữ liệu.
