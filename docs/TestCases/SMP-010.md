# SMP-010: MapReportsResult.fromJson parse danh sách reports và cờ truncated

1. **Mã số test case:** SMP-010
2. **Tên test case:** MapReportsResult.fromJson parse danh sách reports và cờ truncated
3. **Project:** Flutter Client
4. **Chức năng:** Bản đồ phản ánh (Map Models)
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra MapReportsResult.fromJson parse JSON có mảng 'reports' chứa 1 phần tử id='a' và 'truncated': true.
7. **Mục đích kiểm thử:** Đảm bảo model kết quả truy vấn bản đồ đọc đúng danh sách phản ánh và cờ cắt bớt dữ liệu.
8. **Điều kiện tiên quyết:** Map JSON chứa 'reports' và 'truncated': true.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi MapReportsResult.fromJson với 1 report id='a' và truncated=true | {'reports': [{'id': 'a', ...}], 'truncated': true} | result.reports.single.id == 'a' và result.truncated == true |

10. **Input từng bước:**
   - Bước 1: {'reports': [{'id': 'a', ...}], 'truncated': true}
11. **Kỳ vọng từng bước:**
   - Bước 1: result.reports.single.id == 'a' và result.truncated == true
12. **File test tương ứng:** `smartspace_client/test/features/reports/map_models_test.dart`
13. **Ghi chú:** Không có.
