# SMP-269: Trả về không tìm thấy khi đối tượng không phải role admin

1. **Mã số test case:** SMP-269
2. **Tên test case:** Trả về không tìm thấy khi đối tượng không phải role admin
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản quản trị viên
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AdminAccountServiceImpl.updateAdminStatus(...) ném ResourceNotFoundException("admin.account.not_found") và không lưu DB khi tài khoản tìm thấy theo id có vai trò ERole.staff.
7. **Mục đích kiểm thử:** Đảm bảo API quản lý admin không thao tác và không làm lộ sự tồn tại của tài khoản staff/client.
8. **Điều kiện tiên quyết:** Stub lockByRoleAndStatus(ERole.admin, EUserStatus.active) trả về danh sách có "admin-me"; stub userRepository.findById("staff-1") trả về user("staff-1", ERole.staff, EUserStatus.active).
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.updateAdminStatus(...) nhắm vào "staff-1" | targetAdminId="staff-1", UpdateAdminStatusRequest("blocked"), currentAdminId="admin-me" | Ném ResourceNotFoundException với message "admin.account.not_found" và verify(userRepository, never()).save(any()) |

10. **Input từng bước:**
   - Bước 1: targetAdminId="staff-1", UpdateAdminStatusRequest("blocked"), currentAdminId="admin-me"
11. **Kỳ vọng từng bước:**
   - Bước 1: Ném ResourceNotFoundException với message "admin.account.not_found" và verify(userRepository, never()).save(any())
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/admin/AdminAccountServiceImplTest.java`
