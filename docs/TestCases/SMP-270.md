# SMP-270: Khóa admin khác thành công: lưu blocked, thu hồi phiên và ghi log

1. **Mã số test case:** SMP-270
2. **Tên test case:** Khóa admin khác thành công: lưu blocked, thu hồi phiên và ghi log
3. **Project:** Spring Boot Backend
4. **Chức năng:** Quản lý tài khoản quản trị viên
5. **Loại kiểm thử:** Unit Test
6. **Mô tả test case:** Kiểm tra AdminAccountServiceImpl.updateAdminStatus(...) khi khóa một admin khác (nhận status chữ hoa "BLOCKED"): cập nhật trạng thái thành blocked, lưu user, gọi revokeUserAccess (không gọi restoreUserAccess) và ghi ActivityHistory với i18nKey chuẩn.
7. **Mục đích kiểm thử:** Xác minh đầy đủ luồng khóa tài khoản quản trị viên khác.
8. **Điều kiện tiên quyết:** Stub lockByRoleAndStatus(ERole.admin, EUserStatus.active) trả về [me, other] đều active; findById(OTHER) trả về other; findById(ME) trả về me.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Gọi service.updateAdminStatus("admin-other", new UpdateAdminStatusRequest("BLOCKED"), "admin-me") | targetAdminId="admin-other", status="BLOCKED", currentAdminId="admin-me" | other.status=EUserStatus.blocked và gọi userRepository.save(other) |
| 2 | Kiểm tra thu hồi phiên và lịch sử hoạt động | authenticationService, activityHistoryRepository | Gọi authenticationService.revokeUserAccess("admin-other"), không gọi restoreUserAccess; ActivityHistory lưu với i18nKey="activity.admin.status_updated\|Name admin-me\|Name admin-other\|blocked" |

10. **Input từng bước:**
   - Bước 1: targetAdminId="admin-other", status="BLOCKED", currentAdminId="admin-me"
   - Bước 2: authenticationService, activityHistoryRepository
11. **Kỳ vọng từng bước:**
   - Bước 1: other.status=EUserStatus.blocked và gọi userRepository.save(other)
   - Bước 2: Gọi authenticationService.revokeUserAccess("admin-other"), không gọi restoreUserAccess; ActivityHistory lưu với i18nKey="activity.admin.status_updated|Name admin-me|Name admin-other|blocked"
12. **File test tương ứng:** `SmartSpace_Backend/src/test/java/com/vn/smart_space/service/admin/AdminAccountServiceImplTest.java`
13. **Ghi chú:** Tên test method: Status.block_revokesAccessAndLogs.
