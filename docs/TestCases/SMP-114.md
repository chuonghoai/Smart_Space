# SMP-114: Màn hình đăng nhập Admin hỗ trợ tiếng Việt và Dark Theme

1. **Mã số test case:** SMP-114
2. **Tên test case:** Màn hình đăng nhập Admin hỗ trợ tiếng Việt và Dark Theme
3. **Project:** Flutter Admin
4. **Chức năng:** Xác thực - Đăng nhập Admin (Localization & Theme)
5. **Loại kiểm thử:** Widget Test
6. **Mô tả test case:** Kiểm tra AdminLoginScreen khi cấu hình locale 'vi' và AppTheme.darkTheme trên kích thước 1200x800 hiển thị AuthBrandingPanel và các nhãn tiếng Việt tương ứng.
7. **Mục đích kiểm thử:** Xác minh màn hình đăng nhập Admin hỗ trợ đa ngôn ngữ tiếng Việt và giao diện Dark Theme không lỗi.
8. **Điều kiện tiên quyết:** Surface size đặt thành Size(1200, 800); MaterialApp dùng AppTheme.darkTheme và locale 'vi'.
9. **Các bước kiểm thử:**

| Bước | Thao tác | Input | Kết quả kỳ vọng |
|---|---|---|---|
| 1 | Đặt kích thước bề mặt 1200x800, render AdminLoginScreen với locale 'vi' và theme AppTheme.darkTheme, gọi pump(). | AdminLoginScreen(); Size(1200, 800); locale 'vi'; AppTheme.darkTheme. | Tìm thấy 1 AuthBrandingPanel, text 'Quên mật khẩu?' và text 'Ghi nhớ đăng nhập'. |

10. **Input từng bước:**
   - Bước 1: AdminLoginScreen(); Size(1200, 800); locale 'vi'; AppTheme.darkTheme.
11. **Kỳ vọng từng bước:**
   - Bước 1: Tìm thấy 1 AuthBrandingPanel, text 'Quên mật khẩu?' và text 'Ghi nhớ đăng nhập'.
12. **File test tương ứng:** `smartspace_admin/test/ui/screen/auth/auth_responsive_test.dart`
13. **Ghi chú:** Test xác nhận render thành công với AppTheme.darkTheme và localization tiếng Việt qua các nhãn hiển thị; không assert trực tiếp giá trị màu theme.
